# Text

`Text` centraliza tipografia sem substituir a semântica do HTML. O elemento padrão
é `span`; use `render` para títulos, parágrafos e outros elementos.

```tsx
import { Text } from '@acme/elements/text'

<Text>Body text</Text>
<Text render={<h2 />} family="heading" size="lg" weight="semibold">
  Section title
</Text>
```

## Tamanhos

`md` é o padrão.

| `size` | Classe tipográfica |
| --- | --- |
| `sm` | `text-sm` |
| `md` | `text-base` |
| `lg` | `text-lg` |

As cores disponíveis são `base`, `muted`, `destructive` e `inherit`. Elas usam
somente os tokens do tema COSS do seu projeto.
