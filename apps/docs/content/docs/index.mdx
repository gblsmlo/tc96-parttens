# TC96

> **Em migração.** Esta página descreve o modelo decidido em 2026-10-01. Até o
> fim da migração, o CLI ainda lê `tc96.json` e copia `ui` e `utils`
> para o projeto, e o nome do CLI no npm ainda não foi confirmado.

TC96 reúne patterns de interface sem regra de negócio, como collection views,
properties, detail sheet e edição inline. Eles não são uma dependência: o CLI
copia os fontes para o seu projeto, e você passa a ser dono deles.

```sh
npx tc96-parttens add collection-views properties
```

## Camadas do consumidor

Os patterns se apoiam numa estrutura em camadas, configurada pelo
`components.json` na raiz do monorepo:

- `ui`: os componentes COSS do seu projeto. O TC96 não distribui UI própria;
  consulte a [documentação do COSS](https://coss.com/ui) para `Button`, `Input`,
  `Field` e os demais.
- `utils`: o `cn` que o COSS já instala.
- `elements`: componentes do TC96 que não existem no COSS, como `Text`.
- `patterns`: os patterns do TC96.

Os patterns usam o tema e as personalizações dos seus componentes COSS. O TC96
não publica CSS, tokens nem tema.
