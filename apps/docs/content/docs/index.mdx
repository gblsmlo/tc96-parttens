# TC96

TC96 reúne padrões de interface que antes eram publicados separadamente. Instale
um único pacote e importe pela camada adequada ao que você está construindo.

```tsx
import { Kanban } from 'tc96/blocks'
```

## Instalação

```sh
bun add tc96
```

O pacote requer React 19, Tailwind CSS 4 e Base UI. Para manter o código no seu
projeto COSS, instale o bloco correspondente pelo registry do TC96.

## Camadas públicas

- `tc96/ui`: primitives como `Button` e `Input`.
- `tc96/components`: composições reutilizáveis, como properties e edição inline.
- `tc96/blocks`: experiências completas, como as collection views (Kanban,
  List, DataGrid, Calendar), Detail Sheet e Filter Builder.
- `tc96/utils`: utilitários sem domínio, como `cn`.

Os nomes históricos de grupos continuam organizando o registry COSS, mas não
fazem parte da API npm pública.
