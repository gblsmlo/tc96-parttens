# Instalação

> **Em migração.** Esta página descreve o modelo decidido em 2026-10-01. Até o
> fim da migração, o CLI ainda não instala os componentes COSS que os patterns
> usam: instale-os antes com o shadcn. O nome do CLI no npm ainda não foi
> confirmado.

## Requisitos

- React 19, TypeScript e Tailwind CSS 4.
- COSS configurado com shadcn, com `components.json` na raiz do monorepo.
- Node e npm para executar o CLI. Bun não é exigido.

## Aliases

Acrescente `elements` e `patterns` aos aliases que o shadcn já define:

```json
{
  "aliases": {
    "components": "@acme/ui",
    "ui": "@acme/ui",
    "utils": "@acme/ui/lib/utils",
    "elements": "@acme/elements",
    "patterns": "@acme/patterns"
  }
}
```

Cada alias também precisa de entrada exata e de wildcard em `paths` no
`tsconfig` da raiz. O CLI grava `elements` e `patterns` no diretório que o
wildcard de cada alias resolve e reescreve os imports para `ui` e `utils`, que
continuam sendo seus: nenhum arquivo é gravado neles.

## Instalar

Instale um ou vários patterns de uma vez:

```sh
npx tc96-parttens add collection-views properties
```

O CLI delega a escrita ao shadcn e reescreve os imports para os seus aliases:

```tsx
import { CollectionViewOutlet, TextProperty } from '@acme/patterns'
```

Arquivos existentes são preservados; o shadcn pergunta antes de sobrescrever.

## Atualizar

Não há pacote para atualizar. Compare os arquivos instalados com a versão atual
e incorpore as correções manualmente:

```sh
npx tc96-parttens add collection-views --diff
```

Filter Builder não faz parte desta versão.
