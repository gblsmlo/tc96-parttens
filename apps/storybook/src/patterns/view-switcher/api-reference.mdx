# ViewSwitcher

The control that picks the saved view a collection shows: a trigger with the active view and a popover with the search, the views, the options of a view and the creation of a new one. It keeps no state beyond the popover's `open`: the consumer passes the views and the selection and handles every callback. Its trigger is a toolbar button, so it only mounts inside a [CollectionToolbar](?path=/docs/patterns-collectiontoolbar-api-reference--api-reference), usually in its `left` slot.

The other pages of `Patterns/ViewSwitcher`: [Playground](?path=/story/patterns-viewswitcher-playground--playground) to try the trigger variant and the optional parts of the popover, [Layouts](?path=/story/patterns-viewswitcher-layouts--default) for the arrangements of the views, [Behavior](?path=/story/patterns-viewswitcher-behavior--opens-labelled-dialog-not-menu) for the tests, and [Usages](?path=/story/patterns-viewswitcher-usages--managed-views) for real lists of saved views.

Used in: the toolbar of the [Tasks](?path=/story/patterns-collection-usages--tasks) collection and the [Task Views](?path=/story/patterns-collectiontoolbar-usages--task-views) toolbar.

## Import

```tsx
import {
  ViewSwitcherCreate,
  ViewSwitcherItem,
  ViewSwitcherItems,
  ViewSwitcherMenu,
  ViewSwitcherSearch,
} from '@acme/patterns'
```

The prop types of each part are exported with it, listed under Exports.

## Anatomy

`ViewSwitcherMenu` in the `left` slot of a `CollectionToolbar`, with a content slot in its popover:

<Canvas of={ApiReferenceStories.Anatomy} />

```tsx
<CollectionToolbar
  left={
    <ViewSwitcherMenu icon={<Icon />} label="ViewSwitcherMenu">
      <ViewSwitcherSearch onValueChange={setQuery} value={query} />
      <ViewSwitcherItems>
        <ViewSwitcherItem
          label="ViewSwitcherItem"
          onSelect={select}
          options={<MenuItem>Duplicar</MenuItem>}
          selected
        />
      </ViewSwitcherItems>
      <ViewSwitcherCreate onClick={create} />
    </ViewSwitcherMenu>
  }
/>
```

The popover is closed in the canvas above, so the tree below lists what it holds once the trigger is pressed:

```text
button                                          trigger, aria-haspopup="dialog"
├── span                                        icon, only with icon
├── span                                        label, truncated
└── svg                                         chevron, aria-hidden
div[role=dialog][data-slot=popover-popup]       portaled, aria-label is the label
└── div[data-slot=popover-viewport]
    └── div                                     children, in a column
        ├── div[data-slot=view-switcher-search]       ViewSwitcherSearch
        │   └── input[type=search]
        ├── fieldset[data-slot=view-switcher-items]   ViewSwitcherItems
        │   ├── div[data-slot=view-switcher-item]     ViewSwitcherItem
        │   │   ├── button                            label, closes the popover
        │   │   │   └── span[data-slot=view-switcher-item-count]   count, only with count
        │   │   └── button                            options trigger, only with options
        │   └── div[aria-hidden]                      skeleton row, only with loading
        └── button[data-slot=view-switcher-create]    ViewSwitcherCreate
```

## ViewSwitcherMenu

The trigger and the popover of the view switcher. Renders a toolbar button that shows the active view and opens a popover with the views; mount it in the toolbar, since the trigger is a toolbar item. The popover has `role="dialog"`, not a menu, because it holds a search field and a button per view, and a `role="menu"` can hold neither. It opens under the trigger, aligned to its start, 18rem wide, and closes when a view, an option or the create button is chosen.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `string` | required | Sets the text of the trigger and the `aria-label` of the popover, usually the label of the active view. |
| `children` | `ReactNode` | required | Sets the content of the popover, in a column with 4px between its parts. |
| `icon` | `ReactNode` | - | Sets an icon before the label; without it the trigger has no icon wrapper. |
| `variant` | `"default" \| "ghost"` | `"default"` | Sets the look of the trigger: `default` is a filled `secondary` button, `ghost` has no fill until hover. |
| `className` | `string` | - | Adds classes to the trigger. |

The label is truncated, so a long view name never widens the trigger past its container; the accessible name stays whole. A chevron after the label is always drawn. The trigger has no count: a `ViewSwitcherItem` shows the count of its view inside the popover, and the trigger names the active view only.

| Attribute | Part | Values | Description |
| --- | --- | --- | --- |
| `aria-haspopup` | trigger | `"dialog"` | Says the trigger opens a dialog |
| `aria-expanded` | trigger | `"true"` or `"false"` | Follows the popover |
| `data-popup-open` | trigger | present while the popover is open | Lets the theme style the open trigger |
| `data-slot` | popover | `"popover-popup"` | Selects the popover |

## ViewSwitcherSearch

The search field of the popover. Renders a `div` with `data-slot="view-switcher-search"` around an `input` of `type="search"`. It filters nothing: the consumer keeps the typed text, filters the views it passes and renders the result.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | required | Sets the text of the field; the field is controlled. |
| `onValueChange` | `(value: string) => void` | required | Called on every change, with the new text. |
| `label` | `string` | `"Buscar views"` | Sets the `aria-label` of the field. |
| `placeholder` | `string` | `"Buscar views..."` | Sets the placeholder of the field. |

| Attribute | Values | Description |
| --- | --- | --- |
| `data-slot` | `"view-switcher-search"` | Selects the wrapper of the field |

## ViewSwitcherItems

The list of views, or one group of them. Renders a `fieldset` with `role="group"` named by `label`, a column with 2px between its rows. A popover can hold several, such as a favorites group followed by the other views; separators and group headings are the consumer's markup.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | - | Sets the rows, usually `ViewSwitcherItem`. |
| `label` | `string` | `"Views"` | Sets the `aria-label` of the group. |
| `loading` | `boolean` | `false` | When true, marks the group busy and adds skeleton rows after the children. |
| `loadingItemCount` | `number` | `3` | Sets how many skeleton rows `loading` adds. |

With `loading` the children render first, so a view the consumer already knows (the default one) stays selectable while the saved views load. Each skeleton row is `aria-hidden` and holds two `Skeleton` blocks.

| Attribute | Values | Description |
| --- | --- | --- |
| `data-slot` | `"view-switcher-items"` | Selects the group |
| `aria-busy` | `"true"` while `loading` | Says the list is still loading |

## ViewSwitcherItem

One view of the list. Renders a `div` with `data-slot="view-switcher-item"` that holds a button with the label and, when it has `options`, a second button that opens the menu of the view. Choosing the label calls `onSelect` and closes the popover.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `string` | required | Sets the text of the row and, without `aria-label`, its accessible name. |
| `onSelect` | `() => void` | required | Called when the label is pressed, before the popover closes. |
| `selected` | `boolean` | `false` | When true, marks the row as the current one and gives it the accent background. |
| `count` | `number \| string` | - | Shows the number of records of the view at the end of the label button; `0` is shown, `undefined` shows nothing. A `string` passes a number already formatted, such as `"1.284"`. |
| `aria-label` | `string` | - | Sets the accessible name of the label button, as a final string the consumer writes, such as `"Minha fila, 3 prazos"`; the count itself is hidden from assistive technology. |
| `icon` | `ReactNode` | - | Sets an icon before the label; without it the row has no icon wrapper. |
| `options` | `ReactNode` | - | Sets the content of the options menu, usually `MenuItem` parts; without it the options button is not rendered. |
| `optionsLabel` | `string` | `"Opções de {label}"` | Sets the `aria-label` of the options button. |

The count is a muted `span` in extra-small text with tabular numbers, pushed to the end of the label button, so it stays aligned across rows and sits just before the options button. It never shrinks: a long label truncates and the count stays whole. It is `aria-hidden`, so the pattern never joins it to the label: without `aria-label` the row is named by `label` alone, and with it by that string. Start `aria-label` with the visible `label`, so a voice user can say what they see.

The options menu is a `Menu` that opens to the right of the options button, aligned to its start and 16rem wide. It is a separate tree from the popover, so the item closes the popover itself: pressing an option closes the menu and the popover together, while closing the menu with Escape leaves the popover open. An option that is `disabled` stays visible and does nothing.

| Attribute | Values | Description |
| --- | --- | --- |
| `data-slot` | `"view-switcher-item"` | Selects the row |
| `data-selected` | present when `selected` | Lets the theme style the current row; absent otherwise |
| `aria-current` | `"true"` on the label button when `selected` | Marks the current view for assistive technology |
| `data-slot` | `"view-switcher-item-count"` on the count, only with `count` | Selects the count |

## ViewSwitcherCreate

The button that creates a view. Renders a ghost button at the full width of the popover, with a plus icon and the label. Pressing it calls `onClick` and closes the popover.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `onClick` | `() => void` | required | Called when the button is pressed, before the popover closes. |
| `label` | `string` | `"Criar nova view"` | Sets the text of the button. |

| Attribute | Values | Description |
| --- | --- | --- |
| `data-slot` | `"view-switcher-create"` | Selects the button |

## Accessibility and theme

- The labels the view switcher writes itself (`"Buscar views"`, `"Buscar views..."`, `"Views"`, `"Opções de {label}"` and `"Criar nova view"`) are in Portuguese: pass `label`, `placeholder` and `optionsLabel` in the language of the screen.
- With `count`, pass an `aria-label` that says the count in words, such as `"Minha fila, 3 prazos"`: the visible number is hidden from assistive technology, so without it the row is named by its `label` alone.
- Give `ViewSwitcherItems` a `label` that names its group, such as `"Favoritos"` for a favorites group; the popover is named by the `label` of `ViewSwitcherMenu`.
- Pass icons that hide themselves (`aria-hidden="true"`; the `@phosphor-icons/react` icons do not set it, so pass it), since the label already names the control.
- Escape closes the popover and returns focus to the trigger, and the options menu closes before the popover does.
- The popover reads `--popover`, `--popover-foreground` and `--border`, the current row `--accent`, and the placeholder and the count `--muted-foreground`. The trigger and the buttons read the tokens of `Button`.
