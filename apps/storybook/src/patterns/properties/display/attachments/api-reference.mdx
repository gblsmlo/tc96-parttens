# Attachments

A row of files or links attached to a record, with the add path always in view: the documents of a deal, the material of a meeting, the links of a support case. Each item is an `AttachmentProperty` chip that opens its target and, when the consumer allows it, removes itself; the row adds one add trigger after the chips.

The other pages of `Patterns/Properties/Display/Attachments`: [Playground](?path=/story/patterns-properties-display-attachments-playground--playground) to try the texts, the type and the optional parts, [Variants](?path=/story/patterns-properties-display-attachments-variants--default) for the empty and read-only rows, the disabled add trigger and each type, [Layouts](?path=/story/patterns-properties-display-attachments-layouts--default) for the row, [Behavior](?path=/story/patterns-properties-display-attachments-behavior--lists-attachments) for the tests, and [Usages](?path=/story/patterns-properties-display-attachments-usages--record-files) for the files and links of a record.

The row, the chip surface and the add trigger are the shared parts of the properties, documented once in the [API Reference of `Patterns/Properties`](?path=/docs/patterns-properties-api-reference--api-reference): `PropertyRow`, `PropertySurface` and `PropertyAddTrigger`. This page covers what the attachments add to them.

## Import

```tsx
import { AttachmentProperty, AttachmentsProperty } from '@acme/patterns'
```

## AttachmentsProperty

The row. Renders a `fieldset` named by `ariaLabel`, so its role is `group`, with no border, margin or padding, laying out its children in a wrapping row 4px apart (2px between lines). It renders the `children` first and, when `action` is set, one add trigger after them. It never uploads, fetches or stores a file: `onSelect` is where the consumer opens its own picker. There is no `readOnly` prop: a row the user cannot change passes no `action`, and its chips no `onRemove`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `React.ReactNode` | - | Sets the chips, usually one `AttachmentProperty` per item. |
| `action` | `AttachmentsPropertyAction` | - | Adds the add trigger; without it the row only lists. |
| `ariaLabel` | `string` | - | Names the row. |
| `className` | `string` | - | Adds classes to the `fieldset`. |

Takes no other prop.

| Attribute | Values | Description |
| --- | --- | --- |
| `data-slot` | `"attachments-property"` | Selects the row |

The add trigger is a `button` with `type="button"`, named by `action.label` through `aria-label`. While the row has no children it shows the `icon` (12px) and the `label`, so the empty row says what it adds; once a child exists it collapses to a 24px-wide plus (14px) with no text, keeping the same name. It has the filled surface of a chip and `muted-foreground` text. There is one trigger per row: a row that accepts two kinds of item (files and links) is two rows, each with its own `ariaLabel`. With `action.disabled` the button is disabled: it dims to 64% opacity and ignores the pointer.

## AttachmentsPropertyAction

What `action` takes.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `string` | required | Names the trigger and is its text while the row is empty. |
| `onSelect` | `() => void` | required | Called when the trigger is clicked or activated by the keyboard. |
| `disabled` | `boolean` | `false` | When true, disables the trigger. |
| `icon` | `React.ComponentType<React.SVGProps<SVGSVGElement>>` | - | Sets the icon shown before the label while the row is empty. |

## AttachmentProperty

One attachment. Renders a filled chip (a `span`, 24px tall, `text-sm`) that holds a link and, with `onRemove`, a remove button. The link is an `a` with the type icon and the `label`, cut to one line with an ellipsis; the remove button is a sibling of the link, never inside it, so the chip is valid markup and each control is its own tab stop.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `React.ReactNode` | required | Sets the text of the link, which names it. |
| `type` | `"pdf"`, `"doc"`, `"audio"` or `"link"` | - | Sets the type icon before the label; without it the chip shows no icon. |
| `action` | `"anchor"` or `"download"` | `"anchor"` | Controls how the link opens its target: `"download"` adds the `download` attribute. |
| `onRemove` | `() => void` | - | Adds the remove button and is called when it is pressed; without it the chip has no button. |
| `labels` | `Partial<AttachmentPropertyLabels>` | English | Overrides the texts, merged over `defaultPropertyLabels.attachment`: `remove` (`"Remove attachment"`) names the remove button. |

Also takes every prop of an `a` except `children` and `download`: `href`, `target`, `rel` and the event handlers reach the link, while `className` goes to the chip.

| Attribute | Values | Description |
| --- | --- | --- |
| `data-slot` | `"attachment-property"` | Selects the chip |
| `data-slot` | `"attachment-property-link"` | Selects the link |
| `data-slot` | `"attachment-type-icon"` | Selects the type icon |
| `data-attachment-type` | `"pdf"`, `"doc"`, `"audio"` or `"link"` | Reports `type` on the icon |
| `data-slot` | `"attachment-property-remove"` | Selects the remove button |

The link is a plain `PropertySurface` rendered as an `a`, so it takes the plain trigger box described in the `PropertySurface` section of the root API Reference: 24px tall, pulled 6px toward the start of the chip, with a `secondary` fill on hover and keyboard focus, which matches the chip's own fill.

The type icon is 14px, hidden from assistive technology, and takes the tone of its type: `"pdf"` in `destructive-foreground`, `"doc"` in `info-foreground`, `"audio"` in `warning-foreground` and `"link"` in `muted-foreground`. The right-hand control is always remove, whatever `action` and `type` are; it is an `×` at 80% opacity that turns opaque on hover, and the chip drops its end padding to make room for it.

## Accessibility and theme

- Pass `ariaLabel` on every row: an unnamed `fieldset` is a group with no name, and a record often has more than one row of attachments.
- Pass a `labels.remove` that names the item (`Remove Signed contract.pdf`): the default `Remove attachment` is the same on every chip.
- The built-in text is English (`Remove attachment`); pass `labels.remove` to change it.
- The chip and the trigger read `secondary` and `secondary-foreground`, the trigger `muted-foreground`, and the type icons `destructive-foreground`, `info-foreground`, `warning-foreground` and `muted-foreground`.
