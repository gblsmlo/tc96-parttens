# Person

A property for one person: the assignee of a task, the owner of an account, who created a record. The person shows as an avatar and a name, or as the avatar alone in a dense row, and the same surface opens a list of the people the consumer offers. For several people at once, use [People](?path=/docs/patterns-properties-display-people-api-reference--api-reference).

The other pages of `Patterns/Properties/Display/Person`: [Playground](?path=/story/patterns-properties-display-person-playground--playground) to try the person, the texts, the surface and the states, [Variants](?path=/story/patterns-properties-display-person-variants--default) for each surface, avatar size and state, [Layouts](?path=/story/patterns-properties-display-person-layouts--default) for the avatar and name and the [avatar alone](?path=/story/patterns-properties-display-person-layouts--avatar-only-value), [Behavior](?path=/story/patterns-properties-display-person-behavior--badge-surface-with-xs-avatar) for the tests, and [Usages](?path=/story/patterns-properties-display-person-usages--task-assignee) for real content.

Used in: [`AssignedProperty`](?path=/docs/patterns-properties-display-assigned-api-reference--api-reference) is a `PersonProperty` with assignee defaults, and the checklist rows render it for their assignee. The creator of [Patterns/Records/Preview/Usages/Tasks](?path=/story/patterns-records-preview-usages--tasks) renders it read-only.

## PersonProperty

Renders a `button` with `role="combobox"` that opens a list, or, read-only, a `span` with `role="img"`; both are named `"<ariaLabel>: <name>"`, or `"<ariaLabel>: <placeholder>"` while no one is set. It never fetches or filters people: the consumer passes every option and receives the id of the picked person. It is read-only when `readOnly` is set or when neither `action` nor `onValueChange` is passed; with both, only `action` is called.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `TValue \| null` | required | Sets the id of the person; `null` shows no one. |
| `options` | `readonly PersonPropertyOption<TValue>[]` | required | Sets the people the list offers, in order. |
| `onValueChange` | `(value: TValue) => void` | - | Called with the id of the picked person. |
| `action` | `(value: TValue, context: PersonPropertyActionContext<TValue>) => void` | - | Called instead of `onValueChange`, with the picked option. |
| `variant` | `"badge"` or `"plain"` | `"badge"` | Controls the surface: a 24px filled badge, or inline text with no fill that, while editable, draws a `secondary` box on hover, on keyboard focus and while the list is open. |
| `display` | `"full"` or `"avatar"` | `"full"` | Controls the value: the avatar and the name, or the avatar alone. |
| `avatarSize` | `"xs"`, `"sm"`, `"default"`, `"lg"` or `"xl"` | `"xs"` | Sets the avatar of the value: 16, 24, 32, 40 or 48px; the 24px surface fits `"xs"` and `"sm"`. |
| `ariaLabel` | `string` | `"Person"` | Prefixes the accessible name, before the name of the person. |
| `placeholder` | `string` | `"No assignee"` | Sets the text and the name while no one is set. |
| `dropdownPlacement` | `PropertySelectDropdownPlacement` | - | Sets the `side`, `align`, `sideOffset`, `alignOffset` and `alignItemWithTrigger` of the list. |
| `disabled` | `boolean` | `false` | When true, disables the trigger. |
| `readOnly` | `boolean` | `false` | When true, renders the value with no list, with the same look. |
| `className` | `string` | - | Adds classes to the surface. |

`TValue` is a string type of the ids, `string` by default. Takes no other prop.

| Attribute | Values | Description |
| --- | --- | --- |
| `data-slot` | `"property-surface"` | Selects the trigger, or the read-only value |
| `data-variant` | `"badge"` or `"plain"` | Follows `variant` |
| `data-empty` | `"true"` while no one is set | Styles the empty value |
| `data-slot` | `"avatar"`, with `data-size` | Selects each avatar: `avatarSize` in the value, `"sm"` in the list |
| `data-slot` | `"avatar-fallback"` | Selects the initials of an avatar |

### The value

With `display="full"` the value is the avatar, the name cut to one line, and the `supportingLabel` in muted text from the `sm` breakpoint. With no one set it is a user-plus icon and `placeholder` on the muted surface. With `display="avatar"` only the avatar shows, and the name stays in the accessible name; with no one set the avatar holds a user icon.

### The list

The list opens from the trigger with one option per person, each with a 24px avatar, the name and the `supportingLabel`, and a check at the right of the current person. Each option is named by the name of the person alone. Picking another person calls the handler once; picking the current person closes the list and calls nothing.

### The avatar

Each avatar shows the photo of `imageUrl` once it loads, and otherwise the `fallback` of the option, or the initials of the first two words of `label`, in 10px type on the `border` fill with a 1px `input` outline. At `"xs"` the initials are cut to their first letter, an explicit `fallback` included, since two letters do not fit in 16px. The photo is decorative (`alt=""`).

## PersonPropertyBadge

The read-only value of a person, with no list. Renders the property surface, a `span`, with a 16px avatar and the name, or the user-plus icon and `placeholder` on the muted surface when `option` is `null`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `option` | `PersonPropertyOption<TValue> \| null` | required | Sets the person to show. |
| `variant` | `"badge"` or `"plain"` | `"badge"` | Controls the surface. |
| `display` | `"full"` or `"avatar"` | `"full"` | Controls the value: the avatar and the name, or the avatar alone. |
| `placeholder` | `string` | `"No assignee"` | Sets the text while `option` is `null`. |
| `ariaLabel` | `string` | - | Names the surface as given, with `role="img"`. |
| `className` | `string` | - | Adds classes to the surface. |

Takes no other prop. Unlike `PersonProperty`, `ariaLabel` is the whole name: pass `"Responsável: Gabriel Melo"`, not `"Responsável"`.

## PersonPropertyOption

A person of `options`.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `TValue` | required | The id of the person. |
| `label` | `string` | required | The name, shown and used for the initials. |
| `imageUrl` | `string` | - | The photo of the avatar, shown over the initials once it loads. |
| `fallback` | `string` | the initials of `label` | The text of the avatar when there is no photo. |
| `supportingLabel` | `string` | - | A second text, such as a role, shown from the `sm` breakpoint. |

An id of `value` that no option declares shows with the id as its name.

## PersonPropertyActionContext

What `action` receives with the id of the picked person.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `option` | `PersonPropertyOption<TValue>` | - | The picked person. |
| `previousValue` | `TValue \| null` | - | The id before the pick. |

## Accessibility and theme

- Pass `ariaLabel`: without it the value is named `"Person: <name>"`, in English. With `display="avatar"` it is the only way the role of the person reaches a screen reader.
- The default `placeholder` is English (`No assignee`); pass one that says what is missing ("Sem dono").
- The avatar initials are 10px; their contrast is recorded in `docs/accessibility.md`. The surface reads the badge tokens of the property surface.
