# Text

A property for a short free text: the source of a lead, the profession of a contact, an id, an email shown as text. The value shows on the property surface with an optional icon and copy button, and, when the consumer takes commits, it is filled or edited in place. For a value out of a list, use [Select](?path=/docs/patterns-properties-display-select-api-reference--api-reference).

The other pages of `Patterns/Properties/Display/Text`: [Playground](?path=/story/patterns-properties-display-text-playground--playground) to try the value, the `labels`, the icon, the copy button, the editing and the surface, [Variants](?path=/story/patterns-properties-display-text-variants--default) for the `plain` surface and the empty value, [Layouts](?path=/story/patterns-properties-display-text-layouts--default) for the value and the [inline field](?path=/story/patterns-properties-display-text-layouts--inline-field), [Behavior](?path=/story/patterns-properties-display-text-behavior--badge-surface-is-filled) for the tests, and [Usages](?path=/story/patterns-properties-display-text-usages--contact-details) for the details of a contact, the id of a task and the location of an event.

`TextProperty` draws its value with [Icon Label](?path=/docs/patterns-properties-display-iconlabel-api-reference--api-reference) and edits it with [Editable Text](?path=/docs/patterns-properties-display-editabletext-api-reference--api-reference); this page covers what it adds on top.

Used in: the id of [Patterns/Records/Preview/Usages/Tasks](?path=/story/patterns-records-preview-usages--tasks), the details and billing blocks of [Patterns/Records/Group/Usages](?path=/story/patterns-records-group-usages--details), the contact dialog of [Blocks/Application/Record Dialog/Contacts/Contacts2](?path=/story/blocks-application-record-dialog-contacts-contacts2-playground--playground) and the location chip of [Blocks/Application/Record Dialog/Agenda/Agenda1](?path=/story/blocks-application-record-dialog-agenda-agenda1-playground--playground).

## Anatomy

```tsx
<TextProperty

  icon={ShapesIcon}
  labels={{ copy: 'Copiar tipo' }}
  value="Solicitação de documento"
/>
```

The surface holds the icon, the value and the copy button, in this order; only the value is always there. The surface is the one every property shares: see [`PropertySurface`](?path=/docs/patterns-properties-api-reference--api-reference) in the API Reference of `Patterns/Properties`.

## TextProperty

Renders the property surface, a `span`, with the value cut to one line, or `labels.fallback` in the empty look while there is no value. It is read-only unless `onCommit` is passed and `disabled` is not set; it never stores the text, so the consumer keeps `value` and receives each commit.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string \| null` | required | Sets the text; it is trimmed, and an empty text counts as no value. |
| `onCommit` | `(value: string \| null) => void` | - | Called with the committed text, trimmed, or `null` when it was cleared. |
| `editing` | `"trigger"` or `"inline"` | `"trigger"` | Controls how an editable value is edited: an add button while empty, or a field in place of the value from the start. |
| `variant` | `"badge"` or `"plain"` | `"badge"` | Controls the surface: a 24px filled badge, or inline text with no fill. |
| `ariaLabel` | `string` | - | Names the value `"<ariaLabel>: <text>"`, and names the field. |
| `labels` | `Partial<TextPropertyLabels>` | English | Overrides the texts, merged over `defaultPropertyLabels.text`: `fallback` (`"Not set"`, the text while there is no value, the name of the add button without `add`, and the name and placeholder of the field without `ariaLabel` and `inputPlaceholder`), `copy` (`"Copy"`, the name of the copy button), `add` (the name of the add button) and `inputPlaceholder` (the placeholder of the field). |
| `icon` | `PropertyIcon` | - | Sets the icon before the value, at 16px. |
| `iconClassName` | `string` | - | Adds classes to the icon, merged over its `size-4`. |
| `copyable` | `boolean` | `false` | Adds a copy button after the value, named by `labels.copy`, while there is a value. |
| `trailingVisibility` | `"always"` or `"hover"` | `"always"` | Controls when the copy button shows: always, or only while the surface is hovered or holds focus. |
| `disabled` | `boolean` | `false` | When true, shows the value read-only even with `onCommit`. |
| `className` | `string` | - | Adds classes to the surface, or to the add button. |

Takes no other prop.

| Attribute | Values | Description |
| --- | --- | --- |
| `data-slot` | `"property-surface"` | Selects the surface, or the add button |
| `data-variant` | `"badge"` or `"plain"` | Follows `variant` on the surface |
| `data-empty` | `"true"` while there is no value | Styles the empty value and the add button |
| `data-slot` | `"property-icon"` | Selects the icon |
| `data-slot` | `"text-property-copy"` | Selects the copy button |
| `data-slot` | `"property-trailing"` | Selects the wrapper of the copy button, present only with `trailingVisibility="hover"` |

### Naming

With `ariaLabel`, the surface is named `"<ariaLabel>: <value or fallback>"` with `role="img"`, so a screen reader reads one name; with the copy button it takes `role="group"` instead, so the button stays reachable. While the field shows, the surface has no name and the field is named `ariaLabel`, so the value is not read twice.

### Copying

The copy button is a 16px copy icon at 80% opacity, 100% on hover, at the end of the surface, which drops its end padding for it. A click writes the value to the clipboard; a refused write is ignored, and a browser without the Clipboard API does nothing. With no value the button does not render, so the fallback never reaches the clipboard. With `trailingVisibility="hover"` it keeps its space while hidden, and shows on hover, on focus inside the surface and on a coarse pointer.

### Editing

With `onCommit`, an empty value and `editing="trigger"`, the surface becomes an add button: the outlined badge with a 16px plus and `fallback`, whatever `variant` is. A click replaces it with the field, which takes focus, so typing starts at once. With `editing="inline"` the field takes the place of the value from the first render, without taking focus. The field commits on blur or Enter and discards on Escape, as [Editable Text](?path=/docs/patterns-properties-display-editabletext-api-reference--api-reference) does. With `editing="trigger"` only an empty value is editable: a value that is already there, or one just committed through the add button, shows as text.

## Accessibility and theme

- Pass `ariaLabel` when the value alone does not say what it is ("Indicação" is a source): it names the value and the field.
- Pass `labels.copy` with the thing copied ("Copiar e-mail do contato"); the copy icon carries no name of its own.
- The icon is hidden from assistive technology: put its meaning in `ariaLabel`.
- The surface reads the badge tokens of the property surface, and `muted-foreground` for the empty value.
