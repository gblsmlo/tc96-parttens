# List

A list of rows for a collection, flat or in collapsible groups: tasks by status, contacts by owner, documents by date. The consumer passes the collection and the dimension to group by, and returns each row from `renderRecord`, usually built from the `ListRow` parts; the list projects the groups, shows the loading and empty states, and keeps which groups are collapsed.

The other pages of `Patterns/Collection/Layouts/List`: [Playground](?path=/story/patterns-collection-layouts-list-playground--playground) to try the grouping, the states and the row parts, [Stories](?path=/story/patterns-collection-layouts-list-stories--default) for each state, [Behavior](?path=/story/patterns-collection-layouts-list-behavior--loading-keeps-groups-open) for the tests, [Usages](?path=/story/patterns-collection-layouts-list-usages--tasks-by-status) for tasks and a document row, and [Layouts](?path=/story/patterns-collection-layouts-list-layouts--title-only-rows) for the row parts and the group action.

Used in: [Patterns/Collection/Usages, Tasks](?path=/story/patterns-collection-usages--tasks), [Contacts](?path=/story/patterns-collection-usages--contacts), [Documents](?path=/story/patterns-collection-usages--documents) and [Campaigns](?path=/story/patterns-collection-usages--campaigns), where `CollectionLayoutOutlet` mounts the list from its `list` prop and `renderListRecord`.

## Import

```tsx
import {
  ListRow,
  ListRowAction,
  ListRowBody,
  ListRowContent,
  ListRowDescription,
  ListRowField,
  ListRowFooter,
  ListRowHeader,
  ListRowLeading,
  ListRowSkeleton,
  ListRowTitle,
  ListRowTitleTrigger,
  ListRowTrailing,
  ListView,
} from '@acme/patterns'
```

## Anatomy

<Canvas of={ApiReferenceStories.Anatomy} />

```tsx
<ListView
  collection={collection}
  emptyGroupLabel="emptyGroupLabel"
  getGroupActions={() => ({ onAddRecord })}
  grouping="status"
  renderGroupTitle={(group) => group.label}
  renderRecord={(record) => <ListRow>{/* the row parts */}</ListRow>}
/>
```

`ListView` renders one group per option of the grouping dimension, each with a header (the collapse button, the title, the count and the add action) and the rows `renderRecord` returns. The row is the consumer's, built from these parts:

<Canvas of={ApiReferenceStories.RowAnatomy} />

```tsx
<ListRow>
  <ListRowLeading />
  <ListRowBody>
    <ListRowTitle>
      <ListRowTitleTrigger onClick={open} />
    </ListRowTitle>
    <ListRowDescription />
  </ListRowBody>
  <ListRowTrailing>
    <ListRowField always />
    <ListRowAction />
  </ListRowTrailing>
</ListRow>
```

A row on one line uses the header, content and footer parts instead of the body and trailing ones:

<Canvas of={ApiReferenceStories.SingleLineRowAnatomy} />

```tsx
<ListRow>
  <ListRowHeader>
    <ListRowTitle />
    <ListRowContent />
  </ListRowHeader>
  <ListRowFooter />
</ListRow>
```

Every part but `ListRow` is optional. While `loading`, a `ListRowSkeleton` takes the place of the rows:

<Canvas of={ApiReferenceStories.SkeletonAnatomy} />

```tsx
<ListRowSkeleton media="avatar" pills={2} />
```

## ListView

The list. Renders a `div` with no role, framed (8px of padding, a rounded border and a light `card` fill) and scrolling itself: inside a flex column of bounded height it takes the remaining height, and the group headers stick to its top. It never fetches, sorts, filters or stores the records; its only state is which groups are collapsed, unless `collapsedGroupIds` controls it. Each row renders in a memoized leaf that re-runs `renderRecord` only when the record or the function changes.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `collection` | `CollectionDefinition<TRecord>` | required | Sets the records, their keys and the grouping dimensions. |
| `grouping` | `string \| null` | required | Names the dimension of `collection.groupings` to group by; `null` shows a flat list in the order of the records. |
| `renderRecord` | `(record: TRecord) => React.ReactNode` | required | Returns the whole row. |
| `groups` | `readonly CollectionGroup<TRecord>[]` | - | Sets prepared groups, used instead of projecting the collection; `[]` shows no group. |
| `separated` | `boolean` | `false` | When true, draws a line between rows. |
| `collapseEmptyGroups` | `boolean` | `false` | When true, a group with no records starts collapsed. |
| `collapsedGroupIds` | `readonly string[]` | - | Controls the collapsed groups by id; `collapseEmptyGroups` and `defaultCollapsedGroupIds` then do nothing. |
| `defaultCollapsedGroupIds` | `readonly string[]` | `[]` | Sets the groups collapsed at first, when uncontrolled. |
| `onCollapsedGroupIdsChange` | `(groupIds: readonly string[]) => void` | - | Called when a group is collapsed or expanded, with the ids of every collapsed group. |
| `getGroupActions` | `(group: CollectionGroup<TRecord>) => ListGroupActions \| undefined` | - | Returns the add action of a group header. |
| `renderGroupTitle` | `(group: CollectionGroup<TRecord>) => React.ReactNode` | - | Replaces the group heading text, and removes the group icon. |
| `emptyGroupLabel` | `React.ReactNode` or `(group: CollectionGroup<TRecord>) => React.ReactNode` | `"No items in this group."` | Sets the text of a group with no records. |
| `emptyMessage` | `React.ReactNode` | `"No items to show."` | Sets the text of a flat list with no records. |
| `loading` | `boolean` | `false` | When true, replaces the rows with skeletons, keeps every group open, hides the add actions and sets `aria-busy`. |
| `loadingRecordAnatomy` | `ListRowSkeletonAnatomy` | - | Sets the parts of each skeleton, so it matches the row. |
| `loadingRecordCount` | `number` | `1` | Sets the skeletons in each group, or in the whole list when it is flat. |
| `loadingRecordLabel` | `string` | - | Names each skeleton; without it the skeleton is named `"Loading item"`. |

| Attribute | Values | Description |
| --- | --- | --- |
| `data-slot` | `"list-view"` | Selects the list |
| `data-collection-grouping` | the `grouping` id, unset when `null` | Styles the list by grouping |
| `aria-busy` | `"true"` while `loading` | Marks the list as loading |
| `data-slot` | `"list-view-items"` | Selects the rows of a flat list |

With a `grouping`, the groups are the options of that dimension, in their declared order, each with its records in the order of the collection and the id `"<grouping>:<option id>"`. A group id no option declares gets a group of its own after them, labeled with the id; records whose group id is `null` go to a last group labeled by the dimension's `unassignedLabel` (`"Sem valor"` by default). A dimension that `collection.groupings` does not declare throws. A flat list with no records, not loading, holds one `Empty` block with `emptyMessage`.

### Collapsing groups

Uncontrolled, the list keeps the choice made on each group. With `collapseEmptyGroups`, a group with no records starts collapsed, every group stays open while `loading`, a manual choice wins, and a group nobody touched opens again when it gets records. `onCollapsedGroupIdsChange` receives the ids of every collapsed group after the change, in group order, the ones collapsed for being empty included. Controlled by `collapsedGroupIds`, the list changes nothing itself: the callback receives the list without the group, or with it added at the end.

### Groups

Each group is a `section` named by its `h2` heading, so it is a `region` landmark. Its header holds a ghost icon button named `Collapse <label>` or `Expand <label>`, the group icon (`icon` of the grouping option, left out with `renderGroupTitle`), the heading, the count of the group in a round 20px badge and, with `onAddRecord` and not loading, a plus button. The header sticks to the top of the list while its rows scroll.

| Attribute | Values | Description |
| --- | --- | --- |
| `data-slot` | `"list-group"` | Selects a group |
| `data-slot` | `"list-group-header"` | Selects the header |
| `data-slot` | `"list-group-count"` | Selects the count badge |
| `data-slot` | `"list-group-items"` | Selects the rows of a group |

## ListGroupActions

What `getGroupActions` returns for a group.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `onAddRecord` | `(groupId: string) => void` | - | Called when the plus button is clicked, with the group `id` (`"<grouping>:<option id>"`). |
| `addLabel` | `string` | `"Add item to <label>"` | Names the plus button. |

## ListRow

The row. Renders an `article`, with no content of its own: the consumer fills its parts. It is a flex row, at least 36px tall, with 12px between the parts and 8px of horizontal padding.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `density` | `"comfortable"` or `"compact"` | `"comfortable"` | Controls the vertical padding: 6px, or 4px. |
| `interactive` | `boolean` | `true` | When true, fills the row on hover. |

Also takes every prop of an `article`.

| Attribute | Values | Description |
| --- | --- | --- |
| `data-slot` | `"list-row"` | Selects the row |
| `data-density` | `"comfortable"` or `"compact"` | Styles the row by density |
| `data-interactive` | present when `interactive` | Styles a row with the hover fill |

### ListRowTitle, ListRowTitleTrigger

`ListRowTitle` is the heading of the row, truncated to one line: an `h2` in a flat `ListView`, an `h3` inside a group or outside a `ListView`. `ListRowTitleTrigger` is a `button` with `type="button"` that goes inside the title and stretches over the whole row, so a click anywhere on the row reaches it, and draws the focus ring around the row. It is the keyboard path to the record; without it the row has no button of its own. Each takes every prop of its element.

| Attribute | Values | Description |
| --- | --- | --- |
| `data-slot` | `"list-row-title"` or `"list-row-title-trigger"` | Selects the title and the trigger |

### ListRowLeading, ListRowField

`ListRowLeading` is a `div` at the start of the row, for an icon, an avatar or a checkbox. `ListRowField` is a `div` for properties, at the end of the row. A click on a plain area of either reaches the title trigger, and a control inside them (a button, a field, a menu, a checkbox) keeps its own click. A focusable element that is not a control, such as a date with a tooltip, takes the pointer, so its tooltip opens on hover, and passes its click on to the trigger. A click that comes from a portal, such as a popup opened by a property, or whose default was prevented, is not passed on.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `always` | `boolean` | `false` | On `ListRowField`: when true, shows the field below the `lg` breakpoint too, where it is hidden otherwise. |

Each takes every prop of a `div`.

| Attribute | Values | Description |
| --- | --- | --- |
| `data-slot` | `"list-row-leading"` or `"list-row-field"` | Selects each part |

### ListRowBody, ListRowDescription, ListRowTrailing, ListRowAction

`ListRowBody` is a `div` column for the title and the description that takes the remaining width. `ListRowDescription` is a muted `span`, truncated. `ListRowTrailing` is a `div` pushed to the end of the row, for fields and actions. `ListRowAction` is a `div` above the title trigger, for a menu or a button, which keeps its own click. Each takes every prop of its element.

| Attribute | Values | Description |
| --- | --- | --- |
| `data-slot` | `"list-row-body"`, `"list-row-description"`, `"list-row-trailing"` or `"list-row-action"` | Selects each part |

### ListRowHeader, ListRowContent, ListRowFooter

The parts of a row on one line. `ListRowHeader` is a `header` that takes the remaining width, for the title and the content; `ListRowContent` is a muted `div`, truncated; `ListRowFooter` is a muted `footer` pushed to the end, with tabular figures. Inside the `article` neither is a page landmark. Each takes every prop of its element.

| Attribute | Values | Description |
| --- | --- | --- |
| `data-slot` | `"list-row-header"`, `"list-row-content"` or `"list-row-footer"` | Selects each part |

## ListRowSkeleton

A loading row. Renders an `output`, whose role is `status`, named by `label`, with `aria-busy="true"` and no box of its own (`display: contents`); inside it, a `ListRow` hidden from assistive technology. Its lines have the real line heights of a row, so a row with the same parts keeps the height of the skeleton.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `string` | `"Loading item"` | Names the `status`. |
| `media` | `"icon"`, `"avatar"` or `"none"` | `"icon"` | Sets the leading shape: a 36px rounded square, a 32px circle, or none. |
| `lines` | `1` or `2` | `2` | Sets the lines of the body: the title, and the description. |
| `pills` | `number` | `3` | Sets the pills at the end of the row, hidden below `md`. |
| `action` | `boolean` | `true` | When true, adds a square for the action. |

Takes no other prop.

| Attribute | Values | Description |
| --- | --- | --- |
| `data-media` | `"icon"`, `"avatar"` or `"none"` | Reports `media` on the `output` |
| `data-lines` | `"1"` or `"2"` | Reports `lines` on the `output` |
| `data-pills` | the number of pills | Reports `pills` on the `output` |

`ListView` renders it from `loadingRecordAnatomy`, which takes the same fields except `label`.

## Exports

| Export | Kind | Description |
| --- | --- | --- |
| `ListGroup` | `component` | One collapsible group, with its header and rows; `ListView` renders it. |
| `ListViewProps`, `ListGroupProps`, `ListRowProps` | `type` | The props of `ListView`, `ListGroup` and `ListRow`. |
| `ListRowDensity` | `type` | `"comfortable"` or `"compact"`. |
| `ListRowSkeletonAnatomy`, `ListRowSkeletonMedia`, `ListRowSkeletonProps` | `type` | The fields of `loadingRecordAnatomy`, the values of `media` and the props of `ListRowSkeleton`. |

Each row part also exports its props type (`ListRowFieldProps`, `ListRowTitleTriggerProps`, …). `CollectionDefinition` and `CollectionGroup` belong to the collection: see the [API Reference of `Patterns/Collection`](?path=/docs/patterns-collection-api-reference--api-reference).

## Accessibility and theme

- Name the row by its title: put the title text in `ListRowTitleTrigger`, and name every icon-only control in the row with `aria-label`.
- The built-in texts are English (`No items to show.`, `No items in this group.`, `Loading item`, `Collapse`, `Expand`, `Add item to`); pass `emptyMessage`, `emptyGroupLabel`, `loadingRecordLabel` and `addLabel` to change them. The collapse button names cannot be changed.
- Groups are `region` landmarks named by their headings, so keep group labels distinct.
- The frame uses `card` and `border`, the hover fill `muted`, and the separators and description `border` and `muted-foreground`.
