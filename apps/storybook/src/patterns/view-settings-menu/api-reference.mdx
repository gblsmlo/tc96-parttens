# ViewSettingsMenu

The display settings of a collection in one menu: tabs for the layouts, the sections the screen passes (grouping, sorting, density, columns, filters), then the clear, reset and save items. It owns the popover and the organization of the fields: a submenu that shows its current value, the field sections with a visibility switch per field, and the item that shows every field. It keeps no state: the consumer passes the active layout, the filter count and the sections, and handles every callback. Its trigger is a toolbar button, so it only mounts inside a [CollectionToolbar](?path=/docs/patterns-collectiontoolbar-api-reference--api-reference), usually in its `right` slot.

The other pages of `Patterns/ViewSettingsMenu`: [Playground](?path=/story/patterns-viewsettingsmenu-playground--playground) to try the texts and the footer items, [Layouts](?path=/story/patterns-viewsettingsmenu-layouts--default) for the arrangements of the layout tabs, the field settings, the switch options and the property submenus, [Behavior](?path=/story/patterns-viewsettingsmenu-behavior--trigger-is-a-ghost-toolbar-button) for the tests, and [Usages](?path=/story/patterns-viewsettingsmenu-usages--task-list) for real settings menus.

Used in: the toolbar of every [Collection](?path=/story/patterns-collection-usages--tasks) usage and of the table and data grid blocks. `FilterRadioSubmenu`, an item for the filter section, is documented in [Patterns/Collection](?path=/docs/patterns-collection-api-reference--api-reference).

## ViewSettingsMenu

The settings of the view in one menu: tabs for the layouts, the consumer's sections (grouping, sorting, columns, filters), then Limpar filtros, Redefinir and Salvar preferência. Renders a ghost toolbar button with a sliders icon that opens a menu aligned to its end.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `React.ReactNode` | required | Renders the sections, between the tabs and the footer items. |
| `onClearFilters` | `() => void` | - | Called when Limpar filtros is picked; the menu stays open. Without it the item is not rendered. |
| `modes` | `readonly ViewSettingsMode<TMode>[]` | `[]` | Lists the layouts as tabs, each `{ icon, label, value }`; fewer than two show no tabs. |
| `mode` | `TMode` | - | Sets the checked tab. |
| `onModeChange` | `(mode: TMode) => void` | - | Called when a tab is picked; the menu closes. |
| `activeFilterCount` | `number` | `0` | Sets the count in the trigger, `Exibição (2)`, and enables Limpar filtros above zero. |
| `onReset` | `() => void` | - | Called when Redefinir is picked; the menu stays open and the consumer restores every setting of the menu to its default. Without it the item is not rendered. |
| `resetDisabled` | `boolean` | `false` | When true, disables Redefinir; pass it while nothing differs from the defaults. |
| `onSavePreference` | `() => void` | - | Called when Salvar preferência is picked; without it the item is not rendered. |
| `savePreferenceDisabled` | `boolean` | `false` | When true, disables Salvar preferência. |
| `label` | `string` | `"Exibição"` | Sets the text of the trigger. |
| `formatTriggerLabel` | `(label: string, activeFilterCount: number) => string` | `` `${label} (${count})` `` | Builds the trigger text when `activeFilterCount` is above zero. |
| `clearLabel` | `string` | `"Limpar filtros"` | Sets the text of the clear item. |
| `resetLabel` | `string` | `"Redefinir"` | Sets the text of the reset item. |
| `savePreferenceLabel` | `string` | `"Salvar preferência"` | Sets the text of the save item. |
| `className` | `string` | - | Adds classes to the trigger. |

The menu is 20rem (320px) wide up to three tabs, so a submenu trigger fits its label and current value with room between them, and 24rem with four or more. Up to three tabs sit in one row with the icon beside the label; four or more stack the icon above the label. Each tab is a `menuitemradio`.

| Attribute | Values | Description |
| --- | --- | --- |
| `data-slot` | `"view-settings-mode-tab"` | Selects a layout tab |
| `data-layout` | `"inline"` or `"stacked"` | Styles a tab by arrangement: `"inline"` below four tabs, `"stacked"` from four |
| `data-checked` | present on the active tab | Styles the active tab, on `background` with a shadow (`input` in dark) |

## ViewSettingsSection

A named section of the menu. Renders a menu group whose label comes first.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `React.ReactNode` | required | Sets the label of the group. |
| `children` | `React.ReactNode` | required | Renders the items and submenus of the section. |

## ViewSettingsSubmenu

A submenu of single choice whose trigger shows the current option after the label, such as `Agrupar por`, `Ordenar por` or the status of a task. Renders a submenu trigger and a radio group in the submenu; the chosen option carries a check at the end.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `string` | required | Sets the text of the trigger. |
| `options` | `readonly ViewSettingsOption<TValue>[]` | required | Lists the choices, each `{ label, value, icon? }`; `icon` is a node, so it may carry a theme color. |
| `value` | `TValue` | - | Sets the checked option and the value shown in the trigger; without it no option is checked and the trigger shows only its icon and label. |
| `onValueChange` | `(value: TValue) => void` | required | Called when an option is picked. |
| `icon` | `Icon` (Phosphor) | - | Renders before the label when the current option has no icon of its own. |

## ViewSettingsFieldSection

A section of fields, each row a switch that shows or hides the field. The label carries the count of fields, and an empty list renders nothing.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `React.ReactNode` | required | Sets the label of the section, before the count. |
| `fields` | `readonly ViewSettingsField[]` | required | Lists the fields in the order shown, each `{ id, label, visible, icon?, typeLabel? }`. |
| `onVisibleChange` | `(id: string, visible: boolean) => void` | required | Called when a switch changes; the menu stays open. |

## ViewSettingsShowAllFields

The item that shows every hidden field. Keeps the menu open.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `hiddenCount` | `number` | required | Disables the item at zero. |
| `onShowAll` | `() => void` | required | Called when the item is picked. |
| `label` | `string` | `"Mostrar todos os campos"` | Sets the text of the item. |

| Attribute | Values | Description |
| --- | --- | --- |
| `data-slot` | `"view-settings-current-value"` | Selects the current value in a `ViewSettingsSubmenu` trigger |
| `data-slot` | `"view-settings-field-count"` | Selects the count in a field section label |
| `data-field` | the field `id` | Selects one field row |

## Filter submenus

A filter submenu opens with an option for every value, `Todos` or `Todas` to agree with the filter name, checked by default. It stays checked while no value of that filter is picked; picking a value unchecks it, and picking it clears the values of that filter only. A separator divides it from the values. The [Default](?path=/story/patterns-viewsettingsmenu-layouts--default) layout shows it.

## Property submenus

A screen that sets one value per property, as in [Property Submenus](?path=/story/patterns-viewsettingsmenu-layouts--property-submenus), gives each property a `ViewSettingsSubmenu`. The rules:

- The trigger shows the icon and the label of the current option, so `Status` with `Em andamento` shows the half circle in `complete-foreground` and the text `Em andamento`.
- Status and priority icons come from the catalog in `@tc96/ui/property-meta`: `<PropertyMetaIcon meta={workflowStatusMeta.done} />`, `priorityMeta.urgent`. The catalog holds the icon and the tone only; the label is the consumer's.
- A property with an empty choice offers it as an option (`Sem prioridade`, `Sem responsável`), so the trigger still reads a value. A property with no value at all, such as a date not set, passes no `value` and shows only its icon and name.
- An icon outside the catalog takes color only from `propertyToneClassName` (`@tc96/ui/lib/property-tone`), never from the palette.
- Picking an option keeps the submenu open; Escape closes it.

## Field settings

A collection that lets the user choose its fields composes the parts above, as in [Field Settings](?path=/story/patterns-viewsettingsmenu-layouts--field-settings) ([open](?path=/story/patterns-viewsettingsmenu-layouts--field-settings-open)). The parts render what they receive: the consumer groups, sorts and filters the fields and passes each group ready. The rules:

- Grouping and sorting are two submenus, never one list of combinations. `Agrupar por` offers `Nenhum`, `Tipo` and `Visibilidade`; `Ordenar por` offers `Manual`, `Nome A-Z` and `Nome Z-A`.
- The name order applies inside each group. "By type, in alphabetical order" is `Tipo` plus `Nome A-Z`, not a fourth option.
- Both are `ViewSettingsSubmenu`, inside one `ViewSettingsSection` named `Organizar campos`, so each trigger shows its current value.
- The default is `Visibilidade` with `Manual`: `Visíveis` comes before `Ocultos`, and `Manual` keeps the order the consumer passes.
- Each group is a `ViewSettingsFieldSection`; an empty group is not rendered. Without grouping, one section named `Campos` holds every field.
- The switch shows or hides the field and the menu stays open. Grouped by visibility, the field moves to the other group at once.
- The row shows the type icon and the name; pass `typeLabel` only when the list is not grouped by type, where it would repeat the group label.
- Type labels are words the user reads (`Texto`, `Seleção`, `Pessoa`, `Data`, `Número`), never the storage type.
- `ViewSettingsShowAllFields` closes the field sections.
- The menu does not reorder fields by drag; a manual order is edited elsewhere and arrives in the order the consumer passes.

## Accessibility and theme

- The trigger text and the footer items are in Portuguese by default (`"Exibição"`, `"Limpar filtros"`, `"Redefinir"`, `"Salvar preferência"`): pass `label`, `clearLabel`, `resetLabel` and `savePreferenceLabel` in the language of the screen, and `formatTriggerLabel` when the count needs another grammar.
- The field rows are `menuitemcheckbox` items with a switch look; the default `Mostrar todos os campos` is in Portuguese, so pass `label` in the language of the screen.
- The layout tabs are `menuitemradio` items of the menu, so the arrow keys move between them and Enter picks one; picking a tab closes the menu.
- The menu reads `--popover`, `--popover-foreground` and `--border`; the active tab `--background` (`--input` in dark) with a shadow, the others `--muted-foreground`, and the icon square `--primary`. The trigger reads the tokens of the ghost `Button`.
