# CRM

Widgets for sales and relationship work: the funnel of a team, its biggest open deals, the latest interactions and the card of one contact. They answer "where is the pipeline", "what is about to close", "who talked to whom" and "how do I reach this person".

The other pages of `Patterns/Widgets/CRM`: [Playground](?path=/story/patterns-widgets-crm-playground--playground) to try each widget with its title, header action, empty data and expansion, [Stories](?path=/story/patterns-widgets-crm-stories--default) for each widget and the empty state, [Behavior](?path=/story/patterns-widgets-crm-behavior--pipeline-sums-the-stages) for the tests of every widget, [Usages](?path=/story/patterns-widgets-crm-usages--sales-dashboard) for a sales dashboard and each widget with real data, and [Layouts](?path=/story/patterns-widgets-crm-layouts--pipeline-with-periods) for the pipeline with a period switch, deals with no details and the contact with fewer parts.

The frame, `Amount`, `TrendIndicator`, `WidgetPeriodToggle`, `ExpandableList` and `AvatarStack` that these widgets are built from are documented on [Patterns/Widgets](?path=/docs/patterns-widgets-api-reference--api-reference); the key numbers and lead sources of a CRM dashboard are `MetricWidget`, on [Patterns/Widgets/Stats](?path=/docs/patterns-widgets-stats-api-reference--api-reference), and `MarketShareWidget`, on [Patterns/Widgets/Finance](?path=/docs/patterns-widgets-finance-api-reference--api-reference).

Used in: [Templates/Contact Detail](?path=/story/templates-contact-detail--default) mounts a `DealsWidget` and an `ActivityFeedWidget` for the contact's company.

## Import

```tsx
import {
  ActivityFeedWidget,
  ContactWidget,
  DealsWidget,
  PipelineWidget,
} from '@acme/patterns'
```

## Anatomy

<Canvas of={ApiReferenceStories.Anatomy} />

Every widget renders a `WidgetShell` named by its title, with `data-widget` set to its name. The four of the family:

```tsx
<PipelineWidget title="Sales pipeline" stages={stages} />
<DealsWidget title="Top deals" deals={deals} />
<ActivityFeedWidget title="Recent activity" activities={activities} />
<ContactWidget person={person} email={email} activities={activities} />
```

The widgets are controlled: the consumer passes prepared data and receives events through callbacks. They never fetch, sort or store anything; the only state is the uncontrolled expansion of a list that is longer than `visibleCount`. The default texts (`Total no funil`, `Sem negócios`, `Responsável`, `Atividade recente`, `E-mail`) are Portuguese strings exposed as props. Values go through `format` (`AmountFormatOptions`), US dollars by default.

## PipelineWidget

The stages of a funnel with their total. Renders a `WidgetShell` with a header (title and `action`, or the period switch), the sum of the stages as a large amount with `totalLabel` under it, and an `ol` of stages: label, count, value and a bar scaled to the largest stage.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | `ReactNode` | required | Sets the title of the card; names the region. |
| `stages` | `readonly PipelineStage[]` | required | Lists the stages in order, each `{ id: string, label: ReactNode, value: number, count: number, color?: string }`. |
| `totalLabel` | `ReactNode` | `"Total no funil"` | Sets the caption under the total. |
| `periods` | `readonly WidgetPeriodOption[]` | - | Lists the periods; with items, the card shows a `WidgetPeriodToggle` in the header instead of `action`. |
| `period` | `string` | - | Sets the selected period. |
| `onPeriodChange` | `(period: string) => void` | - | Called when the user selects a period, with its `value`. |
| `periodLabel` | `string` | - | Names the period group (`aria-label`). |
| `action` | `ReactNode` | - | Renders at the end of the header; dropped when `periods` has items. |
| `countLabel` | `(count: number) => ReactNode` | `` `${count}` `` | Renders the count beside each stage label. |
| `format` | `AmountFormatOptions` | `{ style: "currency" }` | Sets how the total and the stage values read. |
| `listLabel` | `string` | the `title` when it is a string, else `"Etapas"` | Names the `ol`. |
| `expand` | `WidgetExpandProps` | - | Configures the `ExpandableList` of stages. |

Also takes every prop of a `div`, except `children` and `title`. The component is generic on the period type.

The total sums `max(0, value)` of every stage. Each bar is scaled to the largest value and takes `color`, or `--chart-1` to `--chart-5` by position; a stage's share of the total is read in `sr-only` text (`50.00%`), with the locale of `format`.

| Attribute | Values | Description |
| --- | --- | --- |
| `data-widget` | `"pipeline"` | Selects the frame |
| `data-slot` | `"pipeline-stages"` | Selects the `ol` |
| `data-slot` | `"pipeline-stage"` | Selects each `li` |

## DealsWidget

The open deals of an account or a team. Renders a `WidgetShell` with a header (title and `action`) and a `DealList` of `DealListItem`, or the empty label when `deals` is empty.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | `ReactNode` | required | Sets the title of the card; names the region. |
| `deals` | `readonly Deal[]` | required | Lists the deals in order; see `Deal` below. |
| `emptyLabel` | `ReactNode` | `"Sem negócios"` | Renders in place of the list when `deals` is empty. |
| `ownerLabel` | `string` | `"Responsável"` | Names the owner's `AvatarStack` on each row. |
| `action` | `ReactNode` | - | Renders at the end of the header. |
| `format` | `AmountFormatOptions` | `{ style: "currency" }` | Sets how each value reads. |
| `listLabel` | `string` | the `title` when it is a string, else `"Negócios"` | Names the list. |
| `expand` | `WidgetExpandProps` | - | Configures the `ExpandableList` of deals. |

Also takes every prop of a `div`, except `children` and `title`.

| Attribute | Values | Description |
| --- | --- | --- |
| `data-widget` | `"deals"` | Selects the frame |
| `data-slot` | `"deals-empty"` | Selects the empty label's `p` |

### Deal

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `id` | `string` | required | Identifies the deal; the key of its row. |
| `name` | `ReactNode` | required | Sets the name of the deal. |
| `value` | `number` | required | Sets the amount of the deal. |
| `company` | `ReactNode` | - | Renders under the name, before the close label. |
| `closeLabel` | `ReactNode` | - | Renders under the name, after a dot, when there is a company. |
| `icon` | `ReactNode` | - | Renders before the name, usually an `IconFrame`. |
| `owner` | `AvatarStackPerson` | - | Renders an `AvatarStack` of one person, at the end of the row. |
| `stage` | `DealStage` | - | Renders a `Badge`: `{ label: ReactNode, tone?: WidgetTone }`, with `tone` defaulting to `"info"`. |

### DealList and DealListItem

`DealList` renders a `ul` with dividers between rows and takes every prop of a `ul`. `DealListItem` renders the `li` of one deal from the fields above (`name`, `value`, `company`, `closeLabel`, `icon`, `owner`, `stage`), plus `format` and `ownerLabel`, and takes every prop of an `li`. Use them to build a list of deals outside the widget.

| Attribute | Values | Description |
| --- | --- | --- |
| `data-slot` | `"deal-list"` | Selects the `ul` |
| `data-slot` | `"deal-list-item"` | Selects each row |
| `data-slot` | `"deal-stage"` | Selects the stage badge |
| `data-tone` | `"destructive"`, `"info"`, `"success"` or `"warning"` | Names the tone of the stage badge; the badge variant follows it (`destructive` is `error`) |

## ActivityFeedWidget

The latest interactions of a record. Renders a `WidgetShell` with a header (title and `action`) and an `ActivityTimeline`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | `ReactNode` | required | Sets the title of the card; names the region. |
| `activities` | `readonly Activity[]` | required | Lists the interactions in order; see `Activity` below. |
| `emptyLabel` | `ReactNode` | `"Sem atividades"` | Renders in place of the timeline when `activities` is empty. |
| `listLabel` | `string` | the `title` when it is a string, else `"Atividades"` | Names the timeline. |
| `action` | `ReactNode` | - | Renders at the end of the header. |
| `expand` | `WidgetExpandProps` | - | Configures the `ExpandableList` of interactions. |

Also takes every prop of a `div`, except `children` and `title`. Its `data-widget` is `"activity-feed"`.

## ActivityTimeline

The timeline of interactions that `ActivityFeedWidget` and `ContactWidget` share, exported to use on its own. Renders an `ol` of items, each with the person's avatar, an optional icon badge on the avatar, the person's name followed by the title, the time label and the description; or a `p` with `emptyLabel` when there are no activities.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `aria-label` | `string` | required | Names the `ol`. |
| `activities` | `readonly Activity[]` | required | Lists the interactions in order. |
| `emptyLabel` | `ReactNode` | `"Sem atividades"` | Renders in place of the list when it is empty. |
| `expand` | `WidgetExpandProps` | - | Configures the `ExpandableList`. |

Also takes every prop of an `ol`, except `children`.

| Attribute | Values | Description |
| --- | --- | --- |
| `data-slot` | `"activity-feed-list"` | Selects the `ol` |
| `data-slot` | `"activity-feed-item"` | Selects each `li` |
| `data-slot` | `"activity-feed-icon"` | Selects the icon badge, present only when the activity has an `icon` |
| `data-slot` | `"activity-feed-empty"` | Selects the empty label's `p` |

### Activity

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `id` | `string` | required | Identifies the activity; the key of its row. |
| `person` | `AvatarStackPerson` | required | Sets who acted; the avatar and the name before the title. |
| `title` | `ReactNode` | required | Sets what they did, read after the name. |
| `timeLabel` | `ReactNode` | required | Sets when, already formatted. |
| `description` | `ReactNode` | - | Renders under the title. |
| `icon` | `ReactNode` | - | Renders in a badge at the corner of the avatar; hidden from assistive technology. |
| `tone` | `WidgetTone` | - | Colors the icon with the matching `-foreground` token. |

## ContactWidget

The card of one person: avatar, name, role and company, tags, channels and recent activity. Renders a `WidgetShell` named by `person.label`, which is also its heading.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `person` | `AvatarStackPerson` | required | Sets the name, the avatar fallback and the optional image. |
| `jobTitle` | `ReactNode` | - | Renders under the name, before the company. |
| `company` | `ReactNode` | - | Renders under the name, after the job title and a dot. |
| `tags` | `readonly ContactTag[]` | - | Lists outline badges, each `{ id: string, label: ReactNode }`. |
| `email` | `string` | - | Adds a channel link with `mailto:`. |
| `phone` | `string` | - | Adds a channel link with `tel:`, with the value as received. |
| `whatsapp` | `string` | - | Adds a channel link to `https://wa.me/` with the digits of the value. |
| `channelLabels` | `ContactChannelLabels` | `{ email: "E-mail", phone: "Ligar", whatsapp: "WhatsApp" }` | Sets the text of each channel link. |
| `activities` | `readonly Activity[]` | - | Sets the recent activity; `undefined` hides the section and `[]` shows `emptyLabel`. |
| `activitiesLabel` | `string` | `"Atividade recente"` | Sets the heading and the name of the timeline. |
| `emptyLabel` | `ReactNode` | `"Sem atividades"` | Renders when `activities` is `[]`. |
| `action` | `ReactNode` | - | Renders at the end of the top row, usually an icon button. |
| `expand` | `WidgetExpandProps` | - | Configures the `ExpandableList` of the activity. |

Also takes every prop of a `div`, except `children` and `title`. A channel renders only for a value the widget receives, as a `Button` (`outline`, `sm`) through `render={<a />}`; the WhatsApp link opens with `target="_blank"` and `rel="noreferrer"`. The avatar is the `xl` size.

| Attribute | Values | Description |
| --- | --- | --- |
| `data-widget` | `"contact"` | Selects the frame |
| `data-slot` | `"contact-tags"` | Selects the tag list |
| `data-slot` | `"contact-channels"` | Selects the channel row |
| `data-channel` | `"email"`, `"phone"` or `"whatsapp"` | Names the channel on each link |

`ContactChannelLabels` is `{ email: string, phone: string, whatsapp: string }`.

## Accessibility and theme

- Every widget is a `region` named by its title; `ContactWidget` is named by the person. Keep titles unique on a page.
- The lists are named (`listLabel`, `activitiesLabel`, `ownerLabel`) with the strings of the consumer's language; pass them all when the page is not in Portuguese.
- A stage's share, a deal's stage and an activity's tone are in text or `sr-only` text; the bar and the icon color are decoration.
- The theme supplies the `--chart-1` to `--chart-5` bar colors and the `success`, `destructive`, `info` and `warning` foreground tokens that tint the stage badges and the activity icons.
- Contrast ratios and the avatar wrapper decision are in `docs/accessibility.md`, section `widgets`.
