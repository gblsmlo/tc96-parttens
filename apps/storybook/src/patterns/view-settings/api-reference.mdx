# ViewSettings

The display settings of a collection in one menu: tabs for the layouts, the sections the screen passes (grouping, sorting, density, columns, filters), then the clear and save items. It keeps no state: the consumer passes the active layout, the filter count and the sections, and handles every callback. Its trigger is a toolbar button, so it only mounts inside a [CollectionToolbar](?path=/docs/patterns-collectiontoolbar-api-reference--api-reference), usually in its `right` slot.

The other pages of `Patterns/ViewSettings`: [Playground](?path=/story/patterns-viewsettings-playground--playground) to try the texts and the footer items, [Layouts](?path=/story/patterns-viewsettings-layouts--default) for the arrangements of the layout tabs, [Behavior](?path=/story/patterns-viewsettings-behavior--trigger-is-a-ghost-toolbar-button) for the tests, and [Usages](?path=/story/patterns-viewsettings-usages--task-list) for real settings menus.

Used in: the toolbar of every [Collection](?path=/story/patterns-collection-usages--tasks) usage and of the table and data grid blocks. `FilterRadioSubmenu`, an item for the filter section, is documented in [Patterns/Collection](?path=/docs/patterns-collection-api-reference--api-reference).

## Import

```tsx
import { ViewSettingsMenu, ViewSettingsSection } from '@acme/patterns'
```

```text

div[role=menu]                                  portaled, aligned to the end of the trigger
├── div[data-slot=menu-radio-group]             layout tabs, only with two modes or more
│   └── div[role=menuitemradio][data-slot=view-settings-mode-tab]
├── children                                    the sections, as passed
├── div[data-slot=menu-separator]
├── div[role=menuitem]                          Limpar filtros, only with onClearFilters
└── div[role=menuitem]                          Salvar preferência, only with onSavePreference
```

## ViewSettingsMenu

The settings of the view in one menu: tabs for the layouts, the consumer's sections (grouping, sorting, columns, filters), then Limpar filtros and Salvar preferência. Renders a ghost toolbar button with a sliders icon that opens a menu aligned to its end.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `React.ReactNode` | required | Renders the sections, between the tabs and the footer items. |
| `onClearFilters` | `() => void` | - | Called when Limpar filtros is picked; without it the item is not rendered. |
| `modes` | `readonly ViewSettingsMode<TMode>[]` | `[]` | Lists the layouts as tabs, each `{ icon, label, value }`; fewer than two show no tabs. |
| `mode` | `TMode` | - | Sets the checked tab. |
| `onModeChange` | `(mode: TMode) => void` | - | Called when a tab is picked; the menu closes. |
| `activeFilterCount` | `number` | `0` | Sets the count in the trigger, `Exibição (2)`, and enables Limpar filtros above zero. |
| `onSavePreference` | `() => void` | - | Called when Salvar preferência is picked; without it the item is not rendered. |
| `savePreferenceDisabled` | `boolean` | `false` | When true, disables Salvar preferência. |
| `label` | `string` | `"Exibição"` | Sets the text of the trigger. |
| `formatTriggerLabel` | `(label: string, activeFilterCount: number) => string` | `` `${label} (${count})` `` | Builds the trigger text when `activeFilterCount` is above zero. |
| `clearLabel` | `string` | `"Limpar filtros"` | Sets the text of the clear item. |
| `savePreferenceLabel` | `string` | `"Salvar preferência"` | Sets the text of the save item. |
| `className` | `string` | - | Adds classes to the trigger. |

The width of the menu follows the number of tabs: 14rem (224px) with fewer than two, 16rem with two, 18rem with three, 24rem with four or more. Up to three tabs sit in one row with the icon beside the label; four or more stack the icon above the label. Each tab is a `menuitemradio`.

| Attribute | Values | Description |
| --- | --- | --- |
| `data-slot` | `"view-settings-mode-tab"` | Selects a layout tab |
| `data-layout` | `"inline"` or `"stacked"` | Styles a tab by arrangement: `"inline"` below four tabs, `"stacked"` from four |
| `data-checked` | present on the active tab | Styles the active tab, on `background` with a shadow (`input` in dark) |

## ViewSettingsSection

A named section of the menu. Renders a menu group whose label comes first.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `React.ReactNode` | required | Sets the label of the group. |
| `children` | `React.ReactNode` | required | Renders the items and submenus of the section. |

## Exports

| Export | Kind | Description |
| --- | --- | --- |
| `ViewSettingsMenuProps` | `type` | The props of `ViewSettingsMenu`. |
| `ViewSettingsMode` | `type` | One tab of `ViewSettingsMenu`, `{ icon, label, value }`. |
| `ViewSettingsSectionProps` | `type` | The props of `ViewSettingsSection`. |

## Accessibility and theme

- The trigger text and the footer items are in Portuguese by default (`"Exibição"`, `"Limpar filtros"`, `"Salvar preferência"`): pass `label`, `clearLabel` and `savePreferenceLabel` in the language of the screen, and `formatTriggerLabel` when the count needs another grammar.
- The layout tabs are `menuitemradio` items of the menu, so the arrow keys move between them and Enter picks one; picking a tab closes the menu.
- The menu reads `--popover`, `--popover-foreground` and `--border`; the active tab `--background` (`--input` in dark) with a shadow, the others `--muted-foreground`, and the icon square `--primary`. The trigger reads the tokens of the ghost `Button`.
