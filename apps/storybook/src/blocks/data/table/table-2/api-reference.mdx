# Table2

A member table on the collection Data Table (a semantic `<table>`), the same screen as `DataGrid2`: avatar with presence, role, team, rating, last seen, activity and join date, with a toolbar that holds the saved views and one settings menu (sort, displayed columns, row height, filters and save) and a footer with the page size. Reach for it on a team or people screen where each person has a few measurable properties. Install it with `npx @tc96/cli add table-2`.

It is a section, not a page: it renders no `main` landmark. The heading is the toolbar's: one `CollectionToolbar` with `variant="text"` carries `labels.title` as the only `h2` and `labels.summary` (the member count after the filters) as its description, then the view switcher (`ViewSwitcherMenu`) and the `ViewSettingsMenu`, whose sections are `DataGridSortSubmenu`, `DataTableColumnsSubmenu` and `DataGridDensitySubmenu` and two `FilterRadioSubmenu`s. The table keeps the role and team filters, the page and the page size locally; the sort, the column visibility and the density are the ones a consumer saves, so they are controllable (`sort`, `columnVisibility`, `density`) and reported (`onSortChange`, `onColumnVisibilityChange`, `onDensityChange`). The block never applies a view, never filters the members by `showPaused` and never saves: a view change, Salvar preferência and the paused item are callbacks, and the consumer passes back the sort, columns and density of the chosen view. Loading and error are the block's: the toolbar keeps the heading and hides its controls, `pending` renders its skeleton in place of the table and `error` an error surface with a retry button; the precedence is `pending`, then `error`.

The other pages of `Blocks/Data/Table/Table2`: [Playground](?path=/story/blocks-data-table-table2-playground--playground) to try the controls, [Behavior](?path=/story/blocks-data-table-table2-behavior--each-row-shows-the-member-details) for the tests, [States](?path=/story/blocks-data-table-table2-states--default) for the loaded, loading, error and empty states and [Usages](?path=/story/blocks-data-table-table2-usages--loaded) for the data read over the network.

## Import

```tsx
import { Table2 } from '@tc96/ui/blocks/data/table/table-2'
```

The same path exports the types listed under Exports.

## Anatomy

The toolbar with the heading, the member count, the view switcher and the Configurações menu, the table and the pagination footer with Linhas por página.

```tsx
<Table2
  activeViewId={activeViewId}
  members={members}
  onSortChange={setSort}
  onViewChange={selectView}
  pageSizeOptions={[10, 20, 50]}
  sort={sort}
  views={views}
/>
```

## Table2

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `members` | `Table2Member[]` | required | The rows. Keep the array stable between renders. |
| `sort` | `Table2Sort \| null` | - | Controls the sort. When it changes the table follows it; without it the table sorts locally. |
| `onSortChange` | `(sort: Table2Sort \| null) => void` | - | Called once per sort change, from the Ordenação submenu; the table has no column menu. |
| `columnVisibility` | `Table2ColumnVisibility` | `{ location: false, priority: false }` initially | Controls the visible columns; a column is hidden only when its value is `false`. |
| `onColumnVisibilityChange` | `(visibility: Table2ColumnVisibility) => void` | - | Called once per change, from the Propriedades exibidas submenu. |
| `density` | `Table2Density` | `"tall"` | The row height: `short`, `medium`, `tall` or `extra-tall`. Controlled only with `onDensityChange`. |
| `onDensityChange` | `(density: Table2Density) => void` | - | Called when the Altura das linhas submenu changes the density. |
| `views` | `Table2View[]` | - | The saved views, `{ id, label }`. The view switcher renders only with it. |
| `activeViewId` | `string` | - | The selected view; its label is the trigger text, `labels.viewSelect` without a match. |
| `onViewChange` | `(viewId: string) => void` | - | Called when a view is picked. The block does not apply it: the consumer passes the view's `sort`, `columnVisibility` and `density`. |
| `onViewCreate` | `() => void` | - | The Criar nova view item renders only with it. |
| `showPaused` | `boolean` | `false` | The state of the Mostrar membros pausados item. |
| `onShowPausedChange` | `(showPaused: boolean) => void` | - | The item renders only with this callback. The block does not filter `members`. |
| `onSave` | `(settings: Table2Settings) => void` | - | Called by Salvar preferência with the sort, the full column visibility, the density and `showPaused`; the item renders only with it. |
| `pageSize` | `number` | `10` | Initial rows per page of the footer. |
| `pageSizeOptions` | `readonly number[]` | `[10, 20, 50]` | The choices of the Linhas por página selector; `pageSize` joins them when it is not listed. |
| `locale` | `string` | `"pt-BR"` | Locale of the dates and numbers. |
| `currency` | `string` | `"BRL"` | Part of the shared format props; this block shows no amount. |
| `pending` | `boolean` | `false` | Renders the skeleton in place of the table; wins over `error`. |
| `error` | `boolean` | `false` | Renders the error surface. |
| `onRetry` | `() => void` | - | Called by the Tentar novamente button; without it the button is not rendered. |
| `labels` | `Partial<Table2Labels>` | pt-BR texts | Overrides the texts of the block; `columns`, `densities` and `presence` merge key by key. Keep the object stable, because the columns are rebuilt when it changes. |
| `className` | `string` | - | Merged into the root classes. |

## Accessibility and theme

- The block renders a semantic `table` with column headers and no grid keyboard model, so Tab moves only through the controls and sorting lives in the settings menu; the skeleton is `aria-busy="true"` and named by `labels.loading`, and the error surface has the `alert` role.
- The presence dot, the stars and the ring are decorative: each has a hidden text with its meaning, so the cells never depend on color or shape alone.
- The view switcher is a popover (`role="dialog"`) with a search field and one button per view, the selected one with `aria-current`; the settings are a menu whose submenus use `menuitemradio` and `menuitemcheckbox`.
- The block carries no color, radius or shadow of its own beyond token classes: the theme belongs to the app.
