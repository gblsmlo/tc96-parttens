# Table8

A transaction ledger on the collection Data Table, a semantic `<table>`: transaction and charge id, customer, amount, status, payment method with the last four digits, channel, risk score and date, in a table of bounded height that asks for the next page when the scroll nears the end. Reach for it on a payments or billing screen where the list is far longer than what is loaded. Install it with `npx @tc96/cli add table-8`.

It is a section, not a page: it renders no `main` landmark. A real ledger sorts, filters and searches on the server, so the block never reorders or filters `transactions`: the sort, the filters, the search, the view, the selection, the density and the column visibility are controlled and every change is a callback. The Data Table has no virtualization, so every loaded row is in the DOM; the table scrolls inside a viewport of `maxHeight` pixels, and when that scroll comes within eight rows of the end it calls `onLoadMore` once per `transactions.length`, only while `hasMore` is true; `loadingMore` appends skeleton rows and holds the next call. The heading is the toolbar's: one `CollectionToolbar` with `variant="text"` carries `labels.title` as the only `h2` and the loaded count as its description, then the view switcher, the search, Atualizar, Configurações de visualização and Exportar. Selected rows open the pattern's `ActionBar` floating over the table, with the count and the selected total, Exportar, Estornar and Sinalizar. Loading and error are the block's: the toolbar keeps the heading and hides its controls, `pending` renders the skeleton in place of the table and `error` an error surface with a retry button; the precedence is `pending`, then `error`.

The other pages of `Blocks/Data/Table/Table8`: [Playground](?path=/story/blocks-data-table-table8-playground--playground) to try the controls, [Behavior](?path=/story/blocks-data-table-table8-behavior--each-row-shows-the-transaction) for the tests, [States](?path=/story/blocks-data-table-table8-states--default) for the loaded, loading, loading more, error and empty states and [Usages](?path=/story/blocks-data-table-table8-usages--loaded) for pages read over the network with `useInfiniteQuery`.

## Import

```tsx
import { Table8 } from '@tc96/ui/blocks/data/table/table-8'
```

The same path exports `emptyTable8Filters` and the types listed under Exports.

## Anatomy

The toolbar with the heading, the loaded count, the view switcher, the search, Atualizar, Configurações de visualização (sort, row height and columns, then the Status, Método and Canal filters) and Exportar; the table in its scrolling viewport; the `ActionBar` floating over it while rows are selected.

```tsx
<Table8
  hasMore={hasNextPage}

  onLoadMore={fetchNextPage}
  onSortChange={setSort}
  sort={sort}
  totalCount={total}

/>
```

## Table8

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `transactions` | `Table8Transaction[]` | required | The loaded rows, already sorted and filtered. Keep the array stable between renders. |
| `totalCount` | `number` | required | Rows on the server for the current query; the second number of the toolbar description. |
| `loadedCount` | `number` | `transactions.length` | The first number of the toolbar description. |
| `hasMore` | `boolean` | `false` | Whether the server has another page; without it `onLoadMore` is never called. |
| `onLoadMore` | `() => void` | - | Called once per `transactions.length` when the scroll nears the end. |
| `loadingMore` | `boolean` | `false` | Appends skeleton rows, sets `aria-busy` on the table and holds `onLoadMore`. |
| `maxHeight` | `number` | `560` | Maximum height of the scrolling viewport in pixels. Every loaded row renders, so keep the loaded pages to a few hundred rows or move to `DataGrid8`, which virtualizes. |
| `sort` | `Table8Sort \| null` | - | The sort the rows arrive in; the column headers and the Ordenar por menu show it. |
| `onSortChange` | `(sort: Table8Sort \| null) => void` | - | Called once per sort change. The block does not reorder the rows. |
| `filters` | `Table8Filters` | `emptyTable8Filters` | The Status, Método and Canal filters; `''` means all. |
| `onFiltersChange` | `(filters: Table8Filters) => void` | - | Called with every filter; the Filtros section renders only with it. Limpar filtros sends `emptyTable8Filters`. |
| `search` | `string` | `''` | The committed search. |
| `onSearchChange` | `(search: string) => void` | - | Called on submit and when the field is cleared, never per keystroke; the field renders only with it. |
| `views`, `activeViewId` | `Table8View[]`, `string` | - | The saved views and the active one. |
| `onViewChange` | `(viewId: string) => void` | - | The view switcher renders only with `views` and this callback. |
| `onViewCreate` | `() => void` | - | Renders Criar visualização in the switcher. |
| `selectedIds` | `string[]` | - | Controls the selected rows; without it the table keeps them. |
| `onSelectedIdsChange` | `(ids: string[]) => void` | - | Called once per selection change. |
| `onExportSelected`, `onRefund`, `onFlag` | `(ids: string[]) => void` | - | The `ActionBar` items, called with the selected ids; each renders only with its callback. |
| `onExport` | `() => void` | - | The Exportar button of the toolbar; renders only with it. |
| `onRefresh` | `() => void` | - | The Atualizar button; renders only with it. |
| `refreshing` | `boolean` | `false` | Spins the Atualizar icon and disables the button. |
| `density` | `Table8Density` | `'tall'` | Row height; `short` and `medium` hide the second line of the two-line cells. |
| `onDensityChange` | `(density: Table8Density) => void` | - | Called by the Altura das linhas menu; without it the table keeps the density. |
| `columnVisibility` | `Table8ColumnVisibility` | - | Controls the visible columns; a column is hidden only when its value is `false`. |
| `onColumnVisibilityChange` | `(visibility: Table8ColumnVisibility) => void` | - | Called by the Colunas menu or a column menu. |
| `locale` | `string` | `"pt-BR"` | Locale of the amounts, counts and dates. |
| `currency` | `string` | `"BRL"` | Currency of the amounts. |
| `pending` | `boolean` | `false` | Renders the skeleton in place of the table and keeps only the heading in the toolbar; wins over `error`. |
| `error` | `boolean` | `false` | Renders the error surface below the heading. |
| `onRetry` | `() => void` | - | Called by Tentar novamente; without it the button is not rendered. |
| `labels` | `Table8LabelsOverride` | pt-BR texts | Overrides the texts; `columns`, `statuses`, `methods`, `channels` and `riskBands` merge key by key. Keep the object stable, because the columns are rebuilt when it changes. |
| `className` | `string` | - | Merged into the root classes. |

## Table8Transaction

| Field | Type | Description |
| --- | --- | --- |
| `id`, `chargeId` | `string` | The transaction id (row id) and the processor charge id, both in monospace. |
| `customer` | `{ name; email; imageUrl? }` | Avatar, name and e-mail; the initials stand in for a missing image. |
| `amount` | `number` | Raw amount, formatted with `locale` and `currency`. |
| `status` | `'settled' \| 'pending' \| 'refunded' \| 'failed'` | Liquidada, Pendente, Estornada, Falhou. |
| `method`, `lastFour` | `'card' \| 'apple-pay' \| 'google-pay' \| 'paypal'`, `string` | Method icon and the masked last four digits. |
| `channel` | `'api' \| 'web' \| 'mobile' \| 'pos'` | Channel icon and name. |
| `risk` | `number` | Score from 0 to 100: below 40 low, below 70 medium, otherwise high. |
| `createdAt` | `string` | ISO date and time, shown as day and time. |

## Accessibility and theme

- The table is a semantic `<table>` named by `labels.title`, not a WAI-ARIA grid: Tab walks the checkboxes in reading order and there is no arrow key navigation or `aria-rowcount`; the table is `aria-busy` while more rows load.
- The method icon, the masked digits, the risk dot and the status dot are decorative: the method and the risk carry a hidden text with their meaning, and the status is a word, so no cell depends on color alone.
- The status is an outline badge with a colored dot: a tinted success badge measured 3.97:1 on a selected row.
- The `ActionBar` is a `toolbar` named by `labels.selectionActions`.
- The block carries no color, radius or shadow of its own beyond token classes: the theme belongs to the app.
