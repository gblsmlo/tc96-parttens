# Team1

A member table on the collection Data Grid: avatar with presence, role, team, rating, last seen, activity and join date, with a toolbar that holds the heading and one settings menu (sort, displayed columns, row height, filters and save) and a footer with the page size. Reach for it on a team or people screen where each person has a few measurable properties. Install it with `npx @tc96/cli add team-1`.

It is a section, not a page: it renders no `main` landmark. The heading is the toolbar's: the `left` slot of one `CollectionToolbar` carries `labels.title` as the only `h2` and `labels.summary` (the member count after the filters) as its description, and the `right` slot the `ViewSettings`, whose sections are the Data Grid submenus (`DataGridSortSubmenu`, `DataGridColumnsSubmenu`, `DataGridDensitySubmenu`) and two `FilterRadioSubmenu`s. The Data Grid keeps the role and team filters, the page, the page size and the column sizes locally; the sort, the column visibility and the density are the ones a consumer saves, so they are controllable (`sort`, `columnVisibility`, `density`) and reported (`onSortChange`, `onColumnVisibilityChange`, `onDensityChange`). The screen has no saved views. The block never filters the members by `showPaused` and never saves: Salvar preferência and the paused item are callbacks, and Salvar preferência reports the current display settings (`Team1Settings`) for the consumer to keep as the member's preference. Loading and error are the block's: the toolbar keeps the heading and hides its controls, `pending` renders its skeleton in place of the grid and `error` an error surface with a retry button; the precedence is `pending`, then `error`.

The other pages of `Blocks/Data/Team/Team1`: [Playground](?path=/story/blocks-data-team-team1-playground--playground) to try the controls, [Behavior](?path=/story/blocks-data-team-team1-behavior--each-row-shows-the-member-details) for the tests, [States](?path=/story/blocks-data-team-team1-states--default) for the loaded, loading, error and empty states and [Usages](?path=/story/blocks-data-team-team1-usages--loaded) for the data read over the network.

## Import

```tsx
import { Team1 } from '@tc96/ui/blocks/data/team/team-1'
```

The same path exports the types listed under Exports.

## Anatomy

The toolbar with the heading, the member count and the Configurações menu, the grid and the pagination footer with Linhas por página.

## Team1

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `members` | `Team1Member[]` | required | The rows. Keep the array stable between renders. |
| `sort` | `Team1Sort \| null` | - | Controls the sort. When it changes the grid follows it; without it the grid sorts locally. |
| `onSortChange` | `(sort: Team1Sort \| null) => void` | - | Called once per sort change, from the Ordenação submenu or from a column menu. |
| `columnVisibility` | `Team1ColumnVisibility` | `{ location: false, priority: false }` initially | Controls the visible columns; a column is hidden only when its value is `false`. |
| `onColumnVisibilityChange` | `(visibility: Team1ColumnVisibility) => void` | - | Called once per change, from the Propriedades exibidas submenu or from a column menu. |
| `density` | `Team1Density` | `"tall"` | The row height: `short`, `medium`, `tall` or `extra-tall`. Controlled only with `onDensityChange`. |
| `onDensityChange` | `(density: Team1Density) => void` | - | Called when the Altura das linhas submenu changes the density. |
| `showPaused` | `boolean` | `false` | The state of the Mostrar membros pausados item. |
| `onShowPausedChange` | `(showPaused: boolean) => void` | - | The item renders only with this callback. The block does not filter `members`. |
| `onSave` | `(settings: Team1Settings) => void` | - | Called by Salvar preferência with the sort, the full column visibility, the density and `showPaused`; the item renders only with it. |
| `pageSize` | `number` | `10` | Initial rows per page of the footer. |
| `pageSizeOptions` | `readonly number[]` | `[10, 20, 50]` | The choices of the Linhas por página selector; `pageSize` joins them when it is not listed. |
| `locale` | `string` | `"pt-BR"` | Locale of the dates and numbers. |
| `currency` | `string` | `"BRL"` | Part of the shared format props; this block shows no amount. |
| `pending` | `boolean` | `false` | Renders the skeleton in place of the grid; wins over `error`. |
| `error` | `boolean` | `false` | Renders the error surface. |
| `onRetry` | `() => void` | - | Called by the Tentar novamente button; without it the button is not rendered. |
| `labels` | `Partial<Team1Labels>` | pt-BR texts | Overrides the texts of the block; `columns`, `densities`, `presence` and `priorities` merge key by key. Keep the object stable, because the columns are rebuilt when it changes. |
| `className` | `string` | - | Merged into the root classes. |

## Team1Member

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | Identifies the row. |
| `name`, `email` | `string` | The member cell and the filter of the Membro column. |
| `imageUrl` | `string` | Optional avatar image; the initials stand in when it is absent. |
| `isCurrentUser` | `boolean` | Adds the `labels.you` marker after the name. |
| `presence` | `'online' \| 'away' \| 'offline'` | The dot on the avatar and, when `online`, the Online text of the last seen column. |
| `role` | `{ label: string; tone?: 'danger' \| 'info' \| 'neutral' \| 'success' \| 'warning' }` | A read-only select property with the role icon; the tone colors the icon and defaults to `neutral`. |
| `priority` | `'urgent' \| 'high' \| 'medium' \| 'low'` | A read-only select property with the shared priority icon and tone of every data block. |
| `team` | `{ name: string; members: { id; label; imageUrl? }[] }` | The team name and its avatar stack. |
| `rating` | `number` | From 0 to 5, shown as stars and a number. |
| `lastSeen` | `string` | ISO date, shown when the member is not online. |
| `activity` | `number` | Ratio from 0 to 1, shown as a ring and a percentage. |
| `location` | `string` | Free text. |
| `joined` | `string` | Calendar day (`2024-02-12`), shown as a read-only date property read in UTC so the day never shifts. |

## Accessibility and theme

- The grid follows the WAI-ARIA grid pattern with arrow key navigation; the skeleton is `aria-busy="true"` and named by `labels.loading`, and the error surface has the `alert` role.
- The presence dot, the stars and the ring are decorative: each has a hidden text with its meaning, so the cells never depend on color or shape alone.
- The settings are a menu whose submenus use `menuitemradio` and `menuitemcheckbox`.
- The block carries no color, radius or shadow of its own beyond token classes: the theme belongs to the app.
