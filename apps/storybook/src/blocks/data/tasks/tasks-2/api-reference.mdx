# Tasks2

An "All tasks" screen on the collection Lista: a column header (Tarefa, Prazo, Projeto, Responsáveis, Atualizada and the author), then the tasks grouped by priority, each row with its priority and status icons, title, first tag and a `+N tags` count, due date, project, assignees, last update and author. The same tasks also show as a Kanban.

The block is controlled and renders what it gets. Mode, search, sort, grouping, collapsed groups and the Status, Projeto and Responsáveis filters are a value and a callback; without the value the block keeps it locally. The block does **not** filter or sort `tasks`. Tarefa, Prazo, Projeto and Atualizada in the column header are buttons: a click reports `onSortChange(sort, direction)`, the active column flips its direction and another column starts at its default direction; the arrow shows the current direction.

Prazo, Projeto and Responsáveis are editable with their callback. Responsáveis is `PeopleProperty` with `display="stack"`: one person shows avatar and name, two or more show stacked avatars and `labels.peoplePicker.count`. Atualizada shows the time when `updatedAt` falls on the same day as `now` in `timeZone`, and the short date otherwise. In the Kanban, grouped by Prioridade or Status, a drop calls `onPriorityChange` or `onStatusChange` and returns `false`.

## Import

```tsx
import { Tasks2 } from '@tc96/ui/blocks/data/tasks/tasks-2'
```

## Tasks2

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `tasks` | `Tasks2Task[]` | required | The tasks, already filtered and sorted. |
| `people`, `projects`, `tags` | `Tasks2Person[]`, `Tasks2Option[]`, `Tasks2Tag[]` | `[]` | The catalogs of Responsáveis and author, Projeto, and the tag pills (`tone` colors the dot). |
| `mode`, `onModeChange` | `'list' \| 'kanban'` | `'list'` | The controllable layout. |
| `groupBy`, `onGroupByChange` | `'priority' \| 'status' \| 'project' \| null` | `'priority'` | The controllable grouping; the Kanban reads Prioridade unless it is Status. |
| `collapsedGroupIds`, `onCollapsedGroupIdsChange` | `string[]` | - | Collapsed groups as `<grouping>:<option id>`. Without `collapsedGroupIds` the list keeps them: a group with no tasks starts collapsed, reopens when it gets tasks unless someone toggled it, and the effective list is reported. |
| `sort`, `sortDirection`, `onSortChange` | `Tasks2Sort`, `'asc' \| 'desc'` | `'due'`, the sort's default | Ordenar por and the sortable header, rendered with `onSortChange`. |
| `selectedIds`, `onSelectedIdsChange` | `string[]` | `[]` | The selected tasks; the priority icon of a row turns into its checkbox on hover, focus and touch. |
| `onBulkStatusChange`, `onBulkPriorityChange`, `onBulkProjectChange`, `onBulkAssigneesChange`, `onBulkDelete` | `(taskIds, value?) => void` | - | Any of them enables selection and the `ActionBar` of the list: Concluir, Mais opções and Excluir, with no confirmation. |
| `search`, `onSearchChange` | `string` | - | The search field, rendered with `onSearchChange`. |
| `statusFilter`, `projectFilter`, `assigneeFilter` and their callbacks | `string \| null` | `null` | The Filtros of Exibição, each rendered with its callback. |
| `filtered` | `boolean` | `false` | Picks `labels.noResult` instead of `labels.empty`. |
| `onDueChange`, `onProjectChange`, `onAssigneesChange` | `(taskId, value) => void` | - | Make the row fields editable. |
| `onStatusChange`, `onPriorityChange` | `(taskId, value) => void` | - | Take the Kanban drop. |
| `onOpen` | `(taskId) => void` | - | Makes a row and a card open the task. |
| `onCreate`, `createOptions` | `(optionId?) => void`, `Tasks2CreateOption[]` | - | Render Nova; with options it opens a menu. |
| `now` | `string` | mount time | The instant Atualizada is compared with. |
| `locale`, `timeZone` | `string` | `'pt-BR'`, `'America/Sao_Paulo'` | Format the dates. |
| `pending`, `error`, `onRetry` | `boolean`, `boolean`, `() => void` | - | The loading contract of the data blocks. |
| `labels` | `Tasks2LabelsOverride` | pt-BR texts | Overrides the texts. |
