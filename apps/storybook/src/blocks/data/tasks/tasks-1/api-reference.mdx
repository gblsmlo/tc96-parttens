# Tasks1

A task list across projects on the collection `table` layout: each row shows the status icon and the title, then Tags, Vencimento, Projeto, Responsáveis, Prioridade and Atualizada. Reach for it on a Tasks screen that is filtered, sorted and paged by the server. Install it with `npx @tc96/cli add tasks-1`.

The block is controlled and renders what it gets. Search, sort, grouping, collapsed groups, hidden columns, every filter, the selection and the page are a value and a callback; without the value the block keeps it locally. The block does **not** filter, sort or page `tasks`: the consumer sends each change to its server and passes the resulting page back, with `filtered` saying whether any filter or search is active. The one exception is the grouping: the table draws a group header at each run of rows of the same group, so while `groupBy` is set the block orders the tasks it received by the option order of that grouping (Status: Backlog, A fazer, Em andamento, Concluída, Cancelada; Prioridade: Urgente to Baixa, then Sem prioridade). That order is stable, so the server order holds inside each group. Projects, assignees and tags are workspace catalogs passed as `{ id, label }[]`.

The toolbar `left` slot holds the heading (`labels.title`, the only `h2`). On the right: the search field, which reports the text on submit and when it is emptied, then Exibição and Nova tarefa. Exibição holds Ordenar por (Atualizadas recentemente, Vencimento, Prioridade, Título; rendered with `onSortChange`), Agrupar por (Nenhum, Status, Prioridade), Colunas exibidas (every column but Tarefa) and Filtros: Status, Prioridade, Projeto and Responsáveis. Each filter renders only with its callback; Projeto and Responsáveis also need their catalog; the loading state is the collection's `pending`, never a picker's. Salvar preferência renders with `onSavePreference`.

With `onStatusChange` the status icon is a button that opens the status menu; without it the icon is an image named by the status. Tags, Vencimento, Projeto, Responsáveis and Prioridade are editable with their callback and read-only without it. Vencimento offers Limpar data and Projeto and Prioridade offer Sem projeto and Sem prioridade, each reporting `null`; Vencimento takes the overdue look from `overdue` on the task, which the consumer computes. Responsáveis shows one person with avatar and name, and two or more as stacked avatars with the count (`2 responsáveis`); it and Tags report the whole new list. Atualizada is read-only. Each group header collapses its rows and reports `collapsedGroupIds` as `<grouping>:<option id>` (`status:todo`, `priority:none`). Selecting rows opens the `ActionBar`: Concluir, Mais opções (Status, Prioridade, Projeto) and Excluir, each rendered with its callback; each clears the selection, then reports the ids. The block asks no confirmation before Excluir. The footer is the `CollectionPagination`, rendered with `pageCount` while there are tasks.

## Tasks1

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `tasks` | `Tasks1Task[]` | required | The page of tasks, already filtered, sorted and paged. Keep the array stable between renders. |
| `projects` | `Tasks1Option[]` | `[]` | The project catalog: the options of Projeto in a row, in the filter and in the action bar. |
| `assignees` | `Tasks1Person[]` | `[]` | The options of Responsáveis in a row and in the filter. |
| `tags` | `Tasks1Option[]` | `[]` | The tag catalog: the options of Tags in a row. |
| `groupBy`, `onGroupByChange` | `'status' \| 'priority' \| null`, `(groupBy) => void` | `null` | The controllable grouping. |
| `collapsedGroupIds`, `onCollapsedGroupIdsChange` | `string[]`, `(groupIds) => void` | `[]` | The controllable collapsed groups, as `<grouping>:<option id>`. |
| `hiddenColumns`, `onHiddenColumnsChange` | `Tasks1HideableColumnId[]`, `(columnIds) => void` | `[]` | The controllable hidden columns, changed by Colunas exibidas. |
| `search`, `onSearchChange` | `string`, `(search) => void` | - | The search field, rendered with `onSearchChange`; called on submit and when emptied. |
| `sort`, `onSortChange` | `'updated' \| 'due' \| 'priority' \| 'title'`, `(sort) => void` | `'updated'` | Ordenar por, rendered with `onSortChange`. |
| `statusFilter`, `onStatusFilterChange` | `Tasks1Status \| null`, `(status) => void` | `null` | The Status filter. |
| `priorityFilter`, `onPriorityFilterChange` | `Tasks1Priority \| null`, `(priority) => void` | `null` | The Prioridade filter. |
| `projectFilter`, `onProjectFilterChange` | `string \| null`, `(projectId) => void` | `null` | The Projeto filter. |
| `assigneeFilter`, `onAssigneeFilterChange` | `string \| null`, `(assigneeId) => void` | `null` | The Responsáveis filter. |
| `filtered` | `boolean` | `false` | Picks `labels.noResult` instead of `labels.empty` for the empty message. |
| `onStatusChange` | `(taskId, status) => void` | - | Turns the status icon into the status menu. |
| `onDueChange` | `(taskId, dueAt: string \| null) => void` | - | Makes Vencimento editable; the value is the chosen day as `YYYY-MM-DD`, `null` when cleared. |
| `onProjectChange` | `(taskId, projectId \| null) => void` | - | Makes Projeto editable. |
| `onAssigneesChange` | `(taskId, assigneeIds) => void` | - | Makes Responsáveis editable, with the whole new list. |
| `onTagsChange` | `(taskId, tagIds) => void` | - | Makes Tags editable, with the whole new list. |
| `onPriorityChange` | `(taskId, priority \| null) => void` | - | Makes Prioridade editable. |
| `onOpen` | `(taskId: string) => void` | - | Makes a row open the task. |
| `selectedIds`, `onSelectedIdsChange` | `string[]`, `(taskIds) => void` | `[]` | The controllable selection. Either one, or a bulk callback, adds the select column. |
| `onBulkStatusChange` | `(taskIds, status) => void` | - | Renders Concluir, which reports `'done'`, and Status under Mais opções. |
| `onBulkPriorityChange`, `onBulkProjectChange` | `(taskIds, value \| null) => void` | - | Render Prioridade and Projeto under Mais opções; Sem prioridade and Sem projeto report `null`. |
| `onBulkDelete` | `(taskIds: string[]) => void` | - | Renders Excluir. The block asks no confirmation. |
| `onSavePreference` | `() => void` | - | Renders Salvar preferência at the end of Exibição. |
| `page`, `onPageChange` | `number`, `(page) => void` | `1` | The controllable page, starting at 1. |
| `pageCount` | `number` | - | Renders the pagination footer while there are tasks. |
| `pageSize`, `total` | `number` | - | Together they show the range summary (`1–20 de 57`); `total` of 0 hides the footer. |
| `onCreate` | `() => void` | - | Renders Nova tarefa. |
| `locale`, `timeZone` | `string` | `'pt-BR'`, `'America/Sao_Paulo'` | Format Vencimento and Atualizada. |
| `pending`, `error`, `onRetry` | `boolean`, `boolean`, `() => void` | - | The loading contract of the data blocks. |
| `labels` | `Tasks1LabelsOverride` | pt-BR texts | Overrides the texts; `columns`, `groupings`, `paginationButtons`, `peoplePicker`, `priorities`, `sorts`, `statuses` and `tagPicker` merge key by key. |
| `className` | `string` | - | Merged into the root classes. |

## Tasks1Task

| Field | Type | Description |
| --- | --- | --- |
| `id`, `title` | `string` | The identity and the title in the Tarefa cell. |
| `status` | `'backlog' \| 'todo' \| 'in-progress' \| 'done' \| 'canceled'` | The icon before the title. |
| `tagIds` | `string[]` | Ids of `tags`, shown in the Tags column. |
| `dueAt` | `string \| null` | An ISO date; a day-only `YYYY-MM-DD` is shown as that day. |
| `overdue` | `boolean` | The overdue look of Vencimento; the block computes no dates. |
| `projectId` | `string \| null` | One of `projects`. |
| `assigneeIds` | `string[]` | Ids of `assignees`. |
| `priority` | `'urgent' \| 'high' \| 'medium' \| 'low' \| null` | `null` is Sem prioridade. |
| `updatedAt` | `string` | The ISO instant of the last change, shown with its time. |
