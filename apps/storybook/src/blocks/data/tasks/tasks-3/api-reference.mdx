# Tasks3

The "All tasks" screen of `Tasks2` with a toolbar of one menu per view setting. The list and the Kanban are the same as in `Tasks2`: a column header (Tarefa, Prazo, Projeto, Responsáveis, Atualizada and the author), the tasks grouped by priority, each row with its priority and status icons, title, first tag, due date, project, assignees, last update and author. Install it with `npx @tc96/cli add tasks-3`.

The toolbar `left` slot holds the heading (`labels.title`, the only `h2`). The `right` slot holds, in this order: the filter menu, the layout menu, the sort menu, the group menu and the primary `Action` (`labels.create`). Every control is 32px tall. The filter trigger is an icon button that grows into an icon and a count `Badge` while a filter is active, and its name turns into `labels.activeFilters(count)`. The filter menu holds `labels.filterProperties` with one submenu per property (Status, Prioridade, Responsável), each option with its icon, then `labels.clearFilters`, disabled while no filter is active. The layout menu shows the icon of the current layout and lists Lista and Quadro as radio items; picking one switches the rendered layout. The sort and group menus list their options as radio items with an icon; in the Kanban the group menu offers only Prioridade and Status. The layout, sort and group menus close on a pick.

The block is controlled and renders what it gets. Mode, sort, grouping, collapsed groups, selection and the Status, Prioridade and Responsável filters are a value and a callback; without the value the block keeps it locally. The block does **not** filter or sort `tasks`. Each control renders only with its callback: each filter submenu with its own callback (Responsável also needs `people`), the filter menu with at least one of them, the sort menu with `onSortChange` and the `Action` with `onCreate`. The layout and group menus always render.

Every text is a key of `labels`, with pt-BR defaults. Texts that carry a number or a name (`activeFilters`, `selectedCount`, `openTask`, `sortColumn`) are functions, so the consumer decides the word order.

## Import

```tsx
import { Tasks3 } from '@tc96/ui/blocks/data/tasks/tasks-3'
```

## Tasks3

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `tasks` | `Tasks3Task[]` | required | The tasks, already filtered and sorted. |
| `people`, `projects`, `tags` | `Tasks3Person[]`, `Tasks3Option[]`, `Tasks3Tag[]` | `[]` | The catalogs of Responsáveis and author, Projeto, and the tag pills (`tone` colors the dot). |
| `mode`, `onModeChange` | `'list' \| 'kanban'` | `'list'` | The controllable layout, changed from the layout menu. |
| `groupBy`, `onGroupByChange` | `'priority' \| 'status' \| 'project' \| null` | `'priority'` | The controllable grouping; the Kanban reads Prioridade unless it is Status. |
| `collapsedGroupIds`, `onCollapsedGroupIdsChange` | `string[]` | - | Collapsed groups as `<grouping>:<option id>`. Without `collapsedGroupIds` the list keeps them: a group with no tasks starts collapsed, reopens when it gets tasks unless someone toggled it, and the effective list is reported. |
| `sort`, `sortDirection`, `onSortChange` | `Tasks3Sort`, `'asc' \| 'desc'` | `'due'`, the sort's default | The sort menu and the sortable header, rendered with `onSortChange`. |
| `statusFilter`, `priorityFilter`, `assigneeFilter` and their callbacks | `Tasks3Status \| null`, `Tasks3PriorityFilter \| null`, `string \| null` | `null` | The filter submenus; `'none'` in `priorityFilter` stands for Sem prioridade. |
| `filtered` | `boolean` | `false` | Picks `labels.noResult` instead of `labels.empty`. |
| `selectedIds`, `onSelectedIdsChange` | `string[]` | `[]` | The selected tasks; the priority icon of a row turns into its checkbox on hover, focus and touch. |
| `onBulkStatusChange`, `onBulkPriorityChange`, `onBulkProjectChange`, `onBulkAssigneesChange`, `onBulkDelete` | `(taskIds, value?) => void` | - | Any of them enables selection and the `ActionBar` of the list, with no confirmation. |
| `onDueChange`, `onProjectChange`, `onAssigneesChange` | `(taskId, value) => void` | - | Make the row fields editable. |
| `onStatusChange`, `onPriorityChange` | `(taskId, value) => void` | - | Take the Kanban drop. |
| `onOpen` | `(taskId) => void` | - | Makes a row and a card open the task. |
| `onCreate` | `() => void` | - | Renders the primary `Action`, last in the toolbar. |
| `now` | `string` | mount time | The instant Atualizada is compared with. |
| `locale`, `timeZone` | `string` | `'pt-BR'`, `'America/Sao_Paulo'` | Format the dates. |
| `pending`, `error`, `onRetry` | `boolean`, `boolean`, `() => void` | - | The loading contract of the data blocks; the toolbar keeps only the heading meanwhile. |
| `labels` | `Tasks3LabelsOverride` | pt-BR texts | Overrides the texts. |
