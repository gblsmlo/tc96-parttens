# DataGrid6

A revenue book grouped by region on the collection Data Grid: one toolbar with the title, the description, the search, the Exibição menu, Expandir tudo or Recolher tudo and Exportar, a band of three portfolio indicators below it, and a grid whose region rows carry their subtotals under the ARR, NRR and renewal columns and the region description under the owner. Reach for it on a revenue, retention or territory screen where accounts roll up into named groups. Install it with `npx @tc96/cli add data-grid-6`.

It is a section, not a page: it renders no `main` landmark. Numbers arrive raw and are formatted with `locale` and `currency`. The indicators come from `summary`, because the portfolio values are the consumer's; the region subtotals are computed by the block from the rows the grid shows: the ARR is the sum, the NRR is the average weighted by ARR (an account of R$ 900.000 weighs nine times one of R$ 100.000, which keeps the region NRR consistent with its ARR), and the renewal is the earliest date. Because they follow the rows on screen, a search or a health filter changes them, and the grid does not paginate, since a subtotal of one page would misstate the region. The block orders the accounts by the order of `regions` and keeps the order of `accounts` inside each region; there is no sort, because the region rows are runs of consecutive accounts and any sort would split them.

The collapsed regions and the density are the consumer's (`collapsedRegionIds`, `density`) and reported (`onCollapsedRegionIdsChange`, `onDensityChange`). The search, the Saúde filter and the column visibility stay in the Data Grid. The heading is the toolbar's: the `left` slot of one `CollectionToolbar` carries `labels.title` as the only `h2` and `labels.description` below it. Loading and error are the block's: the toolbar keeps the heading and the description and hides its controls, `pending` renders its skeleton in place of the indicators and the grid, and `error` an error surface with a retry button; the precedence is `pending`, then `error`.

## Import

```tsx
import { DataGrid6 } from '@tc96/ui/blocks/data/data-grid/data-grid-6'
```

The same path exports the types listed under Exports.

## Anatomy

The toolbar with the heading and the controls, the indicators band below it, and the grid with North America expanded and the other regions collapsed.

## DataGrid6

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `accounts` | `DataGrid6Account[]` | required | The rows. Keep the array stable between renders. |
| `regions` | `DataGrid6Region[]` | required | The groups, in display order: `{ id, label, description }`. An account whose `regionId` has no region gets no group row. |
| `summary` | `DataGrid6Summary` | - | `{ totalArr, portfolioNrr, atRiskArr }`, the three indicators below the toolbar; without it they are not rendered. |
| `collapsedRegionIds` | `readonly string[]` | - | The collapsed regions, by region id; without it the grid keeps the collapse locally. |
| `onCollapsedRegionIdsChange` | `(regionIds: readonly string[]) => void` | - | Called by a region chevron and by Expandir tudo or Recolher tudo, which passes every region with accounts or `[]`. The button renders only with this callback. |
| `density` | `'short' \| 'medium' \| 'tall' \| 'extra-tall'` | `'medium'` | The row height. |
| `onDensityChange` | `(density: DataGrid6Density) => void` | - | Called by Altura das linhas of the Exibição menu. |
| `rowActions` | `DataGrid6RowAction[]` | - | The items of the row menu (`{ id, label, destructive? }`). |
| `onRowAction` | `(actionId: string, accountId: string) => void` | - | The menu column renders only with this callback and `rowActions`. |
| `onExport` | `() => void` | - | The Exportar button of the toolbar renders only with this callback. |
| `locale` | `string` | `"pt-BR"` | Locale of the amounts, percentages and dates. |
| `currency` | `string` | `"BRL"` | ISO currency of the ARR values, subtotals and indicators. |
| `pending` | `boolean` | `false` | Renders the skeleton below the heading; wins over `error`. |
| `error` | `boolean` | `false` | Renders the error surface below the heading. |
| `onRetry` | `() => void` | - | Called by the Tentar novamente button; without it the button is not rendered. |
| `labels` | `DataGrid6LabelsOverride` | pt-BR texts | Overrides the texts; `columns` and `health` merge key by key. Keep the object stable, because the columns are rebuilt when it changes. |
| `className` | `string` | - | Merged into the root classes. |

## DataGrid6Account

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | Identifies the row and picks the color of the initials tile. |
| `name` | `string` | The account cell and the search. |
| `regionId` | `string` | The `id` of its region. |
| `owner` | `{ id; label; imageUrl? }` | The avatar and the name; searchable. |
| `health` | `'healthy' \| 'watch' \| 'atRisk'` | The health badge and the Saúde filter. |
| `arr` | `number` | Annual recurring revenue, a raw amount. |
| `nrr` | `number` | Net revenue retention as a ratio (`1.24` is 124%); below `1` it is red with a down trend. |
| `renewal` | `string` | ISO date of the next renewal. |

## Accessibility and theme

- The grid follows the WAI-ARIA grid pattern; a region row is a row of `gridcell`s aligned with the columns, and its chevron is a button with `aria-expanded`.
- The indicators are a description list named by `labels.kpis`, each term next to its value.
- The NRR trend icon carries hidden text from `labels.nrrTrend`, so a value below 100% never depends on red alone; the initials tile is decorative.
- The skeleton is `aria-busy="true"` and named by `labels.loading`; the error surface has the `alert` role.
- The block carries no color, radius or shadow of its own beyond token classes; the initials tile takes its tint through the `IconFrame` `color` prop with the theme's `-foreground` tokens.
