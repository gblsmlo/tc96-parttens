# DataGrid8

A transaction ledger on the collection Data Grid: transaction and charge id, customer, amount, status, payment method with the last four digits, channel, risk score and date, in a virtualized grid that asks for the next page when the scroll nears the end. Reach for it on a payments or billing screen where the list is far longer than what is loaded. Install it with `npx @tc96/cli add data-grid-8`.

It is a section, not a page: it renders no `main` landmark. A real ledger sorts, filters and searches on the server, so the block never reorders or filters `transactions`: the sort, the filters, the search, the view, the selection, the density and the column visibility are controlled and every change is a callback. The grid mounts only the visible rows (`virtualize`), and when the scroll comes within eight rows of the end it calls `onLoadMore` once per `transactions.length`, only while `hasMore` is true; `loadingMore` appends skeleton rows and holds the next call. The toolbar is one `CollectionToolbar`. Its `left` slot holds either the view switcher, when `views` has items and `onViewChange` is passed, or `labels.title` as the only `h2` with the loaded count as its description, never both; with the switcher the page has no `h2` and the section and the grid keep their name from `labels.title`. Its `right` slot holds the search, Atualizar, Configurações de visualização and Exportar. Selected rows open the pattern's `ActionBar` floating over the grid, with the count and the selected total, Exportar, Estornar and Sinalizar. Loading and error are the block's: the toolbar keeps its `left` slot (the view switcher, or the heading without the count) and hides its controls, `pending` renders the skeleton in place of the grid and `error` an error surface with a retry button; the precedence is `pending`, then `error`.

The other pages of `Blocks/Data/DataGrid/DataGrid8`: [Playground](?path=/story/blocks-data-datagrid-datagrid8-playground--playground) to try the controls, [Behavior](?path=/story/blocks-data-datagrid-datagrid8-behavior--each-row-shows-the-transaction) for the tests, [States](?path=/story/blocks-data-datagrid-datagrid8-states--default) for the loaded, loading, loading more, error and empty states and [Usages](?path=/story/blocks-data-datagrid-datagrid8-usages--loaded) for pages read over the network with `useInfiniteQuery`.

## Import

```tsx
import { DataGrid8 } from '@tc96/ui/blocks/data/data-grid/data-grid-8'
```

The same path exports `emptyDataGrid8Filters` and the types listed under Exports.

## Anatomy

The toolbar with the heading and the loaded count (the view switcher takes their place when `views` is passed), the search, Atualizar, Configurações de visualização (sort, row height and columns, then the Status, Método and Canal filters) and Exportar; the virtualized grid; the `ActionBar` floating over it while rows are selected.

```tsx
<DataGrid8
  hasMore={hasNextPage}
  loadingMore={isFetchingNextPage}
  onLoadMore={fetchNextPage}
  onSortChange={setSort}
  sort={sort}
  totalCount={total}
  transactions={transactions}
/>
```

## DataGrid8

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `transactions` | `DataGrid8Transaction[]` | required | The loaded rows, already sorted and filtered. Keep the array stable between renders. |
| `totalCount` | `number` | required | Rows on the server for the current query; the second number of the toolbar description, shown without views. |
| `loadedCount` | `number` | `transactions.length` | The first number of the toolbar description, shown without views. |
| `hasMore` | `boolean` | `false` | Whether the server has another page; without it `onLoadMore` is never called. |
| `onLoadMore` | `() => void` | - | Called once per `transactions.length` when the scroll nears the end. |
| `loadingMore` | `boolean` | `false` | Appends skeleton rows, sets `aria-busy` on the grid and holds `onLoadMore`. |
| `maxHeight` | `number` | `560` | Height of the scrolling grid in pixels. |
| `sort` | `DataGrid8Sort \| null` | - | The sort the rows arrive in; the column headers and the Ordenar por menu show it. |
| `onSortChange` | `(sort: DataGrid8Sort \| null) => void` | - | Called once per sort change. The block does not reorder the rows. |
| `filters` | `DataGrid8Filters` | `emptyDataGrid8Filters` | The Status, Método and Canal filters; `''` means all. |
| `onFiltersChange` | `(filters: DataGrid8Filters) => void` | - | Called with every filter; the Filtros section renders only with it. Limpar filtros sends `emptyDataGrid8Filters`. |
| `search` | `string` | `''` | The committed search. |
| `onSearchChange` | `(search: string) => void` | - | Called on submit and when the field is cleared, never per keystroke; the field renders only with it. |
| `views`, `activeViewId` | `DataGrid8View[]`, `string` | - | The saved views and the active one. |
| `onViewChange` | `(viewId: string) => void` | - | The view switcher renders only with items in `views` and this callback, in place of the heading and the loaded count. |
| `onViewCreate` | `() => void` | - | Renders Criar visualização in the switcher. |
| `selectedIds` | `string[]` | - | Controls the selected rows; without it the grid keeps them. |
| `onSelectedIdsChange` | `(ids: string[]) => void` | - | Called once per selection change. |
| `onExportSelected`, `onRefund`, `onFlag` | `(ids: string[]) => void` | - | The `ActionBar` items, called with the selected ids; each renders only with its callback. |
| `onExport` | `() => void` | - | The Exportar button of the toolbar; renders only with it. |
| `onRefresh` | `() => void` | - | The Atualizar button; renders only with it. |
| `refreshing` | `boolean` | `false` | Spins the Atualizar icon and disables the button. |
| `density` | `DataGrid8Density` | `'tall'` | Row height; `short` and `medium` hide the second line of the two-line cells. |
| `onDensityChange` | `(density: DataGrid8Density) => void` | - | Called by the Altura das linhas menu; without it the grid keeps the density. |
| `columnVisibility` | `DataGrid8ColumnVisibility` | - | Controls the visible columns; a column is hidden only when its value is `false`. |
| `onColumnVisibilityChange` | `(visibility: DataGrid8ColumnVisibility) => void` | - | Called by the Colunas menu or a column menu. |
| `locale` | `string` | `"pt-BR"` | Locale of the amounts, counts and dates. |
| `currency` | `string` | `"BRL"` | Currency of the amounts. |
| `pending` | `boolean` | `false` | Renders the skeleton in place of the grid and keeps only the view switcher or the heading in the toolbar; wins over `error`. |
| `error` | `boolean` | `false` | Renders the error surface below the toolbar. |
| `onRetry` | `() => void` | - | Called by Tentar novamente; without it the button is not rendered. |
| `labels` | `DataGrid8LabelsOverride` | pt-BR texts | Overrides the texts; `columns`, `statuses`, `methods`, `channels` and `riskBands` merge key by key. Keep the object stable, because the columns are rebuilt when it changes. |
| `className` | `string` | - | Merged into the root classes. |

## DataGrid8Transaction

| Field | Type | Description |
| --- | --- | --- |
| `id`, `chargeId` | `string` | The transaction id (row id) and the processor charge id, both in monospace. |
| `customer` | `{ name; email; imageUrl? }` | Avatar, name and e-mail; the initials stand in for a missing image. |
| `amount` | `number` | Raw amount, formatted with `locale` and `currency`. |
| `status` | `'settled' \| 'pending' \| 'refunded' \| 'failed'` | Liquidada, Pendente, Estornada, Falhou. |
| `method`, `lastFour` | `'card' \| 'apple-pay' \| 'google-pay' \| 'paypal'`, `string` | Method icon and the masked last four digits. |
| `channel` | `'api' \| 'web' \| 'mobile' \| 'pos'` | Channel icon and name. |
| `risk` | `number` | Score from 0 to 100: below 40 low, below 70 medium, otherwise high. |
| `createdAt` | `string` | ISO date and time, shown as day and time. |

## Accessibility and theme

- The grid follows the WAI-ARIA grid pattern with arrow key navigation; `aria-rowcount` counts the loaded rows and the loading-more rows, and the grid is `aria-busy` while more rows load.
- The method icon, the masked digits, the risk dot and the status dot are decorative: the method and the risk carry a hidden text with their meaning, and the status is a word, so no cell depends on color alone.
- The status is an outline badge with a colored dot: a tinted success badge measured 3.97:1 on a selected row.
- The `ActionBar` is a `toolbar` named by `labels.selectionActions`.
- The block carries no color, radius or shadow of its own beyond token classes: the theme belongs to the app.
