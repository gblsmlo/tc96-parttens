# DataGrid1

A support ticket queue on the collection Data Grid: ticket title with code and opening time, requester, queue, priority, SLA and status, with the pattern's `ActionBar` floating over the grid while tickets are selected, to assign an owner or move them, and a footer with the rows per page selector. Reach for it on a help desk or operations screen where people triage a queue of items with deadlines. Install it with `npx @tc96/cli add data-grid-1`.

It is a section, not a page: it renders no `main` landmark. The toolbar is one `CollectionToolbar`. Its `left` slot holds either the view switcher, when `views` has items, or `labels.title` as the only `h2` with the summary line as its description, never both; with the switcher the page has no `h2` and the section and the grid keep their name from `labels.title`. Its `right` slot holds the `ViewSettingsMenu` (Exibição) holding sort, row height and columns, the queue and status filters, Limpar filtros and Salvar visão, and the Exportar CSV (ghost) and Novo chamado buttons. Every piece of state a consumer saves is controllable and reported: `queue`, `status`, `sort`, `columnVisibility`, `density`, `selectedIds` and `pageSize`; without the value the grid keeps it locally and still calls the callback. The block filters, sorts and pages the rows it receives, but never changes a ticket: Atribuir responsável and Atualizar status are `ActionBar` items whose submenus list the owners and the statuses, and a choice only calls `onAssignOwner` or `onStatusUpdate` with the selected ids. Loading and error are the block's: the toolbar keeps its `left` slot (the view switcher, or the heading without the summary) and hides its controls, `pending` renders the skeleton in place of the grid and `error` an error surface with a retry button; the precedence is `pending`, then `error`.

The other pages of `Blocks/Data/DataGrid/DataGrid1`: [Playground](?path=/story/blocks-data-datagrid-datagrid1-playground--playground) to try the controls, [Behavior](?path=/story/blocks-data-datagrid-datagrid1-behavior--each-row-shows-the-ticket-details) for the tests, [States](?path=/story/blocks-data-datagrid-datagrid1-states--default) for the loaded, loading, error and empty states and [Usages](?path=/story/blocks-data-datagrid-datagrid1-usages--loaded) for the data read over the network.

## Import

```tsx
import { DataGrid1 } from '@tc96/ui/blocks/data/data-grid/data-grid-1'
```

The same path exports the types listed under Exports.

## Anatomy

The toolbar with the heading and the summary line (the view switcher takes their place when `views` is passed) and the controls, the grid, the `ActionBar` floating over it (only while rows are selected) and the pagination footer with Linhas por página.

<Canvas of={ApiReferenceStories.Anatomy} />

```tsx
<DataGrid1
  onAssignOwner={assign}
  onPageSizeChange={setPageSize}
  onSelectedIdsChange={setSelectedIds}
  onStatusUpdate={move}
  owners={owners}
  pageSize={pageSize}
  pageSizeOptions={[6, 12, 24]}
  selectedIds={selectedIds}
  tickets={tickets}
/>
```

## DataGrid1

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `tickets` | `DataGrid1Ticket[]` | required | The rows. Keep the array stable between renders. |
| `queue` | `DataGrid1Queue \| null` | - | Controls the queue filter of Exibição > Fila; `null` is Todas as filas. |
| `onQueueChange` | `(queue: DataGrid1Queue \| null) => void` | - | Called by the queue filter and by Limpar filtros. |
| `status` | `DataGrid1Status \| null` | - | Controls the status filter of Exibição > Status; `null` is Todos os status. |
| `onStatusChange` | `(status: DataGrid1Status \| null) => void` | - | Called by the status filter and by Limpar filtros. |
| `sort` | `DataGrid1Sort \| null` | - | Controls the sort. |
| `onSortChange` | `(sort: DataGrid1Sort \| null) => void` | - | Called once per sort change, from Exibição > Ordenar por or from a column menu. |
| `columnVisibility` | `DataGrid1ColumnVisibility` | all visible | Controls the visible columns; a column is hidden only when its value is `false`. |
| `onColumnVisibilityChange` | `(visibility: DataGrid1ColumnVisibility) => void` | - | Called once per change, from Exibição > Colunas or from a column menu. |
| `density` | `DataGrid1Density` | `"tall"` | Row height. |
| `onDensityChange` | `(density: DataGrid1Density) => void` | - | With it, `density` is controlled and Exibição > Altura das linhas reports here. |
| `selectedIds` | `string[]` | - | Controls the selected ticket ids. |
| `onSelectedIdsChange` | `(ticketIds: string[]) => void` | - | Called on every selection change, Limpar seleção included. |
| `owners` | `DataGrid1Person[]` | `[]` | The items of the Atribuir responsável submenu of the `ActionBar`. |
| `onAssignOwner` | `(ticketIds: string[], ownerId: string) => void` | - | Called by an owner of Atribuir responsável; the item renders only with it and at least one owner. |
| `onStatusUpdate` | `(ticketIds: string[], status: DataGrid1Status) => void` | - | Called by a status of Atualizar status; the item renders only with it. |
| `pageSize` | `number` | first of `pageSizeOptions` | Controls the rows per page. |
| `pageSizeOptions` | `readonly number[]` | `[10, 20, 50]` | The options of Linhas por página. |
| `onPageSizeChange` | `(pageSize: number) => void` | - | Called by the footer selector; the page goes back to the first. |
| `views` | `DataGrid1View[]` | - | The saved views of the view switcher, which replaces the heading and the summary line in the toolbar; without items the heading shows. |
| `activeViewId` | `string` | - | The view shown on the switcher trigger and marked as selected. |
| `onViewChange` | `(viewId: string) => void` | - | Called when a view is chosen. The block does not apply the view: the consumer changes the other props. |
| `onViewCreate` | `() => void` | - | Renders Criar nova view at the end of the switcher. |
| `onSaveView` | `() => void` | - | Renders Salvar visão at the end of Exibição. |
| `onCreate` | `() => void` | - | Renders the Novo chamado button. |
| `onExport` | `() => void` | - | Renders the Exportar CSV button. |
| `rowActions` | `DataGrid1RowAction[]` | - | The items of the row menu. |
| `onRowAction` | `(actionId: string, ticketId: string) => void` | - | The row menu column renders only with it and a non-empty `rowActions`. |
| `pending` | `boolean` | `false` | Renders the skeleton in place of the grid and keeps only the view switcher or the heading in the toolbar; wins over `error`. |
| `error` | `boolean` | `false` | Renders the error surface below the toolbar. |
| `onRetry` | `() => void` | - | Called by the Tentar novamente button; without it the button is not rendered. |
| `labels` | `Partial<DataGrid1Labels>` | pt-BR texts | Overrides the texts of the block; `columns`, `priorities`, `queues` and `statuses` merge key by key. Keep the object stable, because the columns are rebuilt when it changes. |
| `locale`, `currency` | `string` | `"pt-BR"`, `"BRL"` | The shared format props; this block formats no number or date, the texts arrive ready. |
| `className` | `string` | - | Merged into the root classes. |

## DataGrid1Ticket

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | Identifies the row and is what the callbacks receive. |
| `code`, `title` | `string` | The ticket cell. |
| `opened` | `string` | The opening time as ready text (`"Aberto há 2 h"`); the block does not compute relative times. |
| `ownerId` | `string \| null` | `null` counts the ticket as unassigned in the summary line. |
| `requester` | `{ name; company; imageUrl? }` | Avatar (initials without image), name and company. |
| `queue` | `'platform' \| 'billing' \| 'authentication' \| 'integrations'` | The queue badge and its icon. |
| `priority` | `'urgent' \| 'high' \| 'medium' \| 'low'` | The priority badge; sorts by that order. |
| `sla` | `{ label; caption; tone; dueInMinutes }` | The SLA text colored by `tone` (`breached`, `warning`, `healthy`, `closed`) and its caption; `dueInMinutes` sorts the column, `null` goes last. `breached` and `warning` count as near SLA in the summary line. |
| `status` | `'open' \| 'pending' \| 'resolved'` | The status badge with its dot. |

## Accessibility and theme

- The grid follows the WAI-ARIA grid pattern with arrow key navigation; every checkbox is named by the ticket code, the `ActionBar` is a `toolbar` named by `labels.selectionActions`, and the skeleton is `aria-busy="true"` and named by `labels.loading`.
- Queue, priority and status are outline badges whose color sits only on the icon or the dot; the SLA text carries its tone as color and falls back to the foreground on a selected row, because the selected row background drops the warning, success and destructive foregrounds below 4.5:1.
- The block carries no color, radius or shadow of its own beyond token classes: the theme belongs to the app.
