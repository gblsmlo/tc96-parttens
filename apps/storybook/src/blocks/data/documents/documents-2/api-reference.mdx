# Documents2

The document library of `Documents1` on the toolbar of `Tasks4`, with a row of pinned documents and three layouts: Lista, Tabela and Galeria. Install it with `npx @tc96/cli add documents-2`.

The toolbar `left` slot holds the view switcher (`labels.viewList`): one fixed view named by `labels.title`, then the saved views. The `right` slot holds, in this order: the filter menu (Tipo and Responsável), the layout menu, the sort menu, the group menu and the create menu (`labels.create`: Nota, Link, then Enviar arquivos). The group menu is hidden in the gallery, which never groups.

The pinned row sits between the toolbar and the collection, outside the list, the table and the gallery, so it stays in every layout. It is a `section` named by `labels.pinned` with one compact card per pinned document (type icon, name, type and update date); the name opens the document and the pin button calls `onPinnedChange(id, false)`. The row scrolls sideways when it overflows and is hidden when `pinnedRecords` is empty or while the block is loading or failed.

The gallery card shows a preview (the `previewUrl` image, or the type icon), the name, the type and size, the owner and the update date. Selecting records in the list or the table opens the `ActionBar` with Baixar, Fixar and Excluir; each sends only the ids it applies to (files, unpinned records, records with `canDelete !== false`).

The block is controlled and renders what it gets: it does not filter, sort or pick the pinned records. Every text is a key of `labels`, with English defaults.

## Import

```tsx
import { Documents2 } from '@tc96/ui/blocks/data/documents/documents-2'
```

## Documents2

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `records` | `Documents2Record[]` | required | The documents, already filtered and sorted. |
| `pinnedRecords` | `Documents2Record[]` | `[]` | The pinned row, prepared by the consumer. |
| `people` | `Documents2Person[]` | `[]` | The owners: the Responsável filter, field and grouping. |
| `mode`, `onModeChange` | `'list' \| 'table' \| 'gallery'` | `'list'` | The controllable layout. |
| `groupBy`, `onGroupByChange` | `'type' \| 'owner' \| null` | `null` | The controllable grouping of the list and the table. |
| `collapsedGroupIds`, `onCollapsedGroupIdsChange` | `string[]` | - | Collapsed groups as `<grouping>:<option id>`. |
| `sort`, `onSortChange` | `Documents2Sort` | `'updated'` | The sort menu, rendered with `onSortChange`. |
| `typeFilter`, `ownerFilter` and their callbacks | `Documents2Type \| null`, `string \| null` | `null` | The filter submenus. |
| `filtered` | `boolean` | `false` | Picks `labels.noResult` instead of `labels.empty`. |
| `selectedIds`, `onSelectedIdsChange` | `string[]` | `[]` | The selected records of the list and the table. |
| `onBulkDownload`, `onBulkPinnedChange`, `onBulkDelete` | `(recordIds, value?) => void` | - | Any of them enables selection and the `ActionBar`. |
| `onOpen` | `(recordId) => void` | - | Makes a row, a card and a pinned card open the document. |
| `onDownload`, `onPinnedChange`, `onDelete` | `(recordId, value?) => void` | - | The record menu; `onPinnedChange` also renders the unpin button of a pinned card. |
| `onCreateNote`, `onCreateLink`, `onUpload`, `uploadAccept` | callbacks, `string` | - | The create menu items; `onUpload` opens the file picker. |
| `typeColors` | `Documents2TypeColors` | - | The color of each type icon. |
| `locale`, `timeZone` | `string` | `'pt-BR'`, `'America/Sao_Paulo'` | Format the dates. |
| `savedViews`, `savedViewId`, `savedViewModified` and the `onSavedView*` callbacks | | - | The saved views of `Tasks4`; `onSavedViewSelect(null)` goes back to the fixed view. |
| `pending`, `error`, `onRetry` | `boolean`, `boolean`, `() => void` | - | The loading contract of the data blocks. |
| `labels` | `Documents2LabelsOverride` | English texts | Overrides the texts. |
