# Support3

An ordered list of routing rules on the collection Data Grid: a drag handle, the position, the rule with its icon and description, the scope property, the condition, the effect, the matches of the period, an enabled switch and a row menu. The first rule that matches wins, so the order is the data. Reach for it wherever a list is evaluated top to bottom and people reorder it by hand. Install it with `npx @tc96/cli add support-3`.

It is a section, not a page: it renders no `main` landmark. The block never reorders `rules`: a drop or a keyboard move calls `onRuleMove` with the rule, its position before and after, and the rule it landed on; the consumer moves the rule and passes the new array. Restaurar ordem calls `onResetOrder` and is enabled only while `orderChanged` is true, because only the consumer knows the saved order. The grid does not sort, so a reorder always applies to the order shown. The heading is the toolbar's: the `left` slot of one `CollectionToolbar` carries `labels.title` as the only `h2` and the summary line as its description, and its `right` slot Restaurar ordem. Loading and error are the block's: the toolbar keeps the heading and hides the summary and Restaurar ordem, `pending` renders its skeleton in place of the grid and `error` an error surface with a retry button; the precedence is `pending`, then `error`.

The other pages of `Blocks/Data/Support/Support3`: [Playground](?path=/story/blocks-data-support-support3-playground--playground) to try the controls, [Behavior](?path=/story/blocks-data-support-support3-behavior--each-row-shows-the-rule) for the tests, [States](?path=/story/blocks-data-support-support3-states--default) for the loaded, reordered, loading, error and empty states and [Usages](?path=/story/blocks-data-support-support3-usages--loaded) for the data read over the network and reordered in state.

## Import

```tsx
import { Support3 } from '@tc96/ui/blocks/data/support/support-3'
```

The same path exports the types listed under Exports.

## Anatomy

The toolbar with the heading, the summary line and Restaurar ordem, and the grid with a handle on every row.

<Canvas of={ApiReferenceStories.Anatomy} />

```tsx
<Support3
  onResetOrder={() => setRules(savedRules)}
  onRuleMove={(move) => setRules((current) => moveRule(current, move))}
  orderChanged={!sameOrder(rules, savedRules)}
  rules={rules}
/>
```

## Support3

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `rules` | `Support3Rule[]` | required | The rules in evaluation order. The position column is the index plus one. |
| `onRuleMove` | `(move: Support3RuleMove) => void` | - | Called once per drop with `{ ruleId, fromIndex, toIndex, overRuleId }`; a cancelled drag reports nothing. Without it the handles render disabled. |
| `onResetOrder` | `() => void` | - | Restaurar ordem renders in the toolbar only with it, and not while `pending` or `error`. |
| `orderChanged` | `boolean` | `false` | Enables Restaurar ordem. |
| `onEnabledChange` | `(ruleId: string, enabled: boolean) => void` | - | Called by the switch; without it the switch is disabled. |
| `rowActions`, `onRowAction` | `Support3RowAction[]`, `(actionId, ruleId) => void` | - | The row menu renders only with both. |
| `locale` | `string` | `"pt-BR"` | Locale of the match counts. |
| `currency` | `string` | `"BRL"` | Part of the shared format props; this block shows no amount. |
| `pending` | `boolean` | `false` | Renders the skeleton in place of the grid, below the heading; wins over `error`. |
| `error` | `boolean` | `false` | Renders the error surface below the heading. |
| `onRetry` | `() => void` | - | Called by the Tentar novamente button; without it the button is not rendered. |
| `labels` | `Support3LabelsOverride` | pt-BR texts | Overrides the texts of the block; `columns` merges key by key. |
| `className` | `string` | - | Merged into the root classes. |

## Support3Rule

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | Identifies the row and the moves. |
| `name`, `description` | `string` | The rule cell. |
| `icon` | `'alert' \| 'clock' \| 'people' \| 'sliders' \| 'tag'` | The icon of the tile, decorative. |
| `scope` | `{ label: string; tone?: 'danger' \| 'info' \| 'neutral' \| 'success' \| 'warning' }` | The Escopo property, a read-only `SelectProperty` with one option; the tone defaults to `neutral`, and a disabled rule always shows it as `neutral`. |
| `condition`, `effect` | `string` | The Quando and Então texts. |
| `matches` | `number` | Matches in the period of `labels.period`; the summary adds them. |
| `enabled` | `boolean` | The switch; a disabled rule renders muted and is left out of the active count. |

## Accessibility and theme

- Each handle is a button named by `labels.dragHandle`: Space picks the rule up, the arrows move it, Space or Tab drops it and Escape cancels; every step is spoken from the labels.
- The icons of the rule, the condition, the effect and the matches are decorative; the matches carry a hidden text with the period.
- A disabled rule is muted by text color, and its switch state says it, so the row never depends on color alone.
- The block carries no color, radius or shadow of its own beyond token classes: the theme belongs to the app.
