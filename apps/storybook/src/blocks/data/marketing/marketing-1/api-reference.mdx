# Marketing1

A campaign performance screen on the collection Data Grid: a toolbar that carries the title, the count and the period, the search, one Configurações menu and the Exportar and Nova campanha buttons, a band of six indicators below it, and a grid with the spend, the conversions, an in-cell trend line, the CPA, the ROAS against its target and the share of new buyers. Reach for it on an analytics screen where each row carries several metrics to compare. Install it with `npx @tc96/cli add marketing-1`.

It is a section, not a page: it renders no `main` landmark. Numbers arrive raw and are formatted with `locale` and `currency`; the block sums nothing, so the indicator band comes from `summary`. The heading is the toolbar's: the pattern `CollectionToolbar` carries `labels.title` as the only `h2` and `labels.subtitle` as its description in its `left` slot, and the `DataGridSearch`, the `ViewSettings` and the header buttons in its `right` slot, the menu whose sections are the Data Grid submenus (`DataGridSortSubmenu`, `DataGridColumnsSubmenu`, `DataGridDensitySubmenu`) and a `FilterRadioSubmenu` for the status. The Data Grid keeps the search, the status filter, the page and the page size locally. The screen has no saved views. The sort, the column visibility and the density are the ones a consumer saves, so they are controllable (`sort`, `columnVisibility`, `density`) and reported (`onSortChange`, `onColumnVisibilityChange`, `onDensityChange`). Loading and error are the block's: the toolbar keeps the heading and hides its controls, `pending` renders its skeleton in place of the band and the grid, and `error` an error surface with a retry button; the precedence is `pending`, then `error`.

The other pages of `Blocks/Data/Marketing/Marketing1`: [Playground](?path=/story/blocks-data-marketing-marketing1-playground--playground) to try the controls, [Behavior](?path=/story/blocks-data-marketing-marketing1-behavior--the-heading-appears-once) for the tests, [States](?path=/story/blocks-data-marketing-marketing1-states--default) for the loaded, loading, error and empty states and [Usages](?path=/story/blocks-data-marketing-marketing1-usages--loaded) for the data read over the network.

## Import

```tsx
import { Marketing1 } from '@tc96/ui/blocks/data/marketing/marketing-1'
```

The same path exports the types listed under Exports.

## Anatomy

The toolbar with the heading, the subtitle, the search, the Configurações menu and the two buttons; the six indicators; the grid with its footer and Linhas por página.

## Marketing1

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `campaigns` | `Marketing1Campaign[]` | required | The rows. Keep the array stable between renders. |
| `summary` | `Marketing1Summary` | required | The six indicators, already aggregated by the app. |
| `period` | `{ from: string; to: string }` | required | ISO dates shown in the subtitle. |
| `sort` | `Marketing1Sort \| null` | - | Controls the sort. Without it the grid sorts locally. |
| `onSortChange` | `(sort: Marketing1Sort \| null) => void` | - | Called once per sort change, from the Ordenar por submenu or a column menu. |
| `columnVisibility` | `Marketing1ColumnVisibility` | all visible | Controls the visible columns; a column is hidden only when its value is `false`. |
| `onColumnVisibilityChange` | `(visibility: Marketing1ColumnVisibility) => void` | - | Called once per change, from the Colunas submenu or a column menu. |
| `density` | `'short' \| 'medium' \| 'tall' \| 'extra-tall'` | `"tall"` | The row height. Controlled only with `onDensityChange`. |
| `onDensityChange` | `(density: Marketing1Density) => void` | - | Called when the Altura das linhas submenu changes the density. |
| `onExport` | `() => void` | - | The Exportar button renders only with it. |
| `onCreate` | `() => void` | - | The Nova campanha button renders only with it. |
| `rowActions` | `Marketing1RowAction[]` | - | The items of the row menu. |
| `onRowAction` | `(actionId: string, campaignId: string) => void` | - | The menu column renders only with `rowActions` and this callback. |
| `pageSize` | `number` | `10` | Initial rows per page of the footer. |
| `pageSizeOptions` | `readonly number[]` | `[10, 20, 50]` | The choices of the Linhas por página selector; `pageSize` joins them when it is not listed. |
| `locale` | `string` | `"pt-BR"` | Locale of the numbers, percentages and dates. |
| `currency` | `string` | `"BRL"` | ISO currency of the spend and CPA values. |
| `pending` | `boolean` | `false` | Renders the skeleton in place of the band and the grid and keeps only the heading in the toolbar; wins over `error`. |
| `error` | `boolean` | `false` | Renders the error surface below the heading. |
| `onRetry` | `() => void` | - | Called by the Tentar novamente button; without it the button is not rendered. |
| `labels` | `Partial<Marketing1Labels>` | pt-BR texts | Overrides the texts of the block; `channels`, `columns`, `densities` and `statuses` merge key by key. Keep the object stable, because the columns are rebuilt when it changes. |
| `className` | `string` | - | Merged into the root classes. |

## Accessibility and theme

- The grid follows the WAI-ARIA grid pattern with arrow key navigation; the skeleton is `aria-busy="true"` and named by `labels.loading`, and the error surface has the `alert` role.
- The trend line is `aria-hidden` and followed by a hidden summary; the bullet bar and the share bar are `aria-hidden` and followed by the value as text.
- A change shows an arrow and a hidden word that says the direction and whether it is favorable, so the green and red tones never carry the meaning alone. In the CPA column an increase is the unfavorable direction.
- The settings are a menu whose submenus use `menuitemradio` and `menuitemcheckbox`.
- The block carries no color, radius or shadow of its own beyond token classes: the theme belongs to the app.
