# Navbar1

A page-top bar for a project workspace: a breadcrumb, the collaborators, an optional menu of global actions and an optional primary Share button. Reach for it above the content of a project, board or document page. Install it with `npx @tc96/cli add navbar-1`.

It renders a `header`, not a page: it carries no `main` landmark. The block keeps no state: the share action is a callback.

The other pages of `Blocks/Application/Navbar/Navbar1`: [Playground](?path=/story/blocks-application-navbar-navbar1-playground--playground) to try the controls, [Behavior](?path=/story/blocks-application-navbar-navbar1-behavior--breadcrumb-links-all-but-the-current-page) for the tests and [Usages](?path=/story/blocks-application-navbar-navbar1-usages--project-page-header) for a project page.

## Import

```tsx
import { Navbar1 } from '@tc96/ui/blocks/application/navbar/navbar-1'
```

The same path exports the types listed under Exports.

## Anatomy

The breadcrumb on the left; the collaborators, the more-actions menu and the Share button on the right.

```tsx

```

## Navbar1

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `breadcrumbs` | `NavbarBreadcrumbItem[]` | required | The path, in order. The last item is the current page; the others link when they have an `href`. |
| `collaborators` | `NavbarPerson[]` | - | The people on the project. Four show; the rest become a count. Empty or missing renders no group. |
| `menu` | `ReactNode` | - | The `MenuItem`s of the global actions menu, opened by a "..." button after the collaborators. Without it no button renders. |
| `onShare` | `() => void` | - | Called when Share is clicked; the button is `primary`. Without it no button renders. |
| `renderLink` | `(href: string) => ReactElement` | `renderAnchor` | Renders the breadcrumb links, so the app can pass its router link. |
| `labels` | `Partial<Navbar1Labels>` | pt-BR texts | Overrides the texts of the block; see Labels below. |
| `className` | `string` | - | Merged into the root classes. |

## NavbarPerson

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | Identifies the person. |
| `name` | `string` | Name of the person; its initials fill the avatar and it is the tooltip. |
| `avatarUrl` | `string` | Photo of the person. Without it the initials show. |

## Labels

| Key | Type | Default |
| --- | --- | --- |
| `breadcrumb` | `string` | `"Caminho da página"`; the accessible name of the breadcrumb |
| `collaborators` | `(count: number) => string` | `"6 colaboradores"`; the accessible name of the avatar group |
| `menu` | `string` | `"Mais ações"`; the accessible name of the "..." button |
| `share` | `string` | `"Compartilhar"`; the visible text of the button |

## Exports

| Export | Kind | Description |
| --- | --- | --- |
| `Navbar1` | `component` | The project workspace bar. |
| `Navbar1Props` | `type` | The props of the bar. |
| `Navbar1Labels` | `type` | The keys of `labels`. |

## Accessibility and theme

- The header holds a breadcrumb navigation and the avatar group (named by `labels.collaborators`); the current page is marked with `aria-current`.
- The block carries no color, radius or shadow of its own beyond the bottom border: the theme belongs to the app.
