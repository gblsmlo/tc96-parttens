# Navbar7

The analytics toolbar at the top of a dashboard page: a breadcrumb with refresh, auto-refresh, share and overflow controls, and a second row with a date range picker, a compare toggle and a ⌘K command search. Reach for it on a reports or analytics page where one period drives every chart. Install it with `npx @tc96/cli add navbar-7`.

It renders a `header` that is full width with a bottom border and two rows. The block keeps only the open state of the date range popover and of the search dialog; the range, the compare flag and the refresh interval are controlled by the app, which also loads the data.

The other pages of `Blocks/Application/Navbar/Navbar7`: [Playground](?path=/story/blocks-application-navbar-navbar7-playground--playground) to try the controls, [Behavior](?path=/story/blocks-application-navbar-navbar7-behavior--breadcrumb-ends-on-the-current-page) for the tests and [Usages](?path=/story/blocks-application-navbar-navbar7-usages--switching-reports-from-the-search) for a page with controlled state.

## Import

```tsx
import { Navbar7 } from '@tc96/ui/blocks/application/navbar/navbar-7'
```

The same path exports the types listed under Exports.

## Anatomy

A breadcrumb, refresh button, interval select, share button and overflow menu on the first row; the November range, the compare toggle and the search button on the second.

## Navbar7

Every control renders only when its data and its callback are passed; the second row is absent when none of its controls renders.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `breadcrumb` | `Navbar7Crumb[]` | required | The path; the last item is the current page and never a link. |
| `onRefresh` | `() => void` | - | Renders the refresh icon button and calls it on click. |
| `refreshOptions` | `Navbar7RefreshOption[]` | `[]` | The options of the auto-refresh select. |
| `refreshInterval` | `string` | first option | The `id` of the selected option. |
| `onRefreshIntervalChange` | `(id: string) => void` | - | Called with the `id` of the chosen option; with `refreshOptions` it renders the select. |
| `onShare` | `() => void` | - | Renders the Compartilhar button. |
| `menu` | `ReactNode` | - | `MenuItem`s of the overflow menu; without it no trigger renders. |
| `range` | `Navbar7Range` | `{}` | The selected period; without `from` the picker shows the placeholder. |
| `onRangeChange` | `(range: Navbar7Range) => void` | - | Renders the date range picker; called on every click in the calendar. |
| `compare` | `boolean` | `false` | The pressed state of the Comparar toggle. |
| `onCompareChange` | `(compare: boolean) => void` | - | Renders the toggle; called with the next state. |
| `searchItems` | `Navbar7SearchItem[]` | - | The entries of the command dialog. |
| `onSearchSelect` | `(id: string) => void` | - | Called with the `id` of the chosen entry; with `searchItems` it renders the search button. |
| `locale` | `string` | `'pt-BR'` | The `Intl` locale that formats the range in the button. |
| `calendarLocale` | `Locale` | `ptBR` | The locale of the calendar, from `@daypicker/react/locale`. |
| `renderLink` | `RenderLink` | plain anchor | Builds the element of each breadcrumb link, for the app's router. |
| `labels` | `Partial<Navbar7Labels>` | pt-BR texts | Overrides the texts of the block; see Labels below. |
| `className` | `string` | - | Merged into the root classes. |

## Navbar7Crumb, Navbar7Range, Navbar7RefreshOption and Navbar7SearchItem

| Type | Field | Description |
| --- | --- | --- |
| `Navbar7Crumb` | `id`, `label`, `href?` | An item without `href` renders as text. |
| `Navbar7Range` | `from?`, `to?` | Dates of the period. The button shows `from` alone while `to` is missing. |
| `Navbar7RefreshOption` | `id`, `label` | An option of the interval select. |
| `Navbar7SearchItem` | `id`, `label`, `group?` | An entry of the dialog; entries with the same `group` sit under one heading, and entries without it have no heading. |

## Accessibility and theme

- The breadcrumb is a named `nav`; the current page carries `aria-current="page"`.
- The refresh, overflow and interval controls are named by `labels`, never by an icon alone.
- The compare control is a toggle button with `aria-pressed`.
- The date range button shows the range as text; the calendar opens in a named popover, is operable with the arrow keys and closes with Escape.
- The search opens from the button and from ⌘K or Ctrl+K; the dialog traps focus, filters as you type and closes with Escape.
- Buttons use the `sm` and `icon-sm` sizes.
- The block carries no color, radius or shadow of its own: the theme belongs to the app.
