# RecordDialog2

A create dialog for a calendar event on the Record Dialog inline-properties layout, prefilled with the slot the calendar picked: borderless title and description, then Date, Type and the chips of the chosen type (Reunião, Videochamada or Ligação), Calendar and Availability, pinned to the bottom with `stretchBody`. Reach for it when Nova atividade should capture an event in a compact dialog. Install it with `npx @tc96/cli add record-dialog-2`.

The block keeps only the draft and the create-more switch: the slot, the people catalog and the save are the consumer's. An end before the start, or a failed save, shows in `errorMessage`. Create more keeps the dialog open after saving and puts the fields back to the slot.

The other pages of `Blocks/Application/Record Dialog/Agenda/RecordDialog2`: [Playground](?path=/story/blocks-application-record-dialog-agenda-recorddialog2-playground--playground) to try the controls and [States](?path=/story/blocks-application-record-dialog-agenda-recorddialog2-states--default) for the open dialog.

## Import

```tsx
import { RecordDialog2 } from '@tc96/ui/blocks/application/record-dialog/record-dialog-2'
```

The same path exports the types listed under Exports, plus `recordDialog2SlotFromCalendar` and `defaultRecordDialog2Slot`.

## Anatomy

An open dialog on the default slot.

```tsx
<RecordDialog2

```

## RecordDialog2

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | - | Whether the dialog is open. |
| `onOpenChange` | `(open: boolean) => void` | - | Called when the dialog asks to open or close. |
| `onCreate` | `(values: RecordDialog2Values) => void \| Promise<void>` | - | Called with the validated values on save. A thrown error keeps the dialog open with its message. |
| `people` | `readonly RecordDialog2Person[]` | - | The guest options of the People property. |
| `slot` | `RecordDialog2Slot` | `defaultRecordDialog2Slot` | The day and `HH:mm` window read on mount and after a successful create-more save. Remount (or a new `key`) to apply a new slot. |
| `locale` | `string` | `"pt-BR"` | Locale of the schedule property. |
| `timeZone` | `string` | `"America/Sao_Paulo"` | Zone used to turn the day and times into ISO instants. |
| `typeOptions` | `readonly PropertyOption[]` | from labels | Overrides the Type select options. |
| `calendarOptions` | `readonly PropertyOption[]` | from labels | Overrides the Calendar select options. |
| `availabilityOptions` | `readonly PropertyOption[]` | from labels | Overrides the Availability select options. |
| `labels` | `Partial<RecordDialog2Labels>` | pt-BR texts | Overrides the texts of the block. |
| `className` | `string` | - | Merged into the dialog popup. |

## RecordDialog2Slot

| Field | Type | Description |
| --- | --- | --- |
| `date` | `string` | ISO instant at noon UTC for the picked day. |
| `start` | `string` | Start time as `HH:mm`. |
| `end` | `string` | End time as `HH:mm`. |

## RecordDialog2Values

| Field | Type | Description |
| --- | --- | --- |
| `title` | `string` | Trimmed title. |
| `description` | `string` | Trimmed description from the headline. |
| `start` / `end` | `string` | ISO instants of the window in `timeZone`. |
| `allDay` | `boolean` | Whether the schedule is all day. |
| `frequency` | `string \| null` | Recurrence value, or `null`. |
| `until` | `string \| null` | Recurrence end date serialized by the schedule property. |

| `guests` | `readonly string[]` | Selected person ids, empty for a call. |

| `link` | `string` | Trimmed link, sent for a video call. |
| `phones` | `readonly string[]` | Numbers, sent for a call. |
| `calendar` | `"appointments" \| "sales" \| "personal"` | Target calendar. |
| `availability` | `"busy" \| "free"` | Busy or free. |

## Accessibility and theme

- The dialog is named by the title that follows Type (`labels.titleEvent` or `labels.titleAppointment`).
- Focus, Escape and Mod+Enter come from the Record Dialog pattern; errors render with `role="alert"`.
- The block carries no raw color, radius or shadow: it composes Record Dialog and the property displays as chips.
