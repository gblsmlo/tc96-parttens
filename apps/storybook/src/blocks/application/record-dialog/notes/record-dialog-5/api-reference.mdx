# RecordDialog5

A create or edit dialog for a note on a record, on the Record Dialog property-bar layout: the record name as the trail, a title without a description, Status, Prioridade and Responsável as a bar of `plain` chips and a `RichTextEditor` that fills the rest of the popup in the `readable` column. Reach for it when a record keeps notes. Pass `note` to edit one; the dialog resets its fields when `note` changes. Install it with `npx @tc96/cli add record-dialog-5`.

The block keeps only its draft: the catalogs and the save are the consumer's. A failed save keeps the dialog open and shows its message in `errorMessage`.

The other pages of `Blocks/Application/Record Dialog/Notes/RecordDialog5`: [Playground](?path=/story/blocks-application-record-dialog-notes-recorddialog5-playground--playground) to try the controls and [States](?path=/story/blocks-application-record-dialog-notes-recorddialog5-states--default) for the open dialog.

## RecordDialog5

The props are typed by `RecordDialog5Props`, exported from the same path with `RecordDialog5Labels`, `RecordDialog5Values` and the option builders. Every text comes from `labels` (pt-BR defaults), every catalog from a prop, and `className` is merged into the dialog popup.

## Accessibility and theme

- The dialog is named by its title.
- Focus, Escape and Mod+Enter come from the Record Dialog pattern; errors render with `role="alert"`.
- The block carries no raw color, radius or shadow: it composes Record Dialog and the property displays.
