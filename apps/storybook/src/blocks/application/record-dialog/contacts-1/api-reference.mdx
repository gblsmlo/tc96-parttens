# Contacts1

A create dialog for a contact on the Record Dialog row-properties layout. Phone, e-mail and document are always shown. The document has no type field: 11 digits take the CPF mask and 12 or more take the CNPJ mask. A contact can hold more than one document. Etapa, Tags, Empresa and Cargo stay behind the more menu. Install it with `npx @tc96/cli add record-dialog-contacts-1`.

The other pages of `Blocks/Application/Record Dialog/Contacts/Contacts1`: [Playground](?path=/story/blocks-application-record-dialog-contacts-contacts1-playground--playground) and [States](?path=/story/blocks-application-record-dialog-contacts-contacts1-states--multiple) for a CPF and a CNPJ together, [CPF](?path=/story/blocks-application-record-dialog-contacts-contacts1-states--cpf) and [CNPJ](?path=/story/blocks-application-record-dialog-contacts-contacts1-states--cnpj).
