# Dashboard7

A finance analytics dashboard for a law firm, mapped from the Financeiro screens of lemind (Analítico, Fluxo de caixa and Dinheiro de clientes). From top to bottom: a header with breadcrumb, title, description and period select; an optional account filter; a row of balance cards (realized today and one per projection date) and a row of four indicators (Inadimplência, Prazo de recebimento, Margem de caixa, Fôlego de caixa), each card with its explanation as visible text; a column chart of income and expenses per month with the period totals beside a bar chart of what is open, overdue and received; a bar chart by category with a Receitas / Despesas toggle beside the entries due in the next 7 days; the realized balance per account and the client money table with pagination; and the cash-flow grid by month. Reach for it on the finance home of a services firm. Install it with `npx @tc96/cli add dashboard-7`.

It is a section, not a page: it renders no `main` landmark. The block never fetches, filters, sums or pages, and keeps no state. Money arrives in cents and is formatted with `locale` and `currency`; dates arrive as ISO values (`YYYY-MM-DD`, months as `YYYY-MM`) and are shown in `timeZone`; text that depends on a business rule arrives ready (`runway.text`, every `detail`, `balances.scope`, the entry `kind` and `status`). The period select, the account filter, the category toggle, the client pagination and the grid cell buttons render only when their callbacks are passed. Loading, error and empty are the block's: `pending` renders its skeleton, `error` an error surface with a retry button, and the empty state shows only when every list is empty and `balances`, `receivables` and every indicator are absent. The precedence is `pending`, then `error`, then empty.

```tsx
import { Dashboard7 } from '@tc96/ui/blocks/application/dashboard/dashboard-7'
```

The same path exports the types listed under Exports.

## Anatomy

One balance and three projections, four indicators, six months (three realized, the current one and two forecast), three entries due soon, two accounts, three of five clients and the grid of the same six months.

## Data types

| Type | Fields |
| --- | --- |
| `Dashboard7CashFlowMonth` | `month` (`YYYY-MM`), `column` (`realized`, `current` or `forecast`), `inflowCents` and `outflowCents`. |
| `Dashboard7Balances` | `realizedCents`, `projections` (`{ date, cents }[]`) and `scope`. |
| `Dashboard7Indicators` | `delinquency` and `cashMargin` (`{ ratio, detail }`), `collectionDays` (`{ days, detail }`) and `runway` (`{ text, detail }`, the text already written, such as `2,5 meses`). |
| `Dashboard7Entry` | `id`, `description`, `kind`, `dueDate`, `amountCents` (signed), `status` (`{ label, tone? }`) and `href`. |
| `Dashboard7CashFlowGrid` | `months` (`{ month, column }[]`) and `rows` (`{ id, label, kind: 'section' \| 'line' \| 'total', cells, selectable? }`), where `cells[i]` is the cents of `months[i]` or `null`. |
| `Dashboard7Category`, `Dashboard7AccountBalance`, `Dashboard7ClientMoney` | `id`, `name` and the amount in cents (`cents`, `heldCents`), plus `share` or `href`. |

## Accessibility and theme

- Every chart is drawn with TanStack Charts as one SVG with `role="img"`, named by its label (`cashFlowLabel`, `receivablesLabel`, `categoriesLabel`) and described by a `<desc>` built by a summary label function with every value. The SVG is focusable and the arrow keys move between the points, with a tooltip per point.
- Forecast months are drawn with a lighter fill and a dashed outline, the legend shows a dashed marker named Previsto, and the summary marks each forecast month with `(previsto)`, so color is not the only cue. The `current` month is drawn solid, as realized.
- The cash-flow grid is a table with the exact values of every month; each month header carries a badge (Realizado, Mês atual, Previsto). A cell button is named by `labels.cellEntries(row, month, value)`, which keeps the visible value in the name. The table scrolls sideways inside a focusable `region` named by `labels.gridScroll`, so the hidden months are reachable by keyboard.
- The balance and indicator cards show their explanation as visible text, not in a tooltip.
- The skeleton is `aria-busy="true"` and named by `labels.loading`; the error surface has the `alert` role.
- Chart colors come from `--chart-1` to `--chart-3`; status colors come from the theme badge tones. The block carries no raw color, radius or shadow.
