# Dashboard1

A fulfillment exceptions dashboard in four layers: a header with breadcrumb, title, description, period select and Exportar; a row of four KPI cards; a bar chart of capacity used against capacity per distribution center beside a donut of exceptions by reason; and a table of open exceptions with a status filter that shows a count per option, a search, pagination and a menu per row. Reach for it on an operations home page that shows what is stuck and where. Install it with `npx @tc96/parttens add dashboard-1`.

It is a section, not a page: it renders no `main` landmark. The block never fetches and keeps no state. The filter is controlled: the app passes `filter` and `filterOptions` (with an optional `count` each), handles `onFilterChange` and passes the rows it already filtered. The period select, Exportar, the search, the pagination and the row menu render only when their callbacks are passed, and the app searches and pages the rows. The donut renders only with `reasons`. Numbers arrive raw and the block formats them with `locale` and `currency` (`pt-BR` and `BRL` by default). Loading, error and empty are the block's: `pending` renders its skeleton, `error` an error surface with a retry button, and an empty `kpis`, `capacity`, `reasons` and `exceptions` the empty state. The precedence is `pending`, then `error`, then empty.

## Import

```tsx
import { Dashboard1 } from '@tc96/blocks/application/dashboard/dashboard-1'
```

The same path exports the types listed under Exports.

## Anatomy

Four KPIs, the capacity of five centers, four reasons and six open exceptions.

| Prop | Type | Default | Description |

| `kpis` | `Dashboard1Kpi[]` | required | The KPI cards, in order. |

## Accessibility and theme

- The header is a `header` with the `h2` title; the breadcrumb is a `navigation` named by `labels.breadcrumb` and the period select a `combobox` named by `labels.period`.
- The search is a `searchbox` named by `labels.search`; the pagination is a `navigation` named by `labels.pagination` whose buttons are disabled at the ends.
- The capacity chart and the donut are `img`s named by `labels.capacityLabel` and `labels.reasonsLabel` and described by visually hidden texts from `labels.capacitySummary` and `labels.reasonsSummary`.
- Each row menu is a button named by `labels.rowActionsFor`.
- The filter is a toggle group named by `labels.filter`; the active option has `aria-pressed`.
- The skeleton is `aria-busy="true"` and named by `labels.loading`; the error surface has the `alert` role.
- Chart colors come from `--chart-1` to `--chart-5`; status colors from the theme badge tones. The block carries no raw color, radius or shadow.
