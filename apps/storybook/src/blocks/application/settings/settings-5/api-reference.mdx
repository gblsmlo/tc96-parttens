# Settings5

A workspace settings section with the logo, the name, the URL, the time zone and a danger zone that deletes the workspace. Reach for it when the app lets an admin edit the workspace itself. Install it with `npx @tc96/cli add settings-5`.

It is a section, not a page: it renders no `main` landmark. Saving stays in the app: the block calls the `on...` callbacks, keeps no list and never fetches or stores anything. The name and the URL are read when their field loses focus, and the time zone is kept in local state so the select shows the new value at once.

The other pages of `Blocks/Application/Settings/Settings5`: [Playground](?path=/story/blocks-application-settings-settings5-playground--playground) to try the texts and the workspace values, [Behavior](?path=/story/blocks-application-settings-settings5-behavior--name-commit-sends-value-on-blur) for the tests and [Usages](?path=/story/blocks-application-settings-settings5-usages--loaded) for the workspace read over the network.

## Import

```tsx
import { Settings5 } from '@tc96/ui/blocks/application/settings/settings-5'
```

The same path exports the types `Settings5Props`, `Settings5Labels` and `Settings5TimeZone`.

## Settings5

The workspace settings. Renders the workspace section, with the logo, the name, the URL and the time zone, and the danger section with the delete button.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `name` | `string` | required | The workspace name, the first value of the name field. Also written into the description. |
| `slug` | `string` | required | The workspace URL, shown after `labels.urlPrefix`. |
| `initials` | `string` | required | The text of the logo placeholder. |
| `timeZone` | `string` | required | The value selected first in the time zone select. |
| `timeZones` | `Settings5TimeZone[]` | required | The time zones to choose from. |
| `onNameCommit` | `(value: string) => void` | - | Called with the name when the name field loses focus. |
| `onSlugCommit` | `(value: string) => void` | - | Called with the URL when its field loses focus. |
| `onTimeZoneChange` | `(value: string) => void` | - | Called with the chosen time zone value. |
| `onUploadLogo` | `() => void` | - | Called when the logo placeholder is clicked. |
| `onDeleteWorkspace` | `() => void` | - | Called when the delete button is clicked. |
| `pending` | `boolean` | `false` | Replaces the content with the skeleton of the block, an `output` with `aria-busy="true"` named by `labels.loading`. Wins over `error`. |
| `error` | `boolean` | `false` | Replaces the content with the error `StateSurface` (`role="alert"`). Wins over the empty state. |
| `onRetry` | `() => void` | - | Called by the Tentar novamente button of the error state; without it the button does not render. |
| `labels` | `Partial<Settings5Labels>` | pt-BR texts | Overrides the texts of the block; see Labels below. |
| `className` | `string` | - | Merged into the root element's classes. |

The block takes no other props.

## Settings5TimeZone

| Field | Type | Description |
| --- | --- | --- |
| `value` | `string` | The value passed to `onTimeZoneChange`, for example `America/Sao_Paulo`. |
| `label` | `string` | The text of the option and of the selected value. |

## Accessibility and theme

- The logo placeholder is a button named by `labels.uploadLogo`.
- The name field, the URL field and the time zone select are named by `labels.nameLabel`, `labels.urlLabel` and `labels.timeZoneLabel`.
- The block carries no color, radius or shadow of its own: the theme belongs to the app.
