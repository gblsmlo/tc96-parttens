# Settings15

A settings section that lists the categories of the entries, receipts and expenses, each with its subcategories. Each row shows its name, how many entries use it and, for a top-level category, its direction as a dot and a label. The actions menu edits, adds a subcategory, archives or restores. Reach for it when the app classifies entries by category and lets people organize them one level deep. Install it with `npx @tc96/cli add settings-15`.

It is a section, not a page: it renders no `main` landmark. Creating, editing and archiving stay in the app; the block only calls `onCreate` and `onCategoryAction`, keeps no list of its own and never fetches or stores anything. A subcategory has no Add subcategory action and no direction, so nesting stops at one level.

The other pages of `Blocks/Application/Settings/Settings15`: [Playground](?path=/story/blocks-application-settings-settings15-playground--playground) to try the texts, the empty list, the archived categories and the actions, [Behavior](?path=/story/blocks-application-settings-settings15-behavior--empty-list-shows-state-surface) for the tests and [Usages](?path=/story/blocks-application-settings-settings15-usages--loaded) for the list read over the network.

## Import

```tsx
import { Settings15 } from '@tc96/ui/blocks/application/settings/settings-15'
```

The same path exports the types `Settings15Props`, `Settings15Category`, `Settings15Direction`, `Settings15Action` and `Settings15Labels`.

## Settings15

The categories section. Renders the title, the description and, with `onCreate`, the New category button, then each category followed by its subcategories. With no categories it renders an empty state in place of the rows. With `archivedCategories` it renders a collapsed section, closed by default, after the active rows; without archived categories the section is not rendered.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `categories` | `Settings15Category[]` | required | The active categories to list; an empty array shows the empty state. Each category may carry `subcategories`, listed right below it. |
| `archivedCategories` | `Settings15Category[]` | `[]` | Categories listed in the collapsed archived section, with their subcategories. Only rendered when not empty. |
| `onCreate` | `() => void` | - | Called when the New category button is clicked. Without it the button is not rendered. |
| `onCategoryAction` | `(categoryId: string, action: Settings15Action) => void` | - | Called with the category id and `'edit'`, `'add-subcategory'`, `'archive'` or `'restore'` when a menu item is chosen. Without it the row menus are not rendered. |
| `pending` | `boolean` | `false` | Replaces the content with the skeleton of the block, an `output` with `aria-busy="true"` named by `labels.loading`. Wins over `error`. |
| `error` | `boolean` | `false` | Replaces the content with the error `StateSurface` (`role="alert"`). Wins over the empty state. |
| `onRetry` | `() => void` | - | Called by the Tentar novamente button of the error state; without it the button does not render. |
| `labels` | `Partial<Settings15Labels>` | pt-BR texts | Overrides the texts of the block; see Labels below. |
| `className` | `string` | - | Merged into the section's classes. |

The block takes no other props.

## Settings15Category

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | Identifies the category in `onCategoryAction`. |
| `name` | `string` | Title of the row. |
| `direction` | `'income' \| 'expense'` | Shown as a label on top-level rows only. |
| `entries` | `number` | Entries using the category, shown in `labels.entries`. |
| `subcategories` | `Settings15Category[]` | Rows listed below the category, described by `labels.subcategoryOf`. |

## Accessibility and theme

- The row menu button is named by `labels.actions(name)`, so each row's menu is told apart by screen readers.
- The direction dot is always paired with its text label, so the direction is not told apart by color alone.
- The empty state has `role="status"` and `data-kind="empty"`.
- The block carries no color, radius or shadow of its own: the theme belongs to the app.
