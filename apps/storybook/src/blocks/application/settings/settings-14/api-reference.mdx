# Settings14

A settings section that lists the accounts of the workspace, banks and cash boxes, with the opening balance and date of each one. Each row shows an icon, the name, the type, the opening balance and date and, when the app handles actions, a menu to edit, make default, archive or restore. The default account carries a star. Reach for it when the app settles entries in bank accounts or cash boxes and needs one of them as the default. Install it with `npx @tc96/parttens add settings-14`.

It is a section, not a page: it renders no `main` landmark. Creating, editing and archiving stay in the app; the block only calls `onCreate` and `onAccountAction`, keeps no list of its own and never fetches or stores anything. The default account is a prop: the block shows the star and the menu options that follow from it, and the app moves the default when `make-default` arrives.

The other pages of `Blocks/Application/Settings/Settings14`: [Playground](?path=/story/blocks-application-settings-settings14-playground--playground) to try the texts, the empty list, the archived accounts and the actions, [Behavior](?path=/story/blocks-application-settings-settings14-behavior--empty-list-shows-state-surface) for the tests and [Usages](?path=/story/blocks-application-settings-settings14-usages--loaded) for the list read over the network.

## Import

```tsx
import { Settings14 } from '@tc96/blocks/application/settings/settings-14'
```

The same path exports the types `Settings14Props`, `Settings14Account`, `Settings14AccountType`, `Settings14Action` and `Settings14Labels`.

## Settings14

The accounts section. Renders the title, the description and, with `onCreate`, the New account button, then one row per account. With no accounts it renders an empty state in place of the rows. With `archivedAccounts` it renders a collapsed section, closed by default, after the active rows; without archived accounts the section is not rendered.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `accounts` | `Settings14Account[]` | required | The active accounts to list; an empty array shows the empty state. |
| `archivedAccounts` | `Settings14Account[]` | `[]` | Accounts listed in the collapsed archived section. Only rendered when not empty. |
| `defaultAccountId` | `string` | - | The id of the default account. It gets the star and loses the Make default and Archive options. |
| `onCreate` | `() => void` | - | Called when the New account button is clicked. Without it the button is not rendered. |
| `onAccountAction` | `(accountId: string, action: Settings14Action) => void` | - | Called with the account id and `'edit'`, `'make-default'`, `'archive'` or `'restore'` when a menu item is chosen. Without it the row menus are not rendered. |
| `currency` | `string` | `'BRL'` | Currency code of the opening balance. |
| `locale` | `string` | `'pt-BR'` | Locale of the amount and the date of the opening balance. |
| `pending` | `boolean` | `false` | Replaces the content with the skeleton of the block, an `output` with `aria-busy="true"` named by `labels.loading`. Wins over `error`. |
| `error` | `boolean` | `false` | Replaces the content with the error `StateSurface` (`role="alert"`). Wins over the empty state. |
| `onRetry` | `() => void` | - | Called by the Tentar novamente button of the error state; without it the button does not render. |
| `labels` | `Partial<Settings14Labels>` | pt-BR texts | Overrides the texts of the block; see Labels below. |
| `className` | `string` | - | Merged into the section's classes. |

The block takes no other props.

## Settings14Account

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | Identifies the account in `onAccountAction`. |
| `name` | `string` | Title of the row. |
| `type` | `'bank' \| 'cash'` | Chooses the icon and the type text shown in the description. |
| `openingBalance` | `number` | Opening balance, formatted with `currency` and `locale`. |
| `openingOn` | `string` | Opening day as an ISO day, `YYYY-MM-DD`, shown as a medium date. |

## Accessibility and theme

- The row menu button is named by `labels.actions(name)`, so each row's menu is told apart by screen readers.
- The empty state has `role="status"` and `data-kind="empty"`.
- The star is a flag with text, so the default account is not told apart by color alone.
- The block carries no color, radius or shadow of its own: the theme belongs to the app.
