# Settings21

A settings section that lists the apps connected to the workspace. Each row shows the app's initials, its name and description, a status badge (Conectado, Desconectado or Erro) and a button to connect, reconnect or disconnect. Reach for it when the app integrates with third-party services. Install it with `npx @tc96/parttens add settings-21`.

It is a section, not a page: it renders no `main` landmark. Connecting and disconnecting stay in the app; the block only calls `onConnect` and `onDisconnect` and keeps no status of its own.

The other pages of `Blocks/Application/Settings/Settings21`: [Playground](?path=/story/blocks-application-settings-settings21-playground--playground), [Behavior](?path=/story/blocks-application-settings-settings21-behavior--empty-list-shows-state-surface) and [Usages](?path=/story/blocks-application-settings-settings21-usages--loaded).

## Import

```tsx
import { Settings21 } from '@tc96/blocks/application/settings/settings-21'
```

The same path exports the types `Settings21Props`, `Settings21App`, `Settings21Status` and `Settings21Labels`.

## Anatomy

<Canvas of={ApiReferenceStories.Anatomy} />

```tsx
<Settings21
  apps={apps}
  onConnect={(appId) => connect(appId)}
  onDisconnect={(appId) => disconnect(appId)}
/>
```

## Settings21

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `apps` | `Settings21App[]` | required | The apps to list; an empty array shows the empty state. |
| `onConnect` | `(appId: string) => void` | - | Called by the Conectar button of a disconnected app and the Reconectar button of an app in error. Without it those buttons are not rendered. |
| `onDisconnect` | `(appId: string) => void` | - | Called by the Desconectar button of a connected app. Without it the button is not rendered. |
| `labels` | `Partial<Settings21Labels>` | pt-BR texts | Overrides the texts of the block; see Labels below. |
| `className` | `string` | - | Merged into the section's classes. |

## Settings21App

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | Identifies the app in the callbacks. |
| `name` | `string` | Title of the row; its first two initials fill the icon frame. |
| `description` | `string` | Line under the name. |
| `status` | `'connected' \| 'disconnected' \| 'error'` | Picks the badge and the button. |

## Accessibility and theme

- Each button is named by its `*Action(name)` label, so rows are told apart by screen readers; the visible text is contained in the name.
- The status is text in the badge, never color alone; the initials frame is decorative.
- The empty state has `role="status"` and `data-kind="empty"`.
- The block carries no color, radius or shadow of its own: the theme belongs to the app.
