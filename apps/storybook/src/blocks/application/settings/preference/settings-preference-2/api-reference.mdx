# SettingsPreference2

A settings section for the interface: a font size select, a language select and an email notifications switch. Reach for it when the app lets people choose the text size, the language and whether they get email notifications. Install it with `npx @tc96/cli add settings-preference-2`.

It is a section, not a page: it renders no `main` landmark. The block keeps no state of its own: it shows the `values` it receives and calls `onValueChange` with the key and the new value, so the app saves the change and passes the new `values` back.

The other pages of `Blocks/Application/Settings/Preference/Settings2`: [Playground](?path=/story/blocks-application-settings-preference-settings2-playground--playground) to try the texts, the values and the handler, [Behavior](?path=/story/blocks-application-settings-preference-settings2-behavior--font-size-calls-on-value-change) for the tests and [Usages](?path=/story/blocks-application-settings-preference-settings2-usages--loaded) for the settings read over the network.

## Import

```tsx
import { SettingsPreference2 } from '@tc96/ui/blocks/application/settings/preference/settings-preference-2'
```

The same path exports the types `SettingsPreference2Props`, `SettingsPreference2Values`, `SettingsPreference2Options`, `SettingsPreference2SettingOption` and `SettingsPreference2Labels`.

## SettingsPreference2

The settings section. Renders the title and, in order, the font size row, the language row and the email notifications row. Each select takes its options from `options` and shows the option whose value matches `values`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `values` | `SettingsPreference2Values` | required | The current values of the three rows. |
| `options` | `SettingsPreference2Options` | required | The options of the two selects, `fontSize` and `language`. |
| `onValueChange` | `<K extends keyof SettingsPreference2Values>(key: K, value: SettingsPreference2Values[K]) => void` | - | Called with `'fontSize'`, `'language'` or `'emailNotifications'` and the new value. Without it the rows cannot change and keep showing `values`. |
| `pending` | `boolean` | `false` | Replaces the content with the skeleton of the block, an `output` with `aria-busy="true"` named by `labels.loading`. Wins over `error`. |
| `error` | `boolean` | `false` | Replaces the content with the error `StateSurface` (`role="alert"`). Wins over the empty state. |
| `onRetry` | `() => void` | - | Called by the Tentar novamente button of the error state; without it the button does not render. |
| `labels` | `Partial<SettingsPreference2Labels>` | pt-BR texts | Overrides the texts of the block; see Labels below. |
| `className` | `string` | - | Merged into the section's classes. |

## SettingsPreference2Values

| Field | Type | Description |
| --- | --- | --- |
| `fontSize` | `string` | The value of the font size select; must match an option's `value`. |
| `language` | `string` | The value of the language select; must match an option's `value`. |
| `emailNotifications` | `boolean` | The state of the email notifications switch. |

## SettingsPreference2Options

| Field | Type | Description |
| --- | --- | --- |
| `fontSize` | `SettingsPreference2SettingOption[]` | The options of the font size select. |
| `language` | `SettingsPreference2SettingOption[]` | The options of the language select. |

A `SettingsPreference2SettingOption` is `{ label, value }`: the label is shown, the value is what `onValueChange` receives.

## Accessibility and theme

- Each select trigger is named by its row label, and the switch is named by `labels.emailNotifications`.
- The block carries no color, radius or shadow of its own: the theme belongs to the app.
