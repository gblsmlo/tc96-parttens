# SettingsPreference3

A settings section for the appearance: a mode select (system, light or dark) and a theme select that lists the color presets of the app, grouped. Reach for it when the app lets people choose the light or dark mode and the color theme. Install it with `npx @tc96/cli add settings-preference-3`.

It is a section, not a page: it renders no `main` landmark. The block keeps no state: it shows `mode` and `colorTheme` and calls `onModeChange` or `onColorThemeChange` with the new value, so the app applies the theme and passes the new values back.

The other pages of `Blocks/Application/Settings/Preference/Settings3`: [Playground](?path=/story/blocks-application-settings-preference-settings3-playground--playground) to try the texts, the values and the handlers, [Behavior](?path=/story/blocks-application-settings-preference-settings3-behavior--mode-calls-on-mode-change) for the tests and [Usages](?path=/story/blocks-application-settings-preference-settings3-usages--loaded) for the appearance read over the network.

## Import

```tsx
import { SettingsPreference3 } from '@tc96/ui/blocks/application/settings/preference/settings-preference-3'
```

The same path exports the types `SettingsPreference3Props`, `SettingsPreference3Option`, `SettingsPreference3ThemeGroup` and `SettingsPreference3Labels`.

## SettingsPreference3

The appearance section. Renders the title, the mode row and the theme row. The theme select lists every option of `themeGroups`, one after another, and a separator goes between groups.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `mode` | `string` | required | The value of the mode select; must match a `modeOptions` value. |
| `modeOptions` | `SettingsPreference3Option[]` | required | The options of the mode select. |
| `colorTheme` | `string` | required | The value of the theme select; must match an option's `value` in `themeGroups`. |
| `themeGroups` | `SettingsPreference3ThemeGroup[]` | required | The theme options, in groups. A group without `label` is listed without a heading. |
| `onModeChange` | `(value: string) => void` | - | Called with the chosen mode value. Without it the mode select is not changeable. |
| `onColorThemeChange` | `(value: string) => void` | - | Called with the chosen theme value. Without it the theme select is not changeable. |
| `pending` | `boolean` | `false` | Replaces the content with the skeleton of the block, an `output` with `aria-busy="true"` named by `labels.loading`. Wins over `error`. |
| `error` | `boolean` | `false` | Replaces the content with the error `StateSurface` (`role="alert"`). Wins over the empty state. |
| `onRetry` | `() => void` | - | Called by the Tentar novamente button of the error state; without it the button does not render. |
| `labels` | `Partial<SettingsPreference3Labels>` | pt-BR texts | Overrides the texts of the block; see Labels below. |
| `className` | `string` | - | Merged into the section's classes. |

## SettingsPreference3Option

| Field | Type | Description |
| --- | --- | --- |
| `label` | `string` | The text of the option. |
| `value` | `string` | The value passed to the handler. For a theme it is the preset value, which also picks the swatch colors. |

## SettingsPreference3ThemeGroup

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | Identifies the group; the React key. |
| `label` | `string` | Optional heading of the group, shown above its options. |
| `options` | `SettingsPreference3Option[]` | The options of the group. |

## Accessibility and theme

- Each select trigger is named by its row label; the theme trigger shows the swatch and the name of the current preset.
- The swatches are hidden from screen readers: each option is read by its name.
- The block carries no color, radius or shadow of its own: the theme belongs to the app.
