# Settings3

A settings section for the interface: a font size select, a language select and an email notifications switch. Reach for it when the app lets people choose the text size, the language and whether they get email notifications. Install it with `npx @tc96/parttens add settings-3`.

It is a section, not a page: it renders no `main` landmark. The block keeps no state of its own: it shows the `values` it receives and calls `onValueChange` with the key and the new value, so the app saves the change and passes the new `values` back.

The other pages of `Blocks/Application/Settings/Settings3`: [Playground](?path=/story/blocks-application-settings-settings3-playground--playground) to try the texts, the values and the handler, [Behavior](?path=/story/blocks-application-settings-settings3-behavior--font-size-calls-on-value-change) for the tests and [Usages](?path=/story/blocks-application-settings-settings3-usages--loaded) for the settings read over the network.

## Import

```tsx
import { Settings3 } from '@tc96/blocks/application/settings/settings-3'
```

The same path exports the types `Settings3Props`, `Settings3Values`, `Settings3Options`, `Settings3SettingOption` and `Settings3Labels`.

## Settings3

The settings section. Renders the title and, in order, the font size row, the language row and the email notifications row. Each select takes its options from `options` and shows the option whose value matches `values`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `values` | `Settings3Values` | required | The current values of the three rows. |
| `options` | `Settings3Options` | required | The options of the two selects, `fontSize` and `language`. |
| `onValueChange` | `<K extends keyof Settings3Values>(key: K, value: Settings3Values[K]) => void` | - | Called with `'fontSize'`, `'language'` or `'emailNotifications'` and the new value. Without it the rows cannot change and keep showing `values`. |
| `pending` | `boolean` | `false` | Replaces the content with the skeleton of the block, an `output` with `aria-busy="true"` named by `labels.loading`. Wins over `error`. |
| `error` | `boolean` | `false` | Replaces the content with the error `StateSurface` (`role="alert"`). Wins over the empty state. |
| `onRetry` | `() => void` | - | Called by the Tentar novamente button of the error state; without it the button does not render. |
| `labels` | `Partial<Settings3Labels>` | pt-BR texts | Overrides the texts of the block; see Labels below. |
| `className` | `string` | - | Merged into the section's classes. |

## Settings3Values

| Field | Type | Description |
| --- | --- | --- |
| `fontSize` | `string` | The value of the font size select; must match an option's `value`. |
| `language` | `string` | The value of the language select; must match an option's `value`. |
| `emailNotifications` | `boolean` | The state of the email notifications switch. |

## Settings3Options

| Field | Type | Description |
| --- | --- | --- |
| `fontSize` | `Settings3SettingOption[]` | The options of the font size select. |
| `language` | `Settings3SettingOption[]` | The options of the language select. |

A `Settings3SettingOption` is `{ label, value }`: the label is shown, the value is what `onValueChange` receives.

## Accessibility and theme

- Each select trigger is named by its row label, and the switch is named by `labels.emailNotifications`.
- The block carries no color, radius or shadow of its own: the theme belongs to the app.
