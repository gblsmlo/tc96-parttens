# Settings12

A settings section for the next actions a lead must complete before leaving each open stage. It has a gate switch that decides whether a stage change waits for the required actions, and under it one collapsible group per stage with its actions. Each action row shows its type, a switch that marks it required and, when the app handles actions, a menu to edit or delete. Reach for it when the app lets people set the steps a lead must go through. Install it with `npx @tc96/parttens add settings-12`.

It is a section, not a page: it renders no `main` landmark. Creating, editing and deleting stay in the app; the block only calls its callbacks, keeps no list of its own and never fetches or stores anything.

The other pages of `Blocks/Application/Settings/Settings12`: [Playground](?path=/story/blocks-application-settings-settings12-playground--playground) to try the texts, the empty list and the actions, [Behavior](?path=/story/blocks-application-settings-settings12-behavior--block-stage-changes-switch-calls-on-change) for the tests and [Usages](?path=/story/blocks-application-settings-settings12-usages--loaded) for the list read over the network.

## Import

```tsx
import { Settings12 } from '@tc96/blocks/application/settings/settings-12'
```

The same path exports the types `Settings12Props`, `Settings12Stage`, `Settings12NextAction`, `Settings12ActionType`, `Settings12Action` and `Settings12Labels`.

  onBlockStageChangesChange={setBlockStageChanges}

## Settings12

The next actions section. Renders the gates section with its switch, then the actions section with the title, the description and, with `onCreate`, the New action button, then one collapsible group per stage. With no stages it renders an empty state in place of the groups.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `stages` | `Settings12Stage[]` | required | The stages to list; an empty array shows the empty state. |
| `blockStageChanges` | `boolean` | `false` | The state of the gate switch. |
| `onBlockStageChangesChange` | `(checked: boolean) => void` | - | Called with the new value when the gate switch is toggled. |
| `onRequiredChange` | `(actionId: string, required: boolean) => void` | - | Called with the action id and the new value when a required switch is toggled. |
| `onCreate` | `() => void` | - | Called when the New action button is clicked. Without it the button is not rendered. |
| `onNextActionAction` | `(actionId: string, action: Settings12Action) => void` | - | Called with the action id and `'edit'` or `'delete'` when a menu item is chosen. Without it the row menus are not rendered. |
| `pending` | `boolean` | `false` | Replaces the content with the skeleton of the block, an `output` with `aria-busy="true"` named by `labels.loading`. Wins over `error`. |
| `error` | `boolean` | `false` | Replaces the content with the error `StateSurface` (`role="alert"`). Wins over the empty state. |
| `onRetry` | `() => void` | - | Called by the Tentar novamente button of the error state; without it the button does not render. |
| `labels` | `Partial<Settings12Labels>` | pt-BR texts | Overrides the texts of the block; see Labels below. |
| `className` | `string` | - | Merged into the root's classes. |

The block takes no other props.

## Settings12Stage

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | Identifies the stage. |
| `name` | `string` | Name of the stage, shown in `labels.leaving`. |

## Settings12NextAction

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | Identifies the action in `onRequiredChange` and `onNextActionAction`. |

## Accessibility and theme

- The gate switch is named by `labels.blockStageChanges`, and each required switch by `labels.required(title)`.
- The row menu button is named by `labels.actions(title)`, so each row's menu is told apart by screen readers.
- The empty state has `role="status"` and `data-kind="empty"`.
- The block carries no color, radius or shadow of its own: the theme belongs to the app.
