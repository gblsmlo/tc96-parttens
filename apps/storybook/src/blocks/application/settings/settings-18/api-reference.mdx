# Settings18

A settings section of role capabilities. A role select sits in the header and the capabilities are cards in two columns, each with a title, a description and a switch. Reach for it when the app lets an admin choose what each role can do. Install it with `npx @tc96/parttens add settings-18`.

It is a section, not a page: it renders no `main` landmark. The block holds no value: the role and every switch come from props, and a change is reported through a callback. Loading the capabilities of the chosen role is the app's job.

The other pages of `Blocks/Application/Settings/Settings18`: [Playground](?path=/story/blocks-application-settings-settings18-playground--playground) to try the texts and the empty list, [Behavior](?path=/story/blocks-application-settings-settings18-behavior--capability-switch-calls-on-capability-change) for the tests and [Usages](?path=/story/blocks-application-settings-settings18-usages--loaded) for the permissions read over the network.

## Import

```tsx
import { Settings18 } from '@tc96/blocks/application/settings/settings-18'
```

The same path exports the types `Settings18Props`, `Settings18Capability`, `Settings18Role` and `Settings18Labels`.

## Anatomy

The section for the Editor role:

```tsx
<Settings18
  capabilities={capabilities}
  onCapabilityChange={(id, checked) => save(id, checked)}
  onRoleChange={setRole}
  roles={roles}
  selectedRole={role}
/>
```

## Settings18

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `roles` | `Settings18Role[]` | required | The options of the role select. |
| `selectedRole` | `string` | required | The `value` of the selected role. |
| `capabilities` | `Settings18Capability[]` | required | The cards of the selected role; an empty array shows the empty state. |
| `onRoleChange` | `(role: string) => void` | - | Called with the `value` of the chosen role. |
| `onCapabilityChange` | `(capabilityId: string, checked: boolean) => void` | - | Called when a switch is toggled. |
| `labels` | `Partial<Settings18Labels>` | pt-BR texts | Overrides the texts of the block; see Labels below. |
| `className` | `string` | - | Merged into the section's classes. |

## Settings18Capability and Settings18Role

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | Identifies the capability in `onCapabilityChange`. |
| `title` | `string` | Title of the card and accessible name of its switch. |
| `description` | `string` | Text under the title. |
| `checked` | `boolean` | Value of the switch. |
| `value` | `string` | Role only: the value passed to `onRoleChange`. |
| `label` | `string` | Role only: the text of the option. |

## Labels

| Key | Type | Default |
| --- | --- | --- |
| `title` | `string` | `"Permissões"` |
| `description` | `string` | `"Escolha o que cada função pode fazer no workspace."` |
| `role` | `string` | `"Função"`; the accessible name of the select |
| `emptyTitle` | `string` | `"Nenhuma capacidade"` |
| `emptyDescription` | `string` | `"Esta função ainda não tem capacidades configuráveis."` |

## Accessibility and theme

- The select is named by `labels.role` and each switch by its capability title.
- The cards are items of a list, so a screen reader announces how many there are.
- The empty state has `role="status"` and `data-kind="empty"`.
- The block carries no color, radius or shadow of its own: the theme belongs to the app.
