# Settings16

A settings section that lists the cost centers, the places where a cost is booked, such as a practice area, an office or a project. Each row shows its name, how many entries use it and a menu to edit or archive. Archived cost centers wait in a collapsed section and can be restored. Reach for it when the app tracks where money is spent and lets people manage those places. Install it with `npx @tc96/parttens add settings-16`.

It is a section, not a page: it renders no `main` landmark. Creating, editing and archiving stay in the app; the block only calls `onCreate` and `onCostCenterAction`, keeps no list of its own and never fetches or stores anything.

The other pages of `Blocks/Application/Settings/Settings16`: [Playground](?path=/story/blocks-application-settings-settings16-playground--playground) to try the texts, the empty list, the archived cost centers and the actions, [Behavior](?path=/story/blocks-application-settings-settings16-behavior--empty-list-shows-state-surface) for the tests and [Usages](?path=/story/blocks-application-settings-settings16-usages--loaded) for the list read over the network.

## Import

```tsx
import { Settings16 } from '@tc96/blocks/application/settings/settings-16'
```

The same path exports the types `Settings16Props`, `Settings16CostCenter`, `Settings16Action` and `Settings16Labels`.

## Settings16

The cost centers section. Renders the title, the description and, with `onCreate`, the New cost center button, then one row per cost center. With no cost centers it renders an empty state in place of the rows. With `archivedCostCenters` it renders a collapsed section, closed by default, after the active rows; without archived cost centers the section is not rendered.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `costCenters` | `Settings16CostCenter[]` | required | The active cost centers to list; an empty array shows the empty state. |
| `archivedCostCenters` | `Settings16CostCenter[]` | `[]` | Cost centers listed in the collapsed archived section. Only rendered when not empty. |
| `onCreate` | `() => void` | - | Called when the New cost center button is clicked. Without it the button is not rendered. |
| `onCostCenterAction` | `(costCenterId: string, action: Settings16Action) => void` | - | Called with the cost center id and `'edit'`, `'archive'` or `'restore'` when a menu item is chosen. Without it the row menus are not rendered. |
| `labels` | `Partial<Settings16Labels>` | pt-BR texts | Overrides the texts of the block; see Labels below. |
| `className` | `string` | - | Merged into the section's classes. |

The block takes no other props.

## Settings16CostCenter

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | Identifies the cost center in `onCostCenterAction`. |
| `name` | `string` | Title of the row. |
| `entries` | `number` | Entries using the cost center, shown in `labels.entries`. |

## Accessibility and theme

- The row menu button is named by `labels.actions(name)`, so each row's menu is told apart by screen readers.
- The empty state has `role="status"` and `data-kind="empty"`.
- The block carries no color, radius or shadow of its own: the theme belongs to the app.
