# SettingsNotificationChannel1

A settings section that sets which channels notify each event. Categories are tabs; inside a tab, a table lists the events as rows and the channels as columns, with one checkbox per cell. Reach for it when people choose how to be notified about leads, tasks or finance. Install it with `npx @tc96/cli add settings-notification-channel-1`.

It is a section, not a page: it renders no `main` landmark. The block keeps no matrix of its own: every checkbox reads `matrix` and every click calls `onChange`; only the selected tab is block state.

The other pages of `Blocks/Application/Settings/Notification Channel/Settings1`: [Playground](?path=/story/blocks-application-settings-notification-channel-settings1-playground--playground), [Behavior](?path=/story/blocks-application-settings-notification-channel-settings1-behavior--empty-list-shows-state-surface) and [Usages](?path=/story/blocks-application-settings-notification-channel-settings1-usages--loaded).

## Import

```tsx
import { SettingsNotificationChannel1 } from '@tc96/ui/blocks/application/settings/notification-channel/settings-notification-channel-1'
```

The same path exports the types `SettingsNotificationChannel1Props`, `SettingsNotificationChannel1Category`, `SettingsNotificationChannel1Event`, `SettingsNotificationChannel1Channel`, `SettingsNotificationChannel1Matrix` and `SettingsNotificationChannel1Labels`.

## SettingsNotificationChannel1

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `categories` | `SettingsNotificationChannel1Category[]` | required | One tab each, with its events. An empty array shows the empty state. |
| `channels` | `SettingsNotificationChannel1Channel[]` | required | The columns, shared by every tab. |
| `matrix` | `Record<string, Record<string, boolean>>` | required | `matrix[eventId][channelId]`; a missing entry reads as unchecked. |
| `onChange` | `(eventId: string, channelId: string, checked: boolean) => void` | - | Called when a checkbox is toggled. Without it the checkboxes render disabled. |
| `pending` | `boolean` | `false` | Replaces the content with the skeleton of the block, an `output` with `aria-busy="true"` named by `labels.loading`. Wins over `error`. |
| `error` | `boolean` | `false` | Replaces the content with the error `StateSurface` (`role="alert"`). Wins over the empty state. |
| `onRetry` | `() => void` | - | Called by the Tentar novamente button of the error state; without it the button does not render. |
| `labels` | `Partial<SettingsNotificationChannel1Labels>` | pt-BR texts | Overrides the texts of the block; see Labels below. |
| `className` | `string` | - | Merged into the section's classes. |

## Accessibility and theme

- Each checkbox is named by `labels.cell(event, channel)`, so a cell is told apart without its row and column.
- The tabs follow the Base UI tabs keyboard model: arrow keys move between categories.
- The empty state has `role="status"` and `data-kind="empty"`.
- The block carries no color, radius or shadow of its own: the theme belongs to the app.
