# SettingsAccount2

A billing screen with the current plan, the usage of the plan and the invoices. The plan card shows the name, the price, the renewal date and, when the app handles it, a Change plan button. Below it, one meter per usage metric shows what was used against the limit, and a table lists the invoices with a status badge and a download button. Reach for it when people manage their subscription. Install it with `npx @tc96/cli add settings-account-2`.

It is a section, not a page: it renders no `main` landmark. Changing the plan and downloading stay in the app; the block only calls `onChangePlan` and `onDownload`, keeps no state and never fetches or stores anything. Dates arrive already formatted; the amounts are formatted by the block with `formatAmount`.

The other pages of `Blocks/Application/Settings/Account/Settings2`: [Playground](?path=/story/blocks-application-settings-account-settings2-playground--playground) to try the texts, the empty invoices and the callbacks, [Behavior](?path=/story/blocks-application-settings-account-settings2-behavior--plan-summary-shows-price-and-renewal) for the tests and [Usages](?path=/story/blocks-application-settings-account-settings2-usages--loaded) for the data read over the network.

## Import

```tsx
import { SettingsAccount2 } from '@tc96/ui/blocks/application/settings/account/settings-account-2'
```

The same path exports the types `SettingsAccount2Props`, `SettingsAccount2Plan`, `SettingsAccount2Usage`, `SettingsAccount2Invoice`, `SettingsAccount2InvoiceStatus` and `SettingsAccount2Labels`.

## Anatomy

The plan card with three meters, and the invoices table:

## SettingsAccount2

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `plan` | `SettingsAccount2Plan` | required | Name, monthly price and renewal date of the plan. |
| `usage` | `SettingsAccount2Usage[]` | required | One meter per metric. |
| `invoices` | `SettingsAccount2Invoice[]` | required | The invoices to list; an empty array shows the empty state. |
| `onChangePlan` | `() => void` | - | Called when Change plan is clicked. Without it the button is not rendered. |
| `onDownload` | `(invoiceId: string) => void` | - | Called when the download button of a row is clicked. Without it the buttons are not rendered. |
| `currency` | `string` | `"BRL"` | Currency code passed to `formatAmount` for the price and the invoice amounts. |
| `locale` | `string` | `"pt-BR"` | Locale passed to `formatAmount`. |
| `pending` | `boolean` | `false` | Replaces the content with the skeleton of the block, an `output` with `aria-busy="true"` named by `labels.loading`. Wins over `error`. |
| `error` | `boolean` | `false` | Replaces the content with the error `StateSurface` (`role="alert"`). Wins over the empty state. |
| `onRetry` | `() => void` | - | Called by the Tentar novamente button of the error state; without it the button does not render. |
| `labels` | `Partial<SettingsAccount2Labels>` | pt-BR texts | Overrides the texts of the block; see Labels below. |
| `className` | `string` | - | Merged into the block's classes. |

The block takes no other props.

| Field | Type | Description |

## Accessibility and theme

- Each meter is a `role="meter"` with `aria-valuenow`, `aria-valuemax` and an `aria-valuetext` built by `labels.usage`.
- The download button is named by `labels.download(date)`, so each row is told apart by screen readers.
- The empty state has `role="status"` and `data-kind="empty"`.
- The block carries no color, radius or shadow of its own: the theme belongs to the app.
