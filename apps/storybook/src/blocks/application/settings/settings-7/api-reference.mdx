# Settings7

A settings section that lists tags with their subtags. Each row shows a color swatch, the name, how many leads and tasks use it and, when the app handles actions, a menu to edit, add a subtag or delete. Reach for it when the app lets people organize leads and tasks with tags. Install it with `npx @tc96/parttens add settings-7`.

It is a section, not a page: it renders no `main` landmark. Creating, editing and deleting stay in the app; the block only calls `onCreate` and `onTagAction`, keeps no list of its own and never fetches or stores anything.

The other pages of `Blocks/Application/Settings/Settings7`: [Playground](?path=/story/blocks-application-settings-settings7-playground--playground) to try the texts, the empty list and the actions, [Behavior](?path=/story/blocks-application-settings-settings7-behavior--empty-list-shows-state-surface) for the tests and [Usages](?path=/story/blocks-application-settings-settings7-usages--loaded) for the list read over the network.

## Import

```tsx
import { Settings7 } from '@tc96/blocks/application/settings/settings-7'
```

The same path exports the types `Settings7Props`, `Settings7Tag`, `Settings7Action` and `Settings7Labels`.

## Settings7

The tags section. Renders the title, the description and, with `onCreate`, the New tag button, then one row per tag, each followed by the rows of its subtags. With no tags it renders an empty state in place of the rows.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `tags` | `Settings7Tag[]` | required | The tags to list; an empty array shows the empty state. Each tag may carry `subtags`, listed right below it. |
| `onCreate` | `() => void` | - | Called when the New tag button is clicked. Without it the button is not rendered. |
| `onTagAction` | `(tagId: string, action: Settings7Action) => void` | - | Called with the tag id and `'edit'`, `'add-subtag'` or `'delete'` when a menu item is chosen. Without it the row menus are not rendered. |
| `labels` | `Partial<Settings7Labels>` | pt-BR texts | Overrides the texts of the block; see Labels below. |
| `className` | `string` | - | Merged into the section's classes. |

The block takes no other props.

## Settings7Tag

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | Identifies the tag in `onTagAction`. |
| `name` | `string` | Title of the row. |
| `colorClassName` | `string` | Classes of the swatch, for example `bg-violet-700 dark:bg-violet-500`. |
| `leads` | `number` | Leads using the tag, shown in `labels.usage`. |
| `tasks` | `number` | Tasks using the tag, shown in `labels.usage`. |
| `subtags` | `Settings7Tag[]` | Rows listed below the tag, described by `labels.subtagOf`. A subtag has no Add subtag action, so nesting stops at one level. |

## Labels

| Key | Type | Default |
| --- | --- | --- |
| `title` | `string` | `"Tags"` |
| `description` | `string` | `"Organize leads e tarefas com tags e subtags."` |
| `newTag` | `string` | `"Nova tag"` |
| `edit` | `string` | `"Editar"` |
| `addSubtag` | `string` | `"Adicionar subtag"` |
| `delete` | `string` | `"Excluir"` |
| `emptyTitle` | `string` | `"Nenhuma tag ainda"` |
| `emptyDescription` | `string` | `"Crie uma tag para organizar leads e tarefas."` |
| `actions` | `(name: string) => string` | `"Ações de Indicação"` for `"Indicação"`; the accessible name of the row menu |
| `subtagOf` | `(parent: string) => string` | `"Subtag de Cliente ativo"` for `"Cliente ativo"` |
| `usage` | `(leads: number, tasks: number) => string` | `"12 leads · 5 tarefas"`; `1 lead` and `1 tarefa` in the singular |

## Accessibility and theme

- The row menu button is named by `labels.actions(name)`, so each row's menu is told apart by screen readers.
- The empty state has `role="status"` and `data-kind="empty"`.
- The block carries no color, radius or shadow of its own: the theme belongs to the app.
