# Stats4

A card with the leads of a period: a headline total, a progress bar toward a goal and a stacked bar that splits the total by source, with a legend. A select in the header switches the period. Reach for it when a dashboard needs one glance at how many leads came in, how close the team is to the goal and where they came from. Install it with `npx @tc96/cli add stats-4`.

It is a card, not a page: it renders a `section` and no `main` landmark. The block keeps no state and fetches nothing: `range` is controlled, so the app reads the numbers of the chosen period and passes them back. Loading and error are the block's: `pending` renders its skeleton in place of the content and `error` an error surface with a retry button; the precedence is `pending`, then `error`.

The other pages of `Blocks/Application/Stats/Stats4`: [Playground](?path=/story/blocks-application-stats-stats4-playground--playground) to try the numbers and the empty bar, [Behavior](?path=/story/blocks-application-stats-stats4-behavior--total-and-goal-progress) for the tests, [States](?path=/story/blocks-application-stats-stats4-states--default) for the loaded, loading and error states and [Usages](?path=/story/blocks-application-stats-stats4-usages--loaded) for the card read over the network.

## Import

```tsx
import { Stats4 } from '@tc96/ui/blocks/application/stats/stats-4'
```

The same path exports the types `Stats4Props`, `Stats4Source`, `Stats4Range` and `Stats4Labels`.

## Anatomy

The card with the 30 days range:

```tsx
<Stats4
  goal={1500}
  onRangeChange={setRange}

  sources={sources}
  total={1200}

```

## Stats4

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `total` | `number` | required | Leads in the period, shown as the headline. |
| `goal` | `number` | required | Goal of the period. The progress bar is `total / goal`, capped at 100%; a goal of `0` shows 0%. |
| `sources` | `Stats4Source[]` | required | The segments of the stacked bar and the legend rows. An empty list leaves the bar and the legend empty. |
| `range` | `Stats4Range` | required | The selected period. Controlled: the block keeps no copy. |
| `onRangeChange` | `(range: Stats4Range) => void` | - | Called with `'7d'`, `'30d'` or `'90d'` when an option is chosen. |
| `ranges` | `Stats4Range[]` | `['7d', '30d', '90d']` | Options of the select, in order. |
| `locale` | `string` | `'pt-BR'` | Locale of the numbers. |
| `pending` | `boolean` | `false` | Renders the skeleton in place of the content; wins over `error`. |
| `error` | `boolean` | `false` | Renders the error surface. |
| `onRetry` | `() => void` | - | Called by the Tentar novamente button; without it the button is not rendered. |
| `labels` | `Partial<Stats4Labels>` | pt-BR texts | Overrides the texts of the block; see Labels below. |
| `className` | `string` | - | Merged into the card's classes. |

The block takes no other props.

## Stats4Source

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | Key of the segment and the legend row. |
| `name` | `string` | Name in the legend. |
| `value` | `number` | Leads from the source. Segment widths and legend percentages are `value` over the sum of all sources. |
| `colorClassName` | `string` | Classes of the segment and its legend dot, for example `bg-sky-700 dark:bg-sky-500`. |

## Labels

| Key | Type | Default |
| --- | --- | --- |
| `title` | `string` | `"Visão geral de leads"` |
| `range` | `string` | `"Período"`; the accessible name of the select |
| `ranges` | `Record<Stats4Range, string>` | `"7 dias"`, `"30 dias"`, `"90 dias"` |
| `total` | `(range: string) => string` | `"Leads nos últimos 30 dias"` for `"30 dias"` |
| `goal` | `(goal: string) => string` | `"Meta de 1.500 leads"` |
| `goalProgress` | `(total: string, goal: string, percent: string) => string` | `"1.200 de 1.500 leads, 80% da meta"`; the spoken value of the progress bar |
| `sources` | `string` | `"Leads por origem"` |
| `sourcesBar` | `string` | `"Distribuição dos leads por origem"`; the accessible name of the stacked bar |
| `loading` | `string` | `"Carregando leads"`; the accessible name of the skeleton |
| `errorTitle` | `string` | `"Não foi possível carregar os leads"` |
| `errorDescription` | `string` | `"Verifique sua conexão e tente novamente."` |
| `retry` | `string` | `"Tentar novamente"` |

## Accessibility and theme

- The skeleton is `aria-busy="true"` and named by `labels.loading`; the error surface has the `alert` role.
- The select is named by `labels.range`.
- The progress bar is a `progressbar` whose spoken value is `labels.goalProgress`.
- The stacked bar is an `img` named by `labels.sourcesBar`; the legend carries the same data as text.
- The block carries no color of its own besides the `colorClassName` of each source: the theme belongs to the app.
