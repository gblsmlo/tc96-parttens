# Stats5

A single card split into divided columns, one per metric. Each column shows a label, a large value and a trend badge with the direction and the percent change. Reach for it when a dashboard compares a few headline numbers, such as sales, new customers and churn. Install it with `npx @tc96/parttens add stats-5`.

It is a card, not a page: it renders a `section` and no `main` landmark. It is made for three items: on screens from `sm` they sit side by side, below that they stack. Values arrive as numbers and the block formats them; it keeps no state and fetches nothing. Loading and error are the block's: `pending` renders its skeleton in place of the content and `error` an error surface with a retry button; the precedence is `pending`, then `error`.

The other pages of `Blocks/Application/Stats/Stats5`: [Playground](?path=/story/blocks-application-stats-stats5-playground--playground) to try the trends and the currency, [Behavior](?path=/story/blocks-application-stats-stats5-behavior--columns-show-label-value-and-trend) for the tests, [States](?path=/story/blocks-application-stats-stats5-states--default) for the loaded, loading and error states and [Usages](?path=/story/blocks-application-stats-stats5-usages--loaded) for the card read over the network.

## Import

```tsx
import { Stats5 } from '@tc96/blocks/application/stats/stats-5'
```

The same path exports the types `Stats5Props`, `Stats5Item`, `Stats5Format` and `Stats5Labels`.

## Stats5

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `Stats5Item[]` | required | The columns, in order. |
| `currency` | `string` | `'BRL'` | ISO currency of the items whose `format` is `'currency'`. |
| `locale` | `string` | `'pt-BR'` | Locale of the numbers. |
| `pending` | `boolean` | `false` | Renders the skeleton in place of the content; wins over `error`. |
| `error` | `boolean` | `false` | Renders the error surface. |
| `onRetry` | `() => void` | - | Called by the Tentar novamente button; without it the button is not rendered. |
| `labels` | `Partial<Stats5Labels>` | pt-BR texts | Overrides the texts of the block; see Labels below. |
| `className` | `string` | - | Merged into the card's classes. |

The block takes no other props.

## Stats5Item

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | Key of the column. |
| `label` | `string` | Name of the metric. |
| `value` | `number` | The metric. For `'percent'` it is a ratio: `0.024` shows `2,4%`. |
| `format` | `'currency' \| 'number' \| 'percent'` | How `value` is shown. Defaults to `'currency'`. |
| `trend` | `number` | Change as a ratio: `0.082` shows `8,20%`. Above zero is up, below is down, zero is flat. |
| `lowerIsBetter` | `boolean` | Makes a drop green and a rise red, for metrics such as churn. The arrow still follows the sign. |

## Accessibility and theme

- The skeleton is `aria-busy="true"` and named by `labels.loading`; the error surface has the `alert` role.
- The card is a `region` named by `labels.title`; the columns are a list.
- The direction is also in text: the badge carries a screen reader prefix from `labels.up`, `labels.down` or `labels.flat`, so color is never the only signal.
- `data-direction` and `data-tone` (`good`, `bad` or `neutral`) on each badge record what the badge shows.
- The block carries no color, radius or shadow of its own: the theme belongs to the app.
