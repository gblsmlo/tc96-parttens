# NextSteps1

A section for the page of a record that was just created: what the system is still doing for it, what arrived late and waits to be applied, what failed, and the first tasks of the user. Reach for it after a create dialog that let the user save before every source answered.

The other pages of `Blocks/Records/NextSteps1`: [Playground](?path=/story/blocks-records-nextsteps1-playground--playground) to try the title, the tasks and Dispensar, [Layouts](?path=/story/blocks-records-nextsteps1-layouts--default) for the formation it takes, [Behavior](?path=/story/blocks-records-nextsteps1-behavior--dismiss-calls-on-dismiss) for what it guarantees, and [Usages](?path=/story/blocks-records-nextsteps1-usages--new-lawsuit) for a lawsuit right after it was created.

## Import

```tsx
import { NextSteps1 } from '@acme/blocks/records/next-steps-1'
```

## Anatomy

<Canvas of={ApiReferenceStories.Anatomy} />

```tsx
<NextSteps1 rows={rows} tasks={tasks} onDismiss={onDismiss} onTask={onTask} />
```

A `card` `RecordGroup` that cannot be folded, titled by `labels.title`, with Dispensar in its actions. Inside, a `div` with `data-slot="next-steps"` holds the rows as a `RecordStatusList` and the tasks (`data-slot="next-steps-tasks"`), one `RecordGroupItem` each with its button.

## NextSteps1

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `rows` | `readonly RecordsStatusRow[]` | required | Lists the work of the system; empty hides the list. |
| `tasks` | `readonly NextStepTask[]` | `[]` | Lists the first tasks of the user, each with a button. |
| `onTask` | `(id: string) => void` | - | Called with the `id` of the task whose button is pressed. |
| `onDismiss` | `() => void` | - | Called by Dispensar; without it the button is not rendered. |
| `labels` | `Partial<NextSteps1Labels>` | - | Replaces `title`, `dismiss` and `progress`, the name of the list. |
| `className` | `string` | - | Forwarded to the group. |

`NextStepTask` has `id`, `title` and `actionLabel`. A row's `action` is the place for Aplicar or Tentar de novo; put the values a late source brought in its `detail`, so the user sees them before applying.

| Attribute | Values | Description |
| --- | --- | --- |
| `data-slot` | `"next-steps"` | Selects the body of the section |
| `data-slot` | `"next-steps-tasks"` | Selects the tasks; it renders only with `tasks` |

The block keeps no dismissed state: hide it when `onDismiss` runs, and offer an undo where the page shows its toasts.

## Exports

| Export | Kind | Description |
| --- | --- | --- |
| `NextSteps1Props`, `NextSteps1Labels`, `NextStepTask` | `type` | The props, the texts and a task. |
| `RecordsStatusRow` | `type` | A status row, shared by the records blocks. |

## Accessibility and theme

- The section is a region named by its title; the list of rows is named by `labels.progress`.
- The list reads only status changes, so applying a value or a retry that succeeds is heard once.
