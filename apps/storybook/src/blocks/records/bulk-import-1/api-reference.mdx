# BulkImport1

An import dialog for many records found by one search: the lawsuits of an OAB number, the contacts of a spreadsheet, the invoices of a period. Reach for it when the user picks which results come in, sets what they share once, and keeps working while each one is imported.

The other pages of `Blocks/Records/BulkImport1`: [Playground](?path=/story/blocks-records-bulkimport1-playground--playground) to try the step, the search and the import state, [Layouts](?path=/story/blocks-records-bulkimport1-layouts--default) for the formation it takes, [Behavior](?path=/story/blocks-records-bulkimport1-behavior--marks-the-current-step) for what each step guarantees, and [Usages](?path=/story/blocks-records-bulkimport1-usages--oab-lawsuits) for the lawsuits of an OAB number.

## Import

```tsx
import { BulkImport1 } from '@acme/blocks/records/bulk-import-1'
```

## Anatomy

<Canvas of={ApiReferenceStories.Anatomy} />

```tsx
<BulkImport1 step="select" query={query} searchedAt={searchedAt} columns={columns} rows={rows} selected={selected}>
  {children}
</BulkImport1>
```

The block is one `large` `RecordDialog` with two steps; the header trail is the only breadcrumb, so the step has no trail of its own. `select` renders the query row (`data-slot="bulk-import-query"`: the query, the search status and Buscar de novo) and a table with a checkbox, the `columns` and a status column per row. `link` renders `children`, then the import progress as a `RecordStatusList`.

## BulkImport1

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | required | Controls whether the dialog is open. |
| `onOpenChange` | `(open: boolean) => void` | required | Called when the dialog asks to open or close. |
| `step` | `"select"` or `"link"` | required | Sets the step on screen; a change moves focus to the first field of the new step. |
| `onStepChange` | `(step: BulkImport1Step) => void` | required | Called by Continuar with `"link"` and by Voltar with `"select"`. |
| `query` | `ReactNode` | required | Names what was searched, in a badge. |
| `columns` | `readonly string[]` | required | Sets the column headers, in the order of each row's `cells`. |
| `rows` | `readonly BulkImportRow[]` | required | Lists the results; a row with `disabledReason` cannot be marked and shows the reason. |
| `selected` | `readonly string[]` | required | Sets the ids of the marked rows. |
| `onSelectedChange` | `(selected: readonly string[]) => void` | required | Called with the next ids when a row is marked or unmarked. |
| `onImport` | `() => boolean \| Promise<boolean>` | required | Called by the submit of the link step; `true` keeps the dialog open to show the progress. |
| `children` | `ReactNode` | - | Renders the fields every imported record shares, in the link step. |
| `searching` | `boolean` | `false` | When true, shows skeleton rows and disables Continuar and Buscar de novo. |
| `searchedAt` | `ReactNode` | - | Says when and where the results come from, next to the query. |
| `onSearchAgain` | `() => void` | - | Called by Buscar de novo; without it the button is not rendered. |
| `maxSelected` | `number` | `50` | Sets how many rows can be marked; at the limit the unmarked rows are disabled. |
| `progress` | `readonly RecordsStatusRow[]` | - | Lists one row per imported record in the link step. |
| `importing` | `boolean` | `false` | When true, disables Voltar and the submit and says the dialog can be closed. |
| `labels` | `Partial<BulkImport1Labels>` | - | Replaces any visible or accessible text; `import`, `select` and `selectedCount` are functions of the count or the row label. |

`BulkImportRow` has `id`, `label` (the accessible name of its checkbox, through `select`), `cells` and `disabledReason`.

| Attribute | Values | Description |
| --- | --- | --- |
| `data-slot` | `"bulk-import-query"` | Selects the query row |
| `data-disabled` | present on a row with `disabledReason` | Styles a row that cannot be marked |

## Exports

| Export | Kind | Description |
| --- | --- | --- |
| `BulkImport1Props`, `BulkImport1Labels`, `BulkImport1Step`, `BulkImportRow` | `type` | The props, the texts and a result row. |
| `RecordsStatusRow` | `type` | A progress row, shared by the records blocks. |

## Accessibility and theme

- Each checkbox is named by its row `label` through `labels.select`; the checkbox column header is `sr-only`.
- The search status is a polite live region, so the end of a search is heard.
