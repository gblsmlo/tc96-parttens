# LookupCreate1

A create dialog for a record that other sources already know by a number: a lawsuit by its CNJ number, a company by its CNPJ, an address by its CEP. Reach for it when the user types the number, the system checks whether it exists and asks the sources, and the user keeps filling the record while they answer.

The other pages of `Blocks/Records/LookupCreate1`: [Playground](?path=/story/blocks-records-lookupcreate1-playground--playground) to try the step, the identifier state and the sources, [Layouts](?path=/story/blocks-records-lookupcreate1-layouts--default) for the formation it takes, [Behavior](?path=/story/blocks-records-lookupcreate1-behavior--incomplete-identifier-explains-continuar) for what each step guarantees, and [Usages](?path=/story/blocks-records-lookupcreate1-usages--lawsuits) for a lawsuit created from its number.

## Import

```tsx
import { LookupCreate1 } from '@acme/blocks/records/lookup-create-1'
```

## Anatomy

<Canvas of={ApiReferenceStories.Anatomy} />

```tsx
<LookupCreate1 step="details" sources={sources} recordTitle={title}>
  {children}
</LookupCreate1>
```

The block is one `RecordDialog` with two steps. `origin` renders, in a `small` dialog:

```tsx
<form>
  <div data-slot="field">
    <label />
    <input />
    <p data-slot="field-description" />
  </div>
  <div data-slot="lookup-create-existing" role="alert" />
  <fieldset data-slot="lookup-create-alternatives">
    <legend />
    <button />
  </fieldset>
</form>
```

`details` renders, in a `default` dialog, the sources as a `RecordStatusList`, the alert of a failed source, the `RecordDialogHeadline` with the record title, and `children`; `Voltar` sits in the footer start.

## LookupCreate1

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | required | Controls whether the dialog is open. |
| `onOpenChange` | `(open: boolean) => void` | required | Called when the dialog asks to open or close. |
| `step` | `"origin"` or `"details"` | required | Sets the step on screen; a change moves focus to the first field of the new step. |
| `onStepChange` | `(step: LookupCreate1Step) => void` | required | Called by Continuar with `"details"` and by Voltar with `"origin"`. |
| `identifier` | `string` | required | Sets the value of the identifier field. |
| `onIdentifierChange` | `(identifier: string) => void` | required | Called on every change of the identifier field. |
| `identifierState` | `"incomplete"`, `"checking"`, `"available"` or `"taken"` | required | Sets the hint under the footer and enables Continuar only when `"available"`. |
| `sources` | `readonly RecordsStatusRow[]` | required | Lists the sources in the details step; empty hides the list. |
| `recordTitle` | `string` | required | Sets the title field of the details step; empty disables the submit. |
| `onTitleChange` | `(title: string) => void` | required | Called on every change of the title. |
| `onSubmit` | `() => boolean \| Promise<boolean>` | required | Called by the submit of the details step; `true` closes the dialog. |
| `children` | `ReactNode` | - | Renders the record fields under the title in the details step. |
| `existing` | `LookupExisting` | - | Shows, when `identifierState` is `"taken"`, the record that has the number and a link to it. |
| `alternatives` | `readonly LookupAlternative[]` | `[]` | Lists other ways to start under the identifier field. |
| `onAlternative` | `(id: string) => void` | - | Called with the `id` of the alternative the user picks. |
| `onRetry` | `() => void` | - | Called by Buscar de novo; without it a failed source shows no alert. |
| `pending` | `boolean` | `false` | When true, disables Voltar while the record is saved. |
| `renderLink` | `(href: string) => ReactElement` | `renderAnchor` | Renders the link to the existing record. |
| `labels` | `Partial<LookupCreate1Labels>` | - | Replaces any visible or accessible text. |

`RecordsStatusRow` has `id`, `title`, `status`, `detail`, `announcement` and `action`, the props of `RecordStatusItem`. `LookupExisting` has `description` and `href`; `LookupAlternative` has `id`, `title` and `description`.

| Attribute | Values | Description |
| --- | --- | --- |
| `data-slot` | `"lookup-create-existing"` | Selects the alert of a taken identifier |
| `data-slot` | `"lookup-create-alternatives"` | Selects the group of other ways to start |
| `data-slot` | `"lookup-create-failed"` | Selects the alert of a failed source |

The hint in the footer comes from `identifierState` in `origin`, and in `details` says that the title is missing or that the record can be created while a source is still searching.

## Accessibility and theme

- The footer hint describes the submit button and is read when it changes, so the reason a button is disabled is heard on focus.
- The sources list reads only status changes; put an elapsed time in the row `detail`.
