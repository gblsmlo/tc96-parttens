# ImpactMap

A growth impact map: a read-only vertical tree that links initiatives to metrics and metrics to a north-star metric. Each node is a card with its kind, title, the owner's initials and a progress bar, and a click selects it. Reach for it on a planning page that shows what each initiative moves. Install it with `npx @tc96/cli add impact-map`.

It is a section, not a page: it renders no `main` landmark. The block never fetches and keeps no state: the app passes the nodes with their progress, the links and the selected id, and decides what a selection does. The block computes only the layout. Loading, error and empty are the block's: `pending` renders its skeleton, `error` an error surface with a retry button, an empty `nodes` the empty state. The precedence is `pending`, then `error`, then empty.

The other pages of `Blocks/AI & Agents/Flow/ImpactMap`: [Playground](?path=/story/blocks-ai-agents-flow-impactmap-playground--playground) to try the controls, [Behavior](?path=/story/blocks-ai-agents-flow-impactmap-behavior--each-node-shows-title-kind-and-owner-initials) for the tests, [States](?path=/story/blocks-ai-agents-flow-impactmap-states--default) for the four states and [Usages](?path=/story/blocks-ai-agents-flow-impactmap-usages--loaded) for the data read over the network.

## ImpactMap

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `nodes` | `ImpactMapNode[]` | required | The cards. An empty array renders the empty state. |
| `links` | `ImpactMapLink[]` | required | Which node feeds which; the tree grows from the node that is never a `source`. |
| `selectedId` | `string \| null` | `null` | The highlighted node; controlled, a click does not change it. |
| `onNodeSelect` | `(id: string) => void` | - | Called with the id of the clicked node. |
| `pending` | `boolean` | `false` | Renders the skeleton in place of the tree; wins over `error` and the empty state. |
| `error` | `boolean` | `false` | Renders the error surface; wins over the empty state. |
| `onRetry` | `() => void` | - | Called by the Tentar novamente button; without it the button is not rendered. |
| `labels` | `Partial<ImpactMapLabels>` | pt-BR texts | Overrides the texts of the block; see Labels below. |
| `className` | `string` | - | Merged into the root classes. |

## ImpactMapNode

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | Identifies the node; it is what `onNodeSelect` receives. |
| `kind` | `'initiative' \| 'metric' \| 'north-star'` | Names the card; the tree depth comes from `links`. |
| `title` | `string` | The title of the card. |
| `progress` | `number` | From 0 to 100; other values are clamped. |
| `owner` | `string` | Optional person; its initials show on the card. |
| `valueText` | `string` | Optional value already formatted by the app, shown as a badge. |

`ImpactMapLink` is `{ id: string; source: string; target: string }`: `source` contributes to `target`.

## Accessibility and theme

- The nodes are a list of buttons; the selected one has `aria-pressed="true"` and the highlight comes from the `primary` and `accent` tokens, not from color alone (the ring is also thicker).
- Each progress bar is a `progressbar` named by `labels.progress`; the connecting lines are decorative and hidden.
- The skeleton is `aria-busy="true"` and named by `labels.loading`; the error surface has the `alert` role.
- The block carries no raw color, radius or shadow.
